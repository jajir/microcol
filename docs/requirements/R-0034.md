## 2. Behavior

   project alias, never a hosted model. Existing active jobs finish before the
   migration claims the shared worker lock or loads another model.
2. Start with 8192 context, a 4096-token output allowance and medium reasoning.
   Verify actual runtime identity, context, completion, elapsed time and memory
   pressure. Preserve one request at a time and the existing 300-second attempt,
   600-second task and two-repair limits.
3. A real `codex exec` delegation must produce only the requested instruction
   replacements; the caller validates every match, applies the batch and verifies
   the exact diff and documentation checks after unloading the model. A successful
   download or greeting alone is insufficient.
4. Record setup/worker failures and targeted repairs. Do not claim better code
   quality, savings or support for larger context from this smoke test.
5. No player path, save schema, Java package or TC scenario changes; the
   acceptance concerns the development operator and the local worker.
