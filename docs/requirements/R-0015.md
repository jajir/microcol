## 1. Summary

1. Agreed 2026-10-13: add France as at least one additional nation at fixed map positions, with cities and units.

2. This is a scenario-content starting point; it does not require the previously proposed configurable rival roster, arbitrary opponent counts or intelligence sliders.

3. Implementation authorized on 2026-10-13 covers French scenario content in both selectable maps using the existing AI controller. Long-term economic AI remains in R-0027.

## 2. Behavior

1. The reference free-play scenario includes the human nation and France, with French-owned cities and units at explicit repeatable coordinates.

2. Use Quebec and Montreal with food-producing inhabitants and an armed French colonist. Original-map cities are at (17, 10) and (17, 21); two-island-map cities are at (13, 10) and (13, 20). The human expedition remains at (45, 15), separated from France. These fixed positions passed real-model round trips and both UI Start/Continue journeys on 2026-10-13; the complete integration regression also passed.

3. French cities and units have consistent ownership, valid unique identities and legal places. The name France must not be a cosmetic label on human-owned objects.

4. Persist the added world content and its controller association; save/load preserves French ownership and the human player.

5. Do not promise national advantages, sophisticated AI or editable rival settings merely because France appears on the map. Record those gaps separately.

## 3. Implementation steps

1. Implemented and verified on 2026-10-13. The complete Docker regression passed; see the [shared acceptance record](../functional-tests.md#free-play-implementation-2026-10-13) for commands, counts and delivery evidence. Earlier audit observations describe the baseline.

2. Extend the selected bundled free-play map data and existing player/controller initialization; inspect name/king assumptions before adding the fixed nation.

3. Validate map positions, colony identities, inhabitants and units using the existing model/schema. Use supported unit types and reuse current AI rather than inventing a second rule engine.

4. Add a UI start/inspection/continuation scenario verifying French-owned cities and units. More complete DIP-001 behavior remains with R-0027.

## 4. Open questions

1. Resolved 2026-10-13: include at least France; no configurable opponent roster is required for this slice.

2. Resolved 2026-10-13: use fixed places with cities and units. Exact legal coordinates and initial content are routine implementation choices, not a blocking product question.
