## 1. Summary

Let the player compare work for the selected colonist and choose an available
productive job. Proposed first slice: the currently reachable ordinary colonist;
full specialist effects are a later UC-033 variant.

[`4b3a1b56`](https://github.com/jajir/microcol/commit/4b3a1b567bd9e8c8ad8af1587d9849ecee02bead);

The [source requirement](../gap-analysis.md#production-and-professions) covers
current/best yields and both indoor/outdoor work. This slice adds the usable
ordinary-worker path without inventing expert multipliers or a new worker roster.

## 2. Behavior

The selected worker's job menu includes eligible indoor and outdoor work.
For an outdoor worker, show current and best available yield where they differ;
for an indoor worker, show the best available outdoor yield. Figures come from
the same model calculations used by actual production.

Acceptance examples using independently specified fixture yields:

1. Available fields A=3 and B=4, occupied/shared C=5 → best usable yield is 4.
   Selecting that outdoor job for an indoor worker places the same unit on B.
2. Worker already on A changes its crop → stays on A; the menu does not silently
   move it merely because B has a higher yield.
3. Two equally best fields → select either valid one with the advertised yield;
   no occupied field is chosen. Own current field is not treated as a rival's
   occupation when comparing the worker's options.
4. Full/ineligible indoor job or no available outdoor field → unavailable with a
   reason. Cancel → no change. A stale destination → safe model rejection.
5. Complete the next colony update → output agrees with the displayed calculation;
   save/load preserves the chosen job and worker identity.

The first slice is available from ordinary free-play colony management.
It does not claim complete UC-033 acceptance for specialists.

## 4. Open questions

1. **Scope decision for refinement:** accept the ordinary-colonist first slice,
   or include particular specialists? Recommended: ordinary first. If specialists
   are added, reachable types and agreed outdoor values become blocking;
   unspecified multipliers belong to
   [Q-10](../gap-analysis.md#open-questions-and-decisions).
2. **Nonblocking:** tie-breaking among equally productive valid fields. A stable
   existing field order is sufficient; the UC does not require a particular square.
3. Indoor yield presentation must distinguish potential output from actual
   input-limited output. Refine the labels with a shortage example; do not show
   an unconstrained estimate as guaranteed production.
