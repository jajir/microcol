# R-0137 — Quick-load ranked goods and unload holds in order

1. Status: new
2. Updated: 2026-10-17
3. Related: P08; CARGO-010; UC-026 (Hra). See the [shortcut rule](../gap-analysis.md#transport-ships-and-atlantic-travel), [accepted ranking](../gap-analysis.md#exploration-work-and-transport) and [cargo use case](../use-cases.md#lode-naklad-a-obchodni-trasy).
4. Dependencies: model transfer/capacity operations including [R-0132](R-0132.md); shared quoted bid/tax from [R-0020](done/R-0020.md) and later national prices [R-0143](R-0143.md); colony warehouse policy remains A07.
5. Primary area: [A06](areas.md#a06).
6. Related areas: A07 warehouse source/destination; A10 current tax; A03 dock shortcuts/result feedback.
7. Origin: CARGO-010 missing shortcuts in the [rule catalogue](../gap-analysis.md#transport-ships-and-atlantic-travel).

## 1. Summary

1. A player needs a repeatable quick way to load the best sale cargo and unload holds without manually dragging each stack.
2. The 2026-10-17 catalogue source assessment at `ffae3396` records manual drag transfers but no ranked quick-load or sequential unload command. This is not a runtime test.
3. Scope: one quick-load choice per action and one ordered hold unload per action, reusing current transactions and warehouse limits; route automation remains separate.

## 2. Behavior

1. At an eligible owned colony dock, each Quick load action chooses the available commodity with the highest **current tax-net sale value per unit**. Exclude horses, tools and muskets. Break ties by goods ID. Fill the first compatible partial hold, or the first empty hold by index, using only actual source stock and hold capacity; repeating the action may fill another hold. Do not predict later prices.
2. Quick unload acts on the first nonempty goods hold in index order; repeating it proceeds through the carrier's holds. Each action transfers only the amount the destination can accept under its actual capacity. It does not discard excess, sell goods or empty a passenger hold.
3. If there is no eligible stock, no capacity or a changed state, explain why and leave all goods/treasury unchanged. Cancel does nothing. Quick commands use the same legal transfer and rejection boundaries as manual drag.
4. Save/Continue retains source and hold balances and their order; loading alone neither runs a shortcut nor repeats a transfer.

## 3. Implementation steps

1. Model supplies the ranked eligible candidate and exact transfer operation, applying current quote/tax and R-0132 hold cap. UI invokes those choices and displays a usable no-op/rejection reason, without implementing a second ranking formula.
2. Not prepared for development. On selection, inspect current trade quotes, warehouse and dock contexts; confirm which non-colony ports should offer these shortcuts before readiness.
3. Proposed checks: ranked/tied commodities, exclusions, compatible partial before empty holds, index order, full/empty source and warehouse, cancel/stale, repeated unload and save/Continue. Add a named UC-026 player path under the [functional contract](../functional-tests.md).
4. Current result: captured only; no gameplay change or runtime test is claimed.
