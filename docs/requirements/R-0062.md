## 1. Summary

1. The player needs an unstaffed colony to contribute its automatic cross, with displayed and actual production matching.

2. Migration observation (2026-10-14): Religious production has a declared base of one, but the current calculation only adds worker contributions; existing checks expect zero without staff. Periodic immigration does not prove cross production.

3. Scope: the outcome and examples below. This is captured work awaiting individual refinement; it does not reopen the delivered origin scope or close a whole UC.

## 2. Behavior

Proposed acceptance for refinement; inherited resolved decisions remain agreed.

1. Basic chapel without a preacher → preview one base cross and produce it once at the colony update.

2. Add or remove a worker → add/remove that worker’s contribution while retaining one base cross.

3. Upgrade the religious building → the colony still receives the base once, not once for each old/new building. Other religious bonuses belong to R-0086.

4. Two colonies each contribute once. Reopening screens and saving/loading add no production; unrelated town-hall bell output remains unchanged.

5. Shared behavior accepted on 2026-10-15 ([Q-10](../gap-analysis.md#q-10-economy-production-and-education)): The unstaffed initial colony produces one cross; church/cathedral totals replace that baseline. These decisions unblock policy; individual design, dependencies and acceptance checks still require refinement.
