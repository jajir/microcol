# R-0139 — Create a named route with reachable stops

1. Status: new
2. Updated: 2026-10-17
3. Related: P16; ROUTE-001; UC-029 (Hra). See the [route rule](../gap-analysis.md#automated-trade-routes) and [route use case](../use-cases.md#lode-naklad-a-obchodni-trasy).
4. Dependencies: existing colony and Europe destinations, map reachability and ship/wagon roles; stop cargo instructions are [R-0140](R-0140.md), execution [R-0141](R-0141.md).
5. Primary area: [A06](areas.md#a06).
6. Related areas: A05 route/path legality; A07 colony identity; A03 route editor; A04 saved route state.
7. Origin: ROUTE-001 gap in the [rule catalogue](../gap-analysis.md#automated-trade-routes).

## 1. Summary

1. A player needs a reusable named land or sea itinerary beginning at a colony and containing at most four reachable ordered stops.
2. The 2026-10-17 catalogue source assessment at `ffae3396` finds no saved route collection or editor; it is not a runtime acceptance result.
3. This requirement owns route identity, name, transport kind, ordered-stop structure and create/save/cancel validation. Cargo instructions, carrier assignment and later edits have separate owners.

## 2. Behavior

1. From an owned colony, the player names a land or sea route and chooses one through four ordered reachable destinations. A land route offers colonies reachable by wagon; an appropriate sea route can include Europe. The ordered stops and starting colony are visible before creation.
2. Route names are player-entered Unicode: trim surrounding Unicode whitespace, retain internal characters and limit to 64 Unicode code points under the project text rule. Blank/overlong input, wrong owner, inappropriate transport destination or an unreachable stop rejects without adding a partial route.
3. Cancel changes no route. A created route survives Save and Continue with the same name and stop order; merely creating or loading it does not move a carrier or transfer goods.

## 3. Implementation steps

1. Model owns a persisted route identity, owner, transport kind and ordered stops; expose legal destinations from shared map/colony/Europe state. UI edits a staged choice and calls one validated create operation.
2. Not prepared for development. On selection, inspect the route-path query and current-schema save container; use this structure for R-0140–R-0142 without a second itinerary store.
3. Proposed checks: one/four/five stops, land versus sea/Europe reachability, owner and stale target, Unicode/empty/64/65-code-point names, cancel and disk Continue. Add a named UC-029 player path under the [functional contract](../functional-tests.md).
4. Current result: captured only; no gameplay change or runtime test is claimed.

## 4. Open questions

1. May two routes owned by the same player share the same normalized name, or must route names be unique? The documented route rule does not set name uniqueness; stable internal IDs must not depend on the answer.
