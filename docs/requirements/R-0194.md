# R-0194 — Distinguish Exit, Retire and unscored Continue

1. Status: new
2. Updated: 2026-10-17
3. Related: P25/P28; [END-004](../gap-analysis.md#end-conditions-and-scoring); [UC-111](../use-cases.md#konec-hry-ulozeni-a-informace) (Hra).
4. Dependencies: date/result state [R-0193](R-0193.md), score calculation [R-0195](R-0195.md)/[R-0196](R-0196.md), Hall-of-Fame write [R-0197](R-0197.md), delivered safe Exit menu [R-0013](done/R-0013.md).
5. Primary area: [A10](areas.md#a10).
6. Related areas: A01 menu flow; A03 confirmation/result display; A04 result identity/persistence.
7. Origin: manual retire/result choice residual; existing Exit path is credited, not rebuilt.

## 1. Summary

1. A player can leave without scoring, or retire and record the current scored result.
2. This requirement owns the choice/action path, while dates and score arithmetic remain separate.

## 2. Behavior

1. Exit ends/leaves the current play session without calculating or recording a new score. Retire previews and confirms one score/result, then may place it in the Hall of Fame; cancellation of either leaves the live game unchanged.
2. At the 1800 nonrevolutionary boundary, Continue resumes unscored play; it cannot replace the already recorded result. Retiring during that unscored continuation does not create a second score. End/reload does not repeat a result write.
3. UC-111 checks Exit versus Retire, both cancellations, score/no-score, later unscored Continue and one result identity across Save/Continue.

## 3. Implementation steps

1. UI menu presents clear consequences and calls model-owned result/retirement operations. Model validates live terminal/scored state, records one result identity and invokes R-0197 only on a real scored completion. Keep R-0013 safe-exit behavior.
2. Proposed model/UC-111 checks cover canceled actions, score preview consistency, duplicate prevention and resumed unscored play under the [functional contract](../functional-tests.md).
3. Current result: capture only; no retirement implementation or runtime acceptance is claimed.
