## 1. Summary

1. Contact, trade, provocation, war, capture and peace have consistent consequences in one playable world.
2. This requirement owns connected proof, not new diplomacy, AI or capture rules.

## 2. Behavior

1. In a seeded ordinary game, meet natives, buy land, learn a taught skill and trade, provoke hostility, fight for and capture a rival European colony, negotiate peace, then resume only the trade the current relationship permits. Use legal player actions and actual native/rival responses, without test-time state changes.
2. A captured colony leaves the former owner's route and selection; peace changes attack legality; Save/Continue retains treaties, ownership and economic balances. Exercise a short native-hostility and privateer branch where the connected rules permit them.
3. UC-117 passes only when the expected relationship, stock, ownership and combat transitions agree across the representative UC-060–077 path on the same build. A failure belongs to the smallest feature owner.

## 3. Implementation steps

1. Fix a seed, legal starting resources and an independent milestone ledger; run named `TC_...` player scenarios under the [functional contract](../functional-tests.md), including Save/Continue and an uninterrupted comparison.
2. Current result: captured verification scope only; no integrated diplomacy journey pass is claimed.
