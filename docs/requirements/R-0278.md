## 1. Summary

1. Make the top menu more compact and give its button frames the natural irregularity of the game's pen drawings.
2. The existing toolbar at `20b15460` uses names below most icons and a small stretched border whose irregularity is barely visible.
3. Preserve the existing icon motifs, action order, names and behavior. The icon-only alternative was not selected.

## 2. Behavior

1. On the game map, each available toolbar action shows its recognizable icon followed by its localized name on the same horizontal line. Text remains Playpen Sans 14 Regular.
2. Each frame is a single thin contour with gently uneven edges and asymmetric corners. Cream background, flat seasonal icon colors and distinct hover, pressed, keyboard-focus and disabled states remain readable. Following the user's screenshot correction on 2026-10-25, both icon and frame strokes are stronger, gaps are smaller, and keyboard focus retains the freehand frame with an underlined name and filled background.
3. All ordinary actions fit in one row at the tested 1200-logical-pixel English window. Narrow windows wrap whole controls without clipping labels or covering the map; Czech remains readable.
4. The Colonies control keeps its separate arrow and native dropdown, including empty-list explanation, Escape/outside cancellation and keyboard selection. Hover/focus explanations, conditional independence, retirement, turn progression and Continue retain their effects.

## 3. Implementation steps

1. Reuse `ButtonsGamePanel`, `GamePanel.css` and the existing SVG-to-PNG toolbar-frame pipeline. Place all graphics left of names, retain 32-logical-pixel icons with a 2.4-unit source stroke (1.6 logical pixels), a 2-pixel frame stroke, three-pixel button gaps and graphic/text spacing. Export both SVGs at 2x resolution: 96-pixel atlas cells and a 192 x 96 frame with a 12-pixel source slice displayed at six logical pixels. Tighten ordinary and colony-selector padding; retain native keyboard behavior and an underlined focus cue.
2. Preserve GUI ownership from the [package map](../architecture.md); no model, save schema, fixture, translation or package-responsibility change is needed.
3. Extend TC188/F221's page verification to check actual icon/text positions and compact height, retaining EN/CZ layout, focus, season, Continue and dropdown assertions. Run TC188, TC38/01, TC81/04, TC164/01 and the page source contract in Docker/Xvfb, inspect screenshots, apply shared Java formatting, then run the mandatory complete model/JUnit and fixed smoke gate plus documentation checks and strict MkDocs.
4. The user rejected the thin strokes and excessive spacing of `d2808100` using a real macOS screenshot on 2026-10-25. This refinement addresses the same selected proposal and keeps this active requirement open. Earlier accepted-for-commit work, failed gates and current verification are preserved in the [functional evidence](../functional-tests.md#r-0278-horizontal-toolbar-2026-10-25); publication remains separate.
