## 1. Summary

1. Make the top menu more compact and give its button frames the natural irregularity of the game's pen drawings.
2. The existing toolbar at `20b15460` uses names below most icons and a small stretched border whose irregularity is barely visible.
3. Preserve the existing icon motifs, action order, names and behavior. The icon-only alternative was not selected.

## 2. Behavior

1. On the game map, each available toolbar action shows its recognizable icon followed by its localized name on the same horizontal line. Text remains Playpen Sans 14 Regular.
2. Each frame is a single thin contour with gently uneven edges and asymmetric corners. Cream background, flat seasonal icon colors and distinct hover, pressed, keyboard-focus and disabled states remain readable.
3. All ordinary actions fit in one row at the tested 1440-pixel English window. Narrow windows wrap whole controls without clipping labels or covering the map; Czech remains readable.
4. The Colonies control keeps its separate arrow and native dropdown, including empty-list explanation, Escape/outside cancellation and keyboard selection. Hover/focus explanations, conditional independence, retirement, turn progression and Continue retain their effects.

## 3. Implementation steps

1. Reuse `ButtonsGamePanel`, `GamePanel.css` and the existing SVG-to-PNG toolbar-frame pipeline. Place all graphics left of names, display the existing 48-pixel atlas cells at 32 logical pixels and reduce the colony selector height. Draw a larger six-pixel-sliced frame to retain visible irregularity at actual control sizes.
2. Preserve GUI ownership from the [package map](../architecture.md); no model, save schema, fixture, translation or package-responsibility change is needed.
3. Extend TC188/F221's page verification to check actual icon/text positions and compact height, retaining EN/CZ layout, focus, season, Continue and dropdown assertions. Run TC188, TC38/01, TC81/04, TC164/01 and the page source contract in Docker/Xvfb, inspect screenshots, apply shared Java formatting, then run the mandatory complete model/JUnit and fixed smoke gate plus documentation checks and strict MkDocs.
4. Implementation, nine targeted checks and screenshot review are complete. The first full gate timed out despite zero failures/errors/skips; its retry is pending. The user requested commit without waiting on 2026-10-25. Required acceptance remains pending; actual results are in the [functional evidence](../functional-tests.md#r-0278-horizontal-toolbar-2026-10-25); publication remains separate.
