# Canceled requirements

Requirements with `Status: canceled` live here. Preserve their IDs, decisions,
cancellation reasons and links to successors; cancellation of an old assignment
does not delete feature scope owned by its replacement.

Follow the shared [status and file-location workflow](../README.md#file-locations).
Use the [current backlog](../backlog.md) for active work and the
[migration map](../migration-2026-10-14.md) for the original requirements' lineage.
