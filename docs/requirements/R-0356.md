1. Status: waiting for refinement
2. Updated: 2026-10-30

## 1. Summary

1. Make the minimap presentation fit the game's pen-drawn style: remove the dashed outer frame, place the heading “Minimap” above the map in the existing handwritten text style, and remove the visible instruction below it.
2. Compare the same revised panel with the current angular coastline, gently rounded corners and more continuous curves. The [three proposals](../graphics.md#minimapa-nadpis-a-hladkost-pobrezi-30-rijna-2026) are static design references, not implemented UI.

## 2. Behavior

1. All three alternatives have the same heading, map scale, terrain colors, gray unexplored area and rectangular camera indicator. The solid map border and strong pen strokes remain; the dashed outer frame and bottom explanation disappear.
2. Alternative 1 preserves the stepped contours. Alternative 2 rounds their corners. Alternative 3 joins small steps into more flowing contours while retaining the main geographic shapes.
3. The future selected implementation must preserve click, drag and arrow-key navigation, keyboard access, viewport tracking and concealed terrain. Smoothing must not reveal previously unknown geography or change game rules.
4. The current delivery contains proposals only. The user chooses the final alternative before runtime implementation begins.

## 3. Implementation steps

1. Use the supplied screenshot as the edit reference; produce the baseline proposal, then derive both smoothing alternatives from it with built-in ImageGen. Preserve the three outputs, input and exact prompts in the [gallery](../graphics.md#minimapa-nadpis-a-hladkost-pobrezi-30-rijna-2026).
2. Record design-only inspection and documentation checks in [publication evidence](../publishing.md#r-0356-minimap-refinement-proposals-2026-10-30). Generated lettering and contours are visual approximations, not a pixel-exact runtime specification.
3. After selection, refine the existing GUI minimap renderer and shared text/focus styling without adding model dependencies or replacing procedural map rendering with these PNG references. Preserve accessible help and keyboard focus usability when removing the visible hint and dashed decoration. Reuse TC196, toolbar/layout scenarios and the established local acceptance phases for the eventual implementation.
