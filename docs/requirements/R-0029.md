# R-0029 — Calculate and explain ordinary land combat strength

1. Status: Draft
2. Updated: 2026-10-13
3. Related: P17; COMBAT-004/005/006/007, Q-08; UC-073 (Hra), ordinary land-role slice. See the [rule catalogue](../gap-analysis.md),
   [use cases](../use-cases.md) and [work packages](../implementation-plan.md#seznam-pracovnich-baliku).
4. Dependencies: Existing equipment/terrain; [R-0028](R-0028.md) legal attack selection.
5. Primary area: [A09](areas.md#a09).
6. Related areas: A05 role/terrain data; A03 combat explanation.

## 1. Summary

1. Provide one model calculation of ordinary soldier/dragoon strength with a checkable explanation before changing combat probability.

2. The catalogue records descriptive strengths of 1.5/2 and actual fixed win probability. The manual reference gives ordinary soldier 2 and dragoon 3; a displayed strength alone does not establish strength-based resolution.

3. Ordinary land soldier/dragoon base values and agreed attack/terrain/fortification modifiers, with an honest preview. RNG conversion, veterans, artillery, naval combat and outcome changes require separate requirements.

## 2. Behavior

Proposed acceptance for individual refinement; capture does not approve implementation.

1. The model reports base strength 2 for an ordinary soldier and 3 for an ordinary dragoon, retaining exact internal precision for subsequent modifiers.

2. Expose each applicable modifier and final attack/defense strength with a documented stacking order and rounding rule accepted under Q-08.

3. Changing equipment, terrain or effective fortification updates the result. Merely opening/cancelling the preview consumes no movement and draws no random result.

4. GUI reads that calculation rather than recomputing it. Until the resolution algorithm uses these values, do not label the ratio as win probability or claim this slice fixes actual combat balance.

5. The same saved position produces the same calculation after reload. Test strengths separately from winner/loser tests.

## 3. Implementation steps

1. Introduce the smallest pure calculation within `model`, reusing role/terrain data; inspect existing military-strength consumers to avoid changing unrelated logic accidentally.

2. Implement the agreed narrow modifier table and expose its explanation to the existing combat information flow. Record that integration into probability remains open P17 work.

3. Proposed `TC_land_strength_preview_test` checks displayed soldier/dragoon examples and cancellation. Parameterized model tests calculate each modifier independently and selected combinations with hand-worked expected results.
