## 1. Summary

1. The player needs the displayed year and seasons to follow the agreed game profile, with one calendar advance after a complete round.

2. Current situation: The reference calendar still starts in 1490 and changes season frequency in 1600; the manual-based catalogue specifies a 1500 start. Existing calendar tests describe current behavior, not resolution of Q-02.

3. Scope: the outcome and examples below. This is captured work awaiting individual refinement; it does not reopen the delivered origin scope or close a whole UC.

## 2. Behavior

Proposed acceptance for refinement; inherited resolved decisions remain agreed.

1. Start the reference game → show its agreed initial year and season; loading an existing current-schema game preserves its stored date.

2. Complete all participating nations’ turns → advance the calendar exactly once. Opening a screen or continuing a save never advances it.

3. At each agreed season-frequency boundary, the last turn before and first turn after it show the expected dates; no year or season is duplicated or skipped.

4. The manual’s 1500 reference start is the target to refine. Historical dates in deliberately different scenarios remain explicit scenario choices, not accidental defaults.
