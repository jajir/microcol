# R-0252 — Přibalené řezy Playpen Sans Medium a SemiBold

1. Status: ready for development
2. Updated: 2026-10-20
3. Related: [UC-119](../use-cases.md), TC85; technická dostupnost fontů.
4. Dependencies: [R-0250](done/R-0250.md).
5. Primary area: [A03](areas.md#a03).
6. Related areas: A02 používá společnou typografii v Nastavení.
7. Origin: uživatel požádal o přidání obou silnějších řezů a návod pro CSS.

## 1. Summary

1. Autor stylů potřebuje volit skutečné řezy Medium 500 a SemiBold 600 bez systémové instalace a syntetického zesilování.
2. K 2026-10-20 zdroj cc71e01b registruje pouze Light 300. Rozpracované uživatelské CSS není součástí této změny.

## 2. Behavior

1. Po spuštění hry lze v CSS vybrat oba nové řezy pro běžné texty i stupnici slideru; font se načte z distribuce bez sítě.
2. Přidání řezů nemění výchozí Light, herní akce, uložené hry ani uživatelské CSS. Volbu vzhledu provede autor CSS podle dokumentace.
3. Chybějící nebo nečitelný přibalený font přeruší inicializaci s konkrétní chybou, nezvolí potichu systémovou náhradu.

## 3. Implementation steps

1. Ze stejného ověřeného variabilního zdroje jako Light vytvořit statické řezy 500 a 600; zachovat OFL a zapsat reprodukci do SOURCE.txt.
2. FontService registruje všechny tři řezy, Canvas nadále používá Light. Existující eager singleton zajišťuje načtení před použitím CSS; odpovědnosti balíčků se nemění.
3. Rozšířit TC85 o výběr obou řezů přes CSS na skutečném popisku a ose, s ověřením přesných jmen fontů v TypographyPage. Spustit Docker/Xvfb a kontrakt page objektů; úplnou regresi a distribuce ověří CI. Použít sdílený Java formatter a strict MkDocs.
4. Cílené 4 kontroly prošly; skutečné výsledky vede [funkční evidence](../functional-tests.md#r-0252-additional-font-weights-2026-10-20). Úplná regrese a publikace ještě čekají na CI.
