## 1. Summary

1. The in-game encyclopedia gives the player current, navigable rules for actions and outcomes they may need after the opening tutorial.
2. This requirement owns searchable/navigable rule guidance, not gameplay mechanics or a rewritten first mission.

## 2. Behavior

1. From normal play and relevant help affordances, the player can find concise current explanations of movement, cargo, colonies/work, production, trade, diplomacy, combat, independence and scoring, including prerequisite, cancel/rejection and outcome language. Content follows accepted shared rules and supported features; it does not promise an unimplemented optional mode.
2. Open/close/back and keyboard navigation retain current game/focus without spending a turn or changing stock. Language changes use the same supported locales; text/labels remain readable without sound or color.
3. UC-114 checks each rule family entry, a context lookup from a blocked action, keyboard/mouse return and no gameplay mutation. Individual numeric matrix acceptance remains R-0208–0216, not copied into long encyclopedia prose.

## 3. Implementation steps

1. GUI/help owner fills existing `ColonizopediaDialog` content and links it from current navigation. Source its facts from authoritative game rule/requirement owners; update entries when selected features change, with testable destination labels.
2. Proposed UI/UC-114 checks cover all family headings, current examples, language/focus/back and unchanged game state under the [functional contract](../functional-tests.md).
3. Current result: capture only; no help-content implementation or runtime acceptance is claimed.
