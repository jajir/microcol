## 1. Summary

1. The player needs to learn from the turn report that completed hammer work is waiting for tools, without repeatedly opening every colony.

2. Current situation: R-0025 supplies completion gating and a visible waiting reason. The turn report still lacks the missing-tools advisor event; this is distinct from the working queue display.

3. Scope: the outcome and examples below. This is captured work awaiting individual refinement; it does not reopen the delivered origin scope or close a whole UC.

## 2. Behavior

Proposed acceptance for refinement; inherited resolved decisions remain agreed.

1. A project has enough hammers but is one tool short → do not finish it; show an actionable missing-tools report identifying colony, project and shortage.

2. Opening the colony from that report shows the same retained progress and waiting reason.

3. Supply the last required tool → complete once on the agreed phase and consume exactly the required tools.

4. Repeated views and Continue do not duplicate the report or completion; a clear repeat-notification policy handles multiple waiting turns.
