## 1. Summary

1. The player needs to select goods for automatic export and see the stock and treasury effects each turn.

2. Migration observation (2026-10-14): The catalogue identifies an inert custom-house type without persisted export selections or a turn export transaction.

3. Scope: the outcome and examples below. This is captured work awaiting individual refinement; it does not reopen the delivered origin scope or close a whole UC.

## 2. Behavior

Proposed acceptance for refinement; inherited resolved decisions remain agreed.

1. In a completed custom house, select the goods to export; leave all unselected goods untouched.

2. At the agreed phase, export the eligible quantity once using the shared price/tax/boycott rules and report the actual proceeds.

3. Cancel selection changes → retain previous settings. An unavailable market or invalid export causes no partial stock removal or credit.

4. Save/load preserves selections and processed state. Any revolution-time export at 50% proceeds is a separately identified variant requiring its political-state dependency.

5. Accepted behavior (2026-10-15; [economy, production and education](../gap-analysis.md#economy-production-and-education)): Export selected tradable stock above the agreed reserve after production and spending; apply the specified boycott and revolution proceeds rules.

6. Shared update boundary (2026-10-15): apply this requirement within [national turn processing](../gap-analysis.md#national-turn-processing). Resume the saved completed boundary without repeating production, arrivals or action replenishment; future pending choices must preserve earlier completed updates.
