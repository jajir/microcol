## 1. Summary

Correct the expert blacksmith's basic-house input accounting so six tools require
six ore. Deliver a player-usable expert path rather than proving only a mocked
worker calculation.

[`4b3a1b56`](https://github.com/jajir/microcol/commit/4b3a1b567bd9e8c8ad8af1587d9849ecee02bead);

[UnitFactory](../../microcol-game/src/main/java/org/microcol/model/unit/UnitFactory.java).

Scope is this expert's basic-house example and required reachability. The full
expert roster, factory conversion ratios and outdoor expertise are excluded.

## 2. Behavior

The player obtains the agreed master blacksmith in ordinary free play, assigns it
through colony controls and sees production that matches actual next-turn stocks.

Acceptance examples from the [production catalogue](../gap-analysis.md#production-and-professions):

1. One expert, 3 newly produced ore plus 3 stored ore → 6 tools; no ore remains.
2. Only 3 total ore → 3 tools and no ore remains. Zero ore → zero tools.
3. Ordinary worker with sufficient ore → existing basic 3 ore → 3 tools remains.
4. Multiple slots share available ore without spending it twice. No preview
   or repeated screen opening consumes materials.
5. Cancel assignment → original job and stocks remain. Save/continue preserves
   expert type, owner and job; it does not replay manufacturing.
6. Production preview, turn result and stock changes agree; the UI explains
   input-limited output without claiming full potential output was produced.

These examples do not define upgraded-factory ratios or unspecified bonuses.
