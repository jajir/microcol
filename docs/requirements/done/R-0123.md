## 1. Summary

1. A player must be able to distinguish every documented land and water terrain and its legal forest state, so later production, travel and combat use the same tile identity.
2. The 2026-10-17 catalogue source assessment at `f902be8a` identifies missing plains, marsh and fresh-water lake identity, disallows a documented forested tundra, while R-0093 has already corrected defense values for supported variants. The earlier catalogue table predates that correction. This requirement adds the missing identities/variants and their defense cells; it does not repeat completed defense work.
3. This requirement owns terrain identity, legal forest variants and the terrain-defense reference values. [R-0124](../R-0124.md) owns output cells, [R-0125](../R-0125.md) movement cost, and [R-0093](R-0093.md) owns the existing combat strength/resolver path; no combat resolver is recreated here. River, road and resource overlays have separate owners.

## 2. Behavior

1. Maps can contain and identify plains, grasslands, prairie, savannah, marsh, swamp, desert, tundra, arctic, hills, mountains, a fresh-water lake, ocean and sea lane. A lake remains distinguishable from ocean-connected water after save and Continue. The aid-card land rows support the bare/forested variants shown in the [terrain audit](../../gap-analysis.md#terrain-reference-data-audit), including forested tundra; arctic, hills, mountains and water do not gain an invented forest variant.
2. On each documented terrain/forest variant, the terrain defense value equals the aid-card-4 cell. New cells include forested/bare plains 50/0%, marsh 50/25% and forested tundra 50%. Preserve the already delivered swamp 75/25%, hills 100% and mountains 150%; the [complete terrain audit](../../gap-analysis.md#terrain-reference-data-audit) supplies the remaining cells. A combat preview and actual ordinary battle that already use shared terrain defense must read the same value; this requirement does not add new combat roles or special bonuses.
3. Invalid terrain/forest combinations and unknown required terrain codes are rejected without silently becoming another terrain. Merely inspecting or loading a tile does not alter it. Terrain identity and legal forest state survive save/Continue.
4. Changing a forest through the separately owned [clearing order](R-0120.md) changes the variant once; the corrected type/defense then applies. Whole UC-007 production/movement and UC-073 combat-role matrices remain independently open until their owners are accepted.

5. Accepted on 2026-10-18: a lake keeps its distinct identity but uses ordinary ocean ship access, movement and fishing. The base fish output is three food with the same dock prerequisite and modifiers; no forest, road or Europe sea-lane exit is implied. See the [shared lake rule](../../gap-analysis.md#terrain-reference-data-audit).

## 3. Implementation steps

1. `TerrainType` owns distinct names/codes, water classification, legal forest states and defense values. Add plains, marsh and lake identities, enable forested tundra, and retain existing identifiers. Reuse R-0093 combat strength/resolution; do not introduce a second defense calculation.
2. Trace `WorldMap`/`Terrain` validation and map storage, ship movement/placement and coastal helpers, field dock gating, `ImageRandomProvider`/terrain image mapping, localization and editor selections. Lake uses the agreed ordinary-ocean behavior, including food baseline, without becoming a sea-lane exit. Preserve current terrain codes and ocean-connected voyage behavior.
3. Use existing graphics assets and explicit localized terrain names to keep every terrain displayable. Add no model-to-GUI dependency. Trace every terrain lookup and cover complete image/name mappings; do not silently replace a saved identity with a visual fallback identity. Detailed artwork remains independently owned.
4. Introduce only required new terrain data; R-0124 still owns correction of the complete production matrix and R-0125 the exact movement execution/path/range matrix. Existing land output and movement cells outside this requirement remain unchanged. New land types use documented card data where constructor fields are required; no guessed lake policy remains.
5. Model tests cover all terrain/forest defense cells, illegal forest combinations, strict unknown codes, distinct lake round trips, clearing and shared combat preview/resolution. Verify actual lake ship movement and dock-gated food production, not only flags. TC80/F72 verifies new terrain names/forest state, lake ship/fishing behavior and Save/Continue; preserve existing TC73 clearing and affected coastal/fishing/combat scenarios. Main applies the shared formatter and targeted Docker tests; full regression stays at requirement 20.
6. The lake decision and this source-based refinement permit implementation within the already authorized batch. Implementation and targeted checks are tracked in the [evidence](../../functional-tests.md#r-0123-terrain-identities-and-lakes-2026-10-18); readiness remains until full batch acceptance, independently of publication.
