## 1. Summary

1. Players need to recognize every terrain and special resource and understand their properties without leaving the game.

## 2. Behavior

1. Terrain lists all 14 supported terrain types using existing game artwork and localized names. Show land/water, movement cost, defensive bonus and base production; forest-capable terrain also shows its forest preview, movement, defense and production, and whether fields are supported.
2. Terrain bonuses lists all 12 nonempty resources with their map markers, eligible terrain, affected goods, bonus amounts and finite reserves where applicable. Explain that bonuses precede worker modifiers, may introduce production, and depleted mineral bonuses leave ordinary production. Explain the distinct commons rule.
3. Values come from current model definitions. Existing shared artwork is retained, with names distinguishing terrain that shares a tile. Do not invent new terrain, resource artwork or rules.
4. Both topics work in English and Czech, including searching names without accents. Content wraps and scrolls; keyboard topic selection, H, OK and Escape continue to work. Viewing help changes no game state.
