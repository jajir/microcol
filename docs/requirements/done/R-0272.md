# R-0272 — Open unit commands directly on the map

1. Status: done
2. Updated: 2026-10-25
3. Primary area: [A03](../areas.md#a03), map interaction and discoverable unit commands.
4. Related areas: A05 unit selection/orders, A07 colony entry; existing model rules remain authoritative.
5. Related: [R-0270](R-0270.md), [UX guidelines](../../ux.md), UC-011/114/119 in the [use-case catalogue](../../use-cases.md).
6. Origin: user correction and implementation request on 2026-10-25. The side-panel action menu from R-0270 does not meet the intended map interaction.

## 1. Summary

1. Open a unit's orders beside that unit in the map. Keep the right-hand panel informational, including unit state, movement, cargo and route status.
2. This supersedes R-0270's action-button and clickable-card access design, while retaining its separation between unit commands and global controls.

## 2. Behavior

1. Right-click an own unit on the map: select it and open its commands at the click, without moving it, spending movement or entering a colony.
2. On a colony square, left-click still enters the colony; right-click opens the unit menu even when a ship is in that port. Opening or dismissing the menu never opens the colony.
3. If several own units occupy the square, the menu offers their selection and then the same unit commands. Preserve an already selected unit on that square; otherwise use the existing map selection. The right panel has no Actions button, command menu or clickable unit selection.
4. Right-button dragging pans the map without opening a menu or entering a colony. Small click jitter does not count as dragging. A right-click cancels an unconfirmed movement preview instead of executing it.
5. Empty or foreign-unit squares offer no own-unit commands. Existing game/turn eligibility, explanations, confirmations, command shortcuts and route-status display remain intact.
6. A focused map supports Shift+F10 or the context-menu key for the selected unit. Arrows/Enter/Space operate the menu; Escape dismisses it. The menu must fit the supported small window and retain English/Czech text.

## 3. Implementation steps

1. Reuse the existing GUI menu and command handlers. Move its opening/anchoring into the map input owner and distinguish secondary click/release from panning before any primary-click movement or colony path. Do not change model or save state.
2. Keep the selected unit's route label in `UnitsPanel`; remove side-panel actions and click-selection handlers. Offer stacked-unit selection inside the existing map context menu.
3. Update shared page objects to open map menus and select stacked units there. Preserve gameplay assertions. Extend `TC_11_F11_skip_to_next_unit_test` for the port click distinction, read-only panel, empty/foreign selection, keyboard input, preview cancellation and panning. Recheck the affected command scenarios and mandatory model/JUnit plus Docker/Xvfb smoke gate.
4. Implementation and local acceptance completed on 2026-10-25. Record actual verification in the [functional evidence](../../functional-tests.md#r-0272-map-unit-context-2026-10-25), apply the shared formatter and check documentation before commit/push.
