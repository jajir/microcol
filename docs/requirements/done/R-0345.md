# R-0345 — Hra bez vyskakovacích bublin nápovědy

1. Status: done
2. Updated: 2026-10-29
3. Related: [UC-114, UC-115, UC-119](../../use-cases.md), [pravidla UX](../../ux.md).
4. Dependencies: existující stavový řádek, přístupné názvy a kontextové nabídky.
5. Primary area: [A03](../areas.md#a03).
6. Related areas: žádná nová pravidla jiných oblastí.
7. Origin: uživatel 2026-10-29 odmítl koncept bublin zobrazovaných při zastavení myši a požádal o plošné odstranění.

## 1. Shrnutí

1. Hráč nechce, aby se nad hrou po zastavení ukazatele zobrazoval plovoucí box s nápovědou. Ukázkou je tlačítko Retire.
2. Rozsah zahrnuje celou aplikaci: úvodní menu, herní lišty, jednotky, kolonii, Evropu, diplomacii i ostatní obrazovky a dialogy.

## 2. Chování

1. Po najetí a setrvání nad ovládáním či herním údajem se nezobrazí vyskakovací bublina, v angličtině ani češtině, v širokém ani kompaktním okně.
2. Viditelné popisky, přístupné názvy, dosavadní text ve spodním stavovém řádku a vysvětlení nedostupných rozkazů přímo v nabídce zůstávají dostupné. Nápověda otevíraná tlačítkem nebo H zůstává.
3. Kliknutí, klávesnice, kontextové nabídky, potvrzení a zrušení akcí mají původní účinek. Pouhé prohlížení nemění výběr, tah, pohyb, náklad ani uloženou hru.

## 3. Implementační kroky

1. Vlastníkem je GUI podle [mapy odpovědností](../../architecture.md). Odstranit vytváření a instalaci JavaFX Tooltip ze společných tlačítek i jednotlivých obrazovek. Zachovat sémantické vysvětlení v přístupné nápovědě; řádky rozkazů navázat přímo na ni.
2. Rozšířit ButtonPresentationContractTest o zákaz návratu bublin ve zdrojích. Upravit existující page objects, aby nadále kontrolovaly stejné herní informace. TC188 ověří skutečné najetí na Retire bez bubliny a zachovaný stavový řádek; TC85 projde menu, nastavení, mapu, Kongres, Evropu, kolonii a dialog v obou jazycích.
3. Použít sdílený Java formatter. Provést všechny model/JUnit testy, cílené Docker/Xvfb scénáře dotčených cest a povinný smoke/support do 420 sekund. Dokumentaci ověřit kontrolami konzistence a strict MkDocs.
4. Implementováno a lokálně přijato 2026-10-29: 4 784 model/JUnit, 61 cílených UI/support a 21 smoke/support testů bez selhání, chyb či přeskočení. Smoke trval celkem 207,882 s. Podrobnosti a zachované neúspěšné pokusy vede [funkční evidence](../../functional-tests.md#r-0345-no-hover-tooltips-2026-10-29); vzdálená publikace se neověřovala.
