## 1. Summary

1. A player selects a map square to inspect it. An unexplored square should have the same recognizable fog appearance in the right panel as on the map, without disclosing its terrain or occupants.
2. The supplied screenshot shows gray-beige fog on the map and a nearly black square beside “Unknown” in the panel. Source inspection on 2026-10-27 at `c9d172e18375dc891edf2bb8fdf3e8414f3bda84` confirms separate rendering paths; this is not a newly reproduced runtime test.
3. Selected scope: correct unexplored previews and preserve existing exploration, information filtering and discovered previews. Acceptance also requires a bounded repair of the existing Congress candidate list layout, so the founder-triggered exploration scenarios remain usable. Full equivalence of every discovered-map layer is a broader outcome, described as a limitation in chapter 3 rather than silently included here.

## 2. Behavior

1. Main path: on the main game screen, clicking any unexplored square shows the same gray-beige fog in the right-panel preview. If that particular square has a question mark on the map, the preview has the same mark; an unmarked square remains unmarked. The localized “Unknown” label remains.
2. Selecting an unexplored square after a known square with a colony or unit removes the previous preview completely. The preview reveals no terrain, resource, river, unit, colony or native settlement hidden by exploration. Selection changes neither exploration nor game state and needs no confirmation or cancellation dialog.
3. Panning, resizing and Save/Continue preserve the appearance associated with the same square. Once the square is explored, selecting it shows its existing discovered preview; leaving present sight does not make explored terrain unknown again. Current-sight and remembered-colony rules remain authoritative.
4. Check marked and unmarked unknown squares, map borders and the exploration frontier. Existing rounded fog edges on discovered squares remain intact. Selection outlines, movement indicators and transient animation are not terrain content; this correction does not add them to the preview. Existing static terrain illustrations remain governed by the [visual brief](../../graphics.md#soucasne-zadani-vzhledu) and [UX guidelines](../../ux.md).

5. Supporting acceptance path: in the existing small Congress window, the offered candidates stay readable and selectable inside the scrolling report. Choosing, canceling and founder arrival retain their current outcomes.

[RightPanelView](../../../microcol-game/src/main/java/org/microcol/gui/screen/game/components/RightPanelView.java), in the unexplored branch of `refreshView`, instead requests `ImageLoaderTerrain.IMG_TILE_HIDDEN`. [ImageLoaderTerrain](../../../microcol-game/src/main/java/org/microcol/gui/image/ImageLoaderTerrain.java) maps that key to the dark `type_10_3` cell of `background.png`. [TilePainter](../../../microcol-game/src/main/java/org/microcol/gui/screen/game/components/TilePainter.java) draws that image directly. The atlas was visually inspected; no UI screenshot was generated in this analysis.
2. Selected correction: move the existing fog-fill operation into [PaintService](../../../microcol-game/src/main/java/org/microcol/gui/util/PaintService.java), use it from both current map passes and the panel, and reuse `paintUnknownMark` with the actual location in the panel. Preserve the final map fog pass and its ordering. Clear the whole preview canvas before composing a newly selected unknown tile, including the margins used by colony artwork. Remove the panel's now-unused image-provider dependency only after checking its callers. Do not recolor the atlas as the fix: that would leave the two rendering paths and location-dependent marks inconsistent.
3. Ownership stays in existing `gui.screen.game.components`, `gui.screen.game.gamepanel` and `gui.util` under the [package map](../../architecture.md). The panel's static terrain decoration intentionally differs from animated map frames. Therefore this correction cannot claim literal equivalence of all known map content.
