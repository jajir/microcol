## 1. Summary

1. The in-game encyclopedia gives the player current, navigable rules for actions and outcomes they may need after the opening tutorial.
2. This requirement owns searchable/navigable rule guidance, not gameplay mechanics or a rewritten first mission.

## 2. Behavior

1. From normal play and relevant help affordances, the player can find concise current explanations of movement, cargo, colonies/work, production, trade, diplomacy, combat, independence and scoring, including prerequisite, cancel/rejection and outcome language. Content follows accepted shared rules and supported features; it does not promise an unimplemented optional mode.
2. Open/close/back and keyboard navigation retain current game/focus without spending a turn or changing stock. Language changes use the same supported locales; text/labels remain readable without sound or color.
3. UC-114 checks each rule family entry, a context lookup from a blocked action, keyboard/mouse return and no gameplay mutation. Individual numeric matrix acceptance remains R-0208–0216, not copied into long encyclopedia prose.

4. The existing map help button and H shortcut open the same encyclopedia. A topic list and text search provide access to all rule families in English and Czech. Search matches localized titles and content; no results has an explicit message. Closing with OK or Escape restores the game, with no turn, stock, gold, unit-placement or saved-game mutation.
5. Scoring remains a topic: explain currently implemented statistics and explicitly distinguish unimplemented final-score/Hall-of-Fame behavior. Do not remove a requested topic or present future mechanics as playable. Guidance on a blocked action can be found through its topic or search; this does not introduce new contextual affordances on every control.

## 3. Implementation steps

1. The existing map help button and H shortcut open the localized Colonizopedia through its GUI event listener. Nine topics support title/body search, keyboard selection, scrolling and OK/Escape return. A dialog-local capture filter handles Escape before the focused list can consume it.
2. TC_100_F91 covers English/Czech navigation, searching, no results, scoring limits, scrolling and unchanged game state. Final targeted acceptance and earlier failures are recorded in [functional tests](../../functional-tests.md#r-0206-colonizopedia-help-plan-2026-10-19). The shared Java formatter passed token preservation and idempotence.
3. Accepted on the isolated batch branch on 2026-10-19. Full batch regression, integration with concurrent main changes and publication remain separate gates.
