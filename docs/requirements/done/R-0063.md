## 1. Summary

1. The player needs the nation chosen during setup to determine their actual participant and remain the same after Continue.

2. Migration observation (2026-10-14): R-0014 deliberately uses a mock nation selector while the reference scenarios remain fixed. A selected label alone does not change participant identity.

3. Scope: the outcome and examples below. Selected and refined on 2026-10-16 under the remaining-backlog authorization; it does not reopen the delivered origin scope or close a whole UC.

## 2. Behavior

Acceptance refined on 2026-10-16; inherited resolved decisions remain agreed.

1. Select England, France, Spain or Netherlands in setup → Start assigns the human to that nation with the correct identity, ownership and presentation.

2. Back returns to the menu without replacing the active game or saved continuation. Start validates the selected map/profile before replacement.

3. Player-entered name follows the existing Unicode/64-code-point contract and is distinct from the immutable nation identity.

4. Save and Continue retain nation and player name. National advantages are separate game rules; a working selector must not claim they are all implemented.

5. Accepted behavior (2026-10-15; [difficulty and national effects](../../gap-analysis.md#difficulty-and-national-effects), [calendar and starting expeditions](../../gap-analysis.md#calendar-and-starting-expeditions)): Apply the chosen four-nation expedition profile while preserving the separate display name and internal identity.

6. Actual nation choice applies to the four-nation reference profile from R-0066. Keep the three authored scenarios and the current default map unchanged: their nation control is disabled, reset to Netherlands, and clearly explains the fixed participant. Switching to the reference enables all four choices; switching back cannot silently apply a foreign identity to a Dutch scenario. Player name remains independent.

7. Reference Start and Continue work for each nation through ordinary AI and turn order. English/Czech labels describe the real selection; Back and Escape preserve the existing continuation.
