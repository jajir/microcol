# R-0430 — Náhled obchodní trasy respektuje druh dopravy

1. Status: done
2. Updated: 2026-11-08
3. Related: ROUTE-001–004, UC-029/116 (Hra/Regrese) v [use cases](../../use-cases.md).
4. Dependencies: [R-0395](R-0395.md), [R-0425](R-0425.md).
5. Primary area: [A06](../areas.md#a06).
6. Related areas: A03 — mapový náhled; A05 — existující pravidla pohybu.
7. Origin: uživatelský snímek námořní trasy Pokusna a žádost o odstranění pozemní varianty, 2026-11-08.

## 1. Summary

1. Hráč potřebuje vidět cestu odpovídající uloženému druhu obchodní trasy, i když ještě nepřiřadil dopravce.
2. Plánovač bez dopravce zkoušel vůz i loď; mezi dvěma přístavy proto kreslil oba druhy cest. Tato změna nahrazuje původní pravidlo dvou variant z R-0395.
3. Rozsah je výběr dopravního profilu náhledu, nikoli změna ceny pohybu nebo hledání nejlevnější cesty.

## 2. Behavior

1. Hráč otevře plánovač a vybere námořní trasu mezi dvěma přístavy dostupnými po souši i po moři: objeví se pouze námořní cesta, s dopravcem i bez něj.
2. Pozemní trasa ve stejné situaci ukazuje pouze pozemní cestu. Nedostupná cesta nesmí být nahrazena druhým druhem dopravy; zůstává vysvětlení nedostupnosti.
3. Zavření a opětovné otevření plánovače, přiřazení lodi a uložení/Continue zachovají správný druh. Samotný náhled nic nemění ani neposouvá jednotky. Zavření nevyžaduje potvrzení.
4. Zpáteční spojení, shody cen a Evropa dále používají [pravidla tras](../../gap-analysis.md#automated-trade-routes).

## 3. Implementation steps

1. V modelovém TradeRoutePlanner vybírat výchozí profil vozu/galeony podle TradeRouteKind; přiřazený dopravce dál dodá vlastní profil. GUI čte stejný náhled.
2. Upravit TradeRoutePlanningTest pro oba druhy mezi přístavy a zachovat ověření zpátečního spojení.
3. TC_209_F240_trade_route_two_ports_test ověří pouze mořskou čáru před přiřazením lodi, po otevření, po přiřazení a po Continue; TC_118_F109_trade_route_assignment_test pokryje pozemní plánování. Provést model/JUnit, cílené Docker UI, smoke, dokumentační kontroly a strict MkDocs.
4. Dokončeno lokálně: 5 061 modelových/JUnit kontrol, 6 cílených UI scénářů a 21 smoke/support kontrol prošlo bez chyb či vynechání. Výsledky a předchozí neúspěšné pokusy vede [evidence](../../functional-tests.md#r-0430-route-kind-preview-correction-2026-11-08). Publikace nové distribuce nebyla ověřována.
