## 1. Summary

1. Players need a consistent frame when leaving the map: menu above, status below and the screen's content between them.
2. Source inspection on 2026-10-27 found floating controls in reports and controls embedded in the colony/Europe artwork; reports lack the shared status bar.
3. Apply the frame to goals, turn report, statistics and all report tabs, colony, Europe, trade, settings opened during play, Congress and help. Preserve existing actions and game rules.

## 2. Behavior

1. Open a screen from a running game: its controls occupy a separate top bar; current gold and date remain at the bottom.
2. Content fills the remaining area. Longer content scrolls without moving the top or bottom bar. Narrow windows retain access to all controls and content.
3. Existing Back/Close and keyboard navigation return to their existing destinations. Opening or closing a report spends no resources and does not advance the turn.
4. Keep Czech/English text, focus and disabled states, colony operations, Europe cargo and trade confirmations. Startup menu retains its own presentation. Save data is unchanged.

## 3. Implementation steps

1. Refine one shared GUI layout using the existing status bar and controls. Screen owners retain content, state and navigation; model and AI responsibilities do not change.
2. Migrate existing full-screen views and scoped CSS, remove floating-button overlap, and update relevant page objects while preserving scenario IDs and assertions.
3. Verify with all fast model/JUnit tests, targeted Docker/Xvfb TC192, TC01, TC06, TC83/84, TC100, TC168, TC176/177/178, TC188/191 and PageVerificationContractTest, then the fixed smoke/support selection. Apply the shared Java formatter, documentation checks and strict MkDocs.
4. Current result: shared frame implemented and locally accepted on 2026-10-27; 4,764 model/JUnit, 41 targeted UI/support and 21 smoke/support checks passed with zero failures/errors/skips. Java formatting, source-contract review and strict documentation validation passed. See [evidence](../../functional-tests.md#r-0307-in-game-screen-frame-2026-10-27).
