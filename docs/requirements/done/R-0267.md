## 1. Summary

1. Players see the same readable bottom status panel when moving between the main map, colony and Europe.
2. The main game screen uses the agreed Playpen Sans Regular 14 consistently, including text drawn into the map.

## 2. Behavior

1. Opening a colony or Europe and returning by button or Escape preserves the status panel's cream background, minimum height of 72 logical pixels, padding and Regular 14 text.
2. Description, gold and date remain readable. Gold and date are separated by a single vertical line; the date has no surrounding frame.
3. Long English and Czech descriptions wrap without hiding gold/date or overlapping the map at the existing tested window sizes.
4. Map captions and unit action signs use Regular 14. Shared canvas text uses the agreed Regular face; colony production retains its existing size.
5. Navigation, gold, turn, selection and save behavior are unchanged. No new player action or cancellation path is introduced.

## 3. Implementation steps

1. Source inspection at `374737b1b69b5a37a5d9b83f8f801ab6d60f3fa0` found map-only status CSS and a Light 16 map font. Scope and acceptance are refined and implementation is authorized.
2. Move status rules from `GamePanel.css` into `MicroCol.css`; explicitly set separator sides and remove the date border. Reuse the shared component and existing GUI owners in [architecture](../../architecture.md).
3. Select the bundled Regular default in `FontService`, use 14 for map painting, and preserve existing CSS typography on the main screen.
4. Extend TC21 methods TC01/TC04/TC10 for shared status styling, scene typography and actual screenshots; update TC85 canvas expectations. Run those affected scenarios, source-contract support checks, all model/JUnit tests, the fixed Docker/Xvfb smoke gate, Java formatting and documentation checks/strict MkDocs.
