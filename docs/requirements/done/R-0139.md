## 1. Summary

1. A player needs a reusable named land or sea itinerary beginning at a colony and containing at most four reachable ordered stops.
2. The 2026-10-17 catalogue source assessment at `ffae3396` finds no saved route collection or editor; it is not a runtime acceptance result.
3. This requirement owns route identity, name, transport kind, ordered-stop structure and create/save/cancel validation. Cargo instructions, carrier assignment and later edits have separate owners.

## 2. Behavior

1. From an owned colony, the player names a land or sea route and chooses one through four ordered reachable destinations. A land route offers colonies reachable by wagon; an appropriate sea route can include Europe. The ordered stops and starting colony are visible before creation.
2. Route names are player-entered Unicode: trim surrounding Unicode whitespace, retain internal characters and limit to 64 Unicode code points under the project text rule. Blank/overlong input, wrong owner, inappropriate transport destination or an unreachable stop rejects without adding a partial route.
3. Cancel changes no route. A created route survives Save and Continue with the same name and stop order; merely creating or loading it does not move a carrier or transfer goods.

4. Agreed 2026-10-20 ([shared rule](../../gap-analysis.md#r-0139-refinement)): Route names must be unique within one player under normalized case-insensitive comparison after trimming surrounding Unicode whitespace; different players may reuse a name. Preserve internal spaces, accents and punctuation and the shared 64-Unicode-code-point limit. Stable route identity remains independent of the name.

## 3. Implementation steps

1. Model owns one persisted itinerary collection with stable IDs, European owner, normalized display name, transport kind, starting colony ID and ordered destination identities. Reuse shared Unicode/name normalization and current-schema validation. Names are unique per player under normalized case-insensitive comparison, not globally.
2. Reuse shared map/path legality and colony/Europe destinations to expose reachable choices for wagon or ship. Validate each successive leg from the starting colony, including a legal Atlantic connection for Europe; a land route cannot visit Europe. Preview must not create a live carrier or change movement. Respect the owner's known map and destination permissions.
3. Creation validates current owner, starting colony, one through four ordered stops, transport legality, reachability, name and ID capacity before any mutation. Reject stale or foreign targets and disconnected legs atomically. Persist stable target identities and order; loading is validation, not execution. Cargo policy, assignment, repeated travel and editing remain R-0140–R-0142, sharing this itinerary store.
4. Add an EN/CS route editor reached from an owned colony through existing controls. Show starting colony, transport kind, staged name and ordered stops, with keyboard access and explicit Create/Cancel. Invalid choices show a useful reason; cancel changes nothing. No carrier movement or goods transfer on creation or Continue.
5. Model tests cover one/four/five stops, successive-leg reachability, land/sea/Europe, owner/stale targets, duplicate names across same/different owners, Unicode whitespace and 64/65-code-point boundaries, and save/load.
