# R-0450 — Shared radio-button appearance

1. Status: done
2. Updated: 2026-11-10
3. Related: existing Goto and settings use cases; visual presentation only.
4. Dependencies: existing framed settings radio skin and shared application styles.
5. Primary area: [A03](../areas.md#a03).
6. Related areas: A02 settings reuse; movement and colony choices retain existing rules.
7. Origin: user report of native-looking Goto choices on 2026-11-10.

## 1. Summary

1. Players need consistent radio buttons throughout the game, matching Settings.
2. Source inspection on 2026-11-10 found the framed radio skin restricted to the settings container; Goto consequently used the native skin.
3. Apply one shared style to all radio buttons, without per-screen styling or new artwork.

## 2. Behavior

1. Select a ship on the main map and press G: every destination choice uses the same framed indicator as Settings.
2. Selected and unselected indicators, focus, hover and disabled states retain the existing shared drawing behavior and black pen contours with flat fills.
3. Selecting a destination and confirming preserves the existing travel behavior; cancel leaves the order unchanged. Keyboard operation and exclusive selection remain native radio-button behavior.
4. Settings, colony choices and trade-route cargo choices use the same appearance automatically. No save data changes.

## 3. Implementation steps

1. Move radio selectors from SettingsControls.css into ToolbarControls.css, already imported by application screens and dialogs. Reuse FramedRadioButtonSkin without changing package responsibilities.
2. Extend GoToPage verification used by TC_103_F94_persistent_go_to_test to check the shared skin. Retain gameplay assertions and existing framed-settings rendering checks.
3. Run model/JUnit, targeted Goto/settings/cargo/colony UI scenarios, then smoke; apply the shared Java formatter and run documentation consistency and strict MkDocs.
4. Implemented and locally accepted on 2026-11-10. See [functional evidence](../../functional-tests.md#r-0450-shared-radio-buttons-2026-11-10) for source verification, test selections and results.
