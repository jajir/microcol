# R-0443 — Keyboard shortcuts footer and scrolling layout

1. Status: done
2. Updated: 2026-11-10
3. Related: UC-119 SUPPORT-001; [UX rules](../../ux.md).
4. Dependencies: existing shortcut editor and shared status bar.
5. Primary area: [A03](../areas.md#a03).
6. Related areas: none; presentation only.
7. Origin: user screenshots and implementation request, 2026-11-10.

## 1. Summary

1. Keyboard shortcuts needs the standard footer, scrolling introductory text and operation names aligned toward their shortcut controls.
2. Source inspection found the introduction outside the scroll pane and no status bar in the editor.
3. This change covers layout only and preserves shortcut capture, validation, Save and Cancel.

## 2. Behavior

1. Open Keyboard shortcuts from Settings: the title/actions remain above the scrolling body and the shared footer stays below it. During a game it shows the current gold and date.
2. Scroll down: the introductory explanation, platform and status text move with the operation list; the header and footer remain visible. Scroll up to read the introduction again.
3. Operation names align right, including wrapped lines, toward their shortcut controls in English and Czech.
4. Cancel discards changes and Save applies them using the existing behavior. Menu-origin access remains usable without a running game; smaller windows retain scrolling.

## 3. Implementation steps

1. Keep ownership in `gui.screen.setting.ScreenKeyboardShortcuts`; reuse `StatusBar`, place information and rows in one scroll content and right-align operation labels.
2. Extend `KeyboardShortcutsPage` layout checks and TC_84/10 and TC_84/12 for game/menu origins, both languages, scrolling and footer placement.
3. Apply the shared formatter, run model/JUnit, targeted TC_84 and page source contract, fixed smoke, documentation consistency and strict MkDocs.
4. Current result: implemented and locally accepted; 5,117 model/JUnit, 18 targeted UI/source-contract and 21 smoke/support tests passed without failures/errors/skips. [Acceptance evidence](../../functional-tests.md#r-0443-shortcut-footer-and-scrolling-2026-11-10).
