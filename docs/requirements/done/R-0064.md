## 1. Summary

1. The player needs a difficulty selection that is preserved and used by the rules that depend on it.

2. Migration observation (2026-10-14): The delivered setup slice did not implement the five difficulty levels or a saved difficulty profile.

3. Selected and refined on 2026-10-16 as a prerequisite for difficulty-dependent starting expeditions and game rules. This delivers setup and persistence; it does not claim the dependent numerical effects implemented.

## 2. Behavior

Agreed acceptance after refinement on 2026-10-16.

1. Setup offers Discoverer, Explorer, Conquistador, Governor and Viceroy, initially Conquistador. Choose any level and Start → the game displays that difficulty and saves it; Continue restores the same difficulty. Labels follow the selected English/Czech language without changing the stored identity.

2. Back/cancel leaves the active game unchanged. Invalid or missing required profile identity is rejected without guessing.

3. The saved profile supplies one authoritative difficulty to rule consumers. This requirement accepts setup/continuity only; game effects need separate worked examples under their own requirements.

4. Explicitly list remaining unsupported effects. Tory penalties are owned by R-0101; start-party differences use R-0066.

5. Accepted behavior (2026-10-15; [difficulty and national effects](../../gap-analysis.md#difficulty-and-national-effects)): Persist the five named difficulties, default new games to Conquistador and reject missing/unknown required saved profiles.
