# R-0419 — Minimapa bez rámečku při zaměření

1. Status: done
2. Updated: 2026-11-05
3. Related: UC-114/119; [UX](../../ux.md).
4. Dependencies: [R-0417](R-0417.md).
5. Primary area: [A03](../areas.md#a03) — zobrazení minimapy.
6. Related areas: A05 — zachování navigace mapy.
7. Origin: uživatel po vyzkoušení R-0417 žádá odstranit rušivý obdélník kolem zaměřené minimapy; implementaci výslovně zadal.

## 1. Summary

1. Zaměření minimapy nemá přidávat vnější obdélníkový rámeček.

## 2. Behavior

1. Kliknutí i klávesové zaměření minimapy nepřidá vnější rámeček; po ztrátě zaměření se její vzhled také nemění.
2. Vnitřní značka aktuálního výřezu světa zůstává zachována, stejně jako klikání, tažení, klávesnice, přístupný název a hláška při najetí.
3. Toto výslovné rozhodnutí nahrazuje požadavek R-0417 na viditelný rámeček fokusu; nejde o změnu pravidel nebo uloženého stavu hry.

## 3. Implementation steps

1. Ve stávajícím WorldMinimap odstranit focusFrame a související barvu; zachovat viewport a skutečný fokus. GUI je vlastníkem změny podle [architektury](../../architecture.md).
2. Upravit WorldMinimapPage.verifyMapFocus: ověřit skutečný fokus a absenci vnějšího rámečku, zachovat navigační kontroly TC196 a sdílený kontrakt page objektů.
3. Claude provede navazující úpravu, Codex revizi a formatter podle sdíleného profilu. Přejímka: celý model/JUnit, Docker TC196 a PageVerificationContractTest, pak smoke; dokumentační kontroly a strict MkDocs. Výsledky patří do funkční evidence, nikoli do zadání.

4. Implementace a lokální přejímka dokončeny 2026-11-05; [výsledky](../../functional-tests.md#r-0419-minimap-without-focus-frame-2026-11-05) potvrzují model/JUnit, cílené UI a smoke.
