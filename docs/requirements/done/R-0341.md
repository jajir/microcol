# R-0341 — Společné nadpisy herních pohledů a Mappa Mundi

1. Status: done
2. Updated: 2026-10-29
3. Related: UC-079, UC-114–119 v [katalogu use cases](../../use-cases.md), [společné nadpisy](../../ux.md#nadpisy-hernich-pohledu-navrh-2026-10-29).
4. Dependencies: [R-0337](R-0337.md) společný rám a boční odsazení, [R-0307](R-0307.md) herní pohledy, [R-0316](R-0316.md) společná tlačítka, [R-0342](R-0342.md) společný limit šířky obsahu lišt.
5. Primary area: [A03](../areas.md#a03).
6. Related areas: A01 navigace a kontextová nápověda; A06, A07 a A10 dodávají obsah a názvy pohledů.
7. Origin: žádost uživatele z 29. října 2026 o větší společné nadpisy vlevo a latinský název mapy s vysvětlením; následné schválení implementace s přesným zápisem **Mappa Mundi** a zachováním vzhledu tlačítek.

## 1. Shrnutí

1. Hráč pozná otevřený herní pohled podle jednotného výrazného nadpisu vlevo v horní liště. Akce zůstávají vpravo.
2. Mapa dostane nadpis **Mappa Mundi**. Kontextová nápověda vysvětlí jeho latinský význam a dobové používání latiny.
3. Uživatel schválil implementaci návrhu. [Evidence původního náhledu](../../publishing.md#r-0341-game-heading-proposal-2026-10-29) zůstává oddělená od přejímky hry.

4. Implementace a místní přejímka jsou dokončeny společně s šířkou obsahu R-0342. [Výsledky modelu, cíleného UI a smoke](../../functional-tests.md#r-0341-shared-game-headings-2026-10-29) jsou oddělené od neověřené vzdálené publikace.

## 2. Chování

1. Nadpisy všech herních pohledů používají stávající Playpen Sans, běžný řez a velikost 28. Pokud pohled nemá název, levá část zůstane prázdná. Úvodní nabídka, editor a dialogy do této změny nepatří.
2. Výška horní lišty zůstává 72 a společné minimální boční odsazení horní i dolní lišty 16. Podle R-0342 je jejich obsah společně vycentrovaný a má nejvýše 1 440 logických pixelů. Tlačítka se zarovnají doprava; jejich obrázky, rámečky, font, mezery uvnitř a stavy se nemění.
3. Při najetí na **Mappa Mundi** nebo zaměření klávesnicí se dole zobrazí „Mappa Mundi je latinsky „mapa světa“. Latina se tehdy běžně používala.“ Anglické rozhraní použije anglické vysvětlení, latinský nadpis zůstává stejný. Po opuštění nadpisu bez zbývajícího fokusu se obnoví předchozí kontext, pokud jej mezitím nenahradila novější zpráva. Zlato a rok zůstávají čitelné.
4. Nápověda neotevírá dialog ani nemění herní stav. Název kolonie si zachová přejmenování. Při nedostatku šířky se zachová dosavadní přechod akcí na ikony; nadpis a ovládání se nesmějí překrývat.

## 3. Kroky implementace

1. Vlastník je GUI podle [mapy odpovědností](../../architecture.md). `GameScreenHeader` sdílí umístění názvu a akcí mezi mapou a `InGamePage`; `GameScreenBars.css` je jediný vlastník stylu nadpisů a lišt. Jednotlivé pohledy dodávají názvy a akce.
2. Přenést existující nadpisy do lišty, zachovat jejich identifikátory a chování. Započítat nadpis do minimální šířky akcí. Vysvětlení mapy napojit na existující stavový panel a lokalizaci.
3. Rozšířit `TC_192_F225_in_game_layout_test`, `TC_21_F15_free_play_screen_navigation_test` a `TC_188_F221_game_toolbar_test` o společný font, umístění nadpisů, najetí/fokus/opuštění mapového nadpisu a malou šířku bez překryvu. Zachovat přejmenování kolonie, klávesové ovládání mapy, Kongres a nápovědu; před dokončením provést model, cílené Docker UI a pevný smoke výběr podle [lokální přejímky](../../publishing.md#local-acceptance-policy).
