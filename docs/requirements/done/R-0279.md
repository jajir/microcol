# R-0279 — Compact unit menu with a plain heading

1. Status: done
2. Updated: 2026-10-25
3. Related: UC-015/017/018/025 in [use cases](../../use-cases.md), [visual brief](../../graphics.md#soucasne-zadani-vzhledu), [UX guidelines](../../ux.md).
4. Dependencies: [R-0272](R-0272.md) map commands and [R-0276](R-0276.md) shared single-stroke menus and keycaps.
5. Primary area: [A03 — screens and shared UI language](../areas.md#a03).
6. Related areas: A05/A06 retain unit, cargo and colony actions; no model rule changes.
7. Origin: on 2026-10-25 the user selected the attached compact preview with a plain heading and one divider, and explicitly requested implementation.

## 1. Summary

1. Make the unit context menu shorter and immediately distinguish the unit name from the available commands.
2. The current menu at `20b15460` uses generous command spacing and multiple dividers. Its disabled unit-name item can still receive a selection-colored appearance from the menu skin.
3. Reuse the existing pen contours, cream paper, typography, shortcut keycaps and warm action selection without introducing another visual style.

## 2. Behavior

1. Opening a unit menu with the mouse or keyboard shows its localized unit name as plain, nonselectable heading text. Hovering or clicking that heading neither highlights an action nor closes the menu or changes the selected unit.
2. Exactly one horizontal divider appears immediately below the heading. The optional unit-choice submenu and all existing commands follow it; there are no further internal dividers.
3. Command rows have smaller vertical gaps, matching the attached preview, while preserving the font size and legible keycaps. Unavailable commands retain their full explanations; English and Czech fit narrow windows without overlapping rows.
4. Existing command order, available actions, unit selection, Escape/outside cancellation and single activation by mouse or keyboard remain intact. The colony dropdown retains its existing styling and behavior.

## 3. Implementation steps

1. Keep ownership in ButtonsGamePanel and ContextMenus.css. Retain the disabled native title item, suppress its selection appearance, place the only separator directly after it, and remove obsolete separator-visibility bookkeeping.
2. Reduce padding only around custom unit-command rows; preserve inner button faces, localized text, keycaps and model operations.
3. Extend TC11/05 and TC11/06 for the plain heading, single divider and compact geometry, and TC107/01 for actual heading hover/click followed by Jettison. Run all TC11, TC107 and TC188 scenarios, ContextMenuStyleTest and PageVerificationContractTest in Docker/Xvfb; review actual English/Czech screenshots. Apply the shared Java formatter, run the required model/JUnit plus fixed smoke gate, documentation checks and strict MkDocs.
4. Locally accepted on 2026-10-25: all 21 combined targeted checks and the fixed 4,748-check precommit gate passed with zero failures, errors or skips. Actual English/Czech screenshots, formatting and documentation validation are recorded in [functional evidence](../../functional-tests.md#r-0279-compact-unit-menu-2026-10-25). Publication remains independently unverified.
