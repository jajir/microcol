# R-0328 — Sjednocení pozadí nápovědy

1. Status: done
2. Updated: 2026-10-28
3. Related: UC-114/119 v [katalogu](../../use-cases.md).
4. Dependencies: [R-0325](R-0325.md), [grafický manuál](../../graphics.md).
5. Primary area: [A03](../areas.md#a03).
6. Related areas: A01 vlastní společný rám; pravidla a obsah se nemění.
7. Origin: žádost uživatele z 28. října 2026 o návrh stejného rozložení s barvou prostředního pozadí shodnou s horním a spodním panelem.

## 1. Shrnutí

1. Nápověda má zachovat rozložení Přímé úpravy R-0325 a působit jako souvislá krémová plocha. Uživatel následně požádal o implementaci a push bez testů; tato výjimka platí pro tento krok.

## 2. Chování

1. Změna nahrazuje béžové pozadí prostřední části `#EAE2CC` barvou `#FFF9EC`, která odpovídá horní a spodní liště. Jde o okolí a mezery kolem rejstříku a článku.
2. Poloha názvu, tlačítka, hledání, seznamu, článku i spodního stavu zůstává stejná. Vnitřní světlejší panely, rámečky, střídání řádků a pískový výběr tématu se nemění.
3. Změna zachovává písmo, obsah, hledání, klávesnici, posouvání, OK/Escape a nezměněnou partii. Náhled není důkazem změny běžící hry ani pixelově přesné přejímky.

## 3. Kroky implementace

1. Náhled v konverzaci vychází z [českého snímku R-0325](../../graphics-assets/help-refinement-2026-10-27/r0325-help-czech.png) na revizi `94a591ff`. Generovaný obrázek slouží k posouzení barvy; nepoužívá se jako runtime asset ani jako typografická předloha.
2. Místní `Colonizopedia.css` nastavuje `#FFF9EC` na kořen nápovědy, její vnější ScrollPane, viewport a pozadí svislých posuvníků. Ostatní obrazovky ani rozložení se neupravují; vlastnictví zůstává podle [architektury](../../architecture.md).
3. Uživatel dne 28. října 2026 výslovně zadal implementaci a push bez testů. Model/JUnit, Docker UI, smoke ani dokumentační testy a strict MkDocs se pro tuto implementaci nespouštějí. Byla provedena pouze kontrola diffu; barva v běžící hře není ověřena. Výjimku a skutečný rozsah zachycuje [evidence](../../publishing.md#r-0328-help-background-implementation-2026-10-28).
