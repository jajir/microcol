# R-0431 — Nastavitelná rychlost posunu mapy WASD

1. Status: done
2. Updated: 2026-11-08
3. Related: UC-114 (Hra), UC-119 (Regrese) v [use cases](../../use-cases.md).
4. Dependencies: existující předvolby a společný posuvník nastavení.
5. Primary area: [A03](../areas.md#a03).
6. Related areas: A02 — uložené nastavení; A01 — návrat z nastavení.
7. Origin: uživatelská žádost z 2026-11-08; implementace a návrh počáteční škály jsou autorizované.

## 1. Summary

1. Hráč potřebuje přizpůsobit rychlost posunu mapy klávesami WASD.
2. Současná rychlost má zůstat výchozí a patřit mezi nižší hodnoty.

## 2. Behavior

1. Nastavení obsahuje pojmenovaný posuvník „Rychlost posunu mapy (WASD)“, dostupný myší i klávesnicí, v češtině a angličtině.
2. Počáteční škála má devět poloh 1–9. Výchozí poloha 2 odpovídá dosavadní rychlosti; poloha 1 je poloviční a poloha 9 je 4,5násobná. Škála je výchozí návrh pro pozdější uživatelské doladění.
3. Změna se ihned uloží stejně jako ostatní předvolby. Návrat z nastavení ji neruší; po opětovném otevření i spuštění aplikace zůstane zachována.
4. Všechny směry WASD používají stejnou rychlost. Uvolnění klávesy zastaví příslušný směr. Ostatní způsoby posunu a rychlost animací zůstávají samostatné.

## 3. Implementation steps

1. Rozšířit existující `Setting` a `GamePreferences`; chybějící či neplatná uložená hodnota použije výchozí polohu 2. Zápis mimo rozsah odmítnout před změnou.
2. `WasdController` používá dvojnásobek polohy jako krok v pixelech. Přidat standardní posuvník do existujícího nastavení bez změny odpovědností balíčků.
3. Ověřit všechny směry, meze, okamžitou změnu a ukládání v JUnit; rozšířit TC_84/02 o ovládání a přenos předvolby do WASD, zachovat pořadí ovládacích prvků v TC_84 a TC_192.
4. Použít sdílený formatter; model/JUnit, cílené Docker UI a smoke; dokumentační kontroly a strict MkDocs. Výsledky zapsat do [funkční evidence](../../functional-tests.md#r-0431-wasd-scroll-speed-2026-11-08).
