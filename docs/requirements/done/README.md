# Completed requirements

Requirements with `Status: done` live here. Each file preserves its original ID,
agreed scope and acceptance evidence. A completed requirement does not imply
that its whole use case or work area is finished.

Follow the shared [status and file-location workflow](../README.md#file-locations).
Use the [current backlog](../backlog.md) for active work and the
[migration map](../migration-2026-10-14.md) for the original requirements' lineage.

One-off user-directed location exception, 2026-11-02: [R-0281](R-0281.md) is archived here with `Status: canceled`. Its placement does not signify completed implementation or successful acceptance.
