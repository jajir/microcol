## 1. Summary

1. A scout entering a marked lost-city tile should receive one intelligible result, with seasoned scouts receiving better odds, and cannot farm the same rumor again.
2. The 2026-10-17 catalogue source assessment at `f902be8a` reports no rumor marker or resolution state. R-0074 has since delivered the seasoned-scout roster/identity while its actual rumor interaction remains unfinished; this capture preserves that work and makes the missing effect explicit.
3. This requirement owns marker resolution, outcome application and persistence. Native anger state is consumed through [R-0153/R-0154](R-0154.md); sight and scout purchase are not rebuilt here.

## 2. Behavior

1. When an eligible explorer enters a rumor tile, resolve and report exactly one outcome, then consume the marker. The ordinary chances are empty 40%, gold 25%, recruit 15%, expedition lost 10% and burial site 10%; a seasoned scout uses 30/35/25/5/5% in that same order. Outcome selection belongs to the shared game random state, never to reopening a view or a save.
2. Gold awards a whole number from 200 through 500 uniformly; recruit places one free colonist on the explored tile; expedition lost removes only the explorer. A burial site adds the [accepted native anger](../../gap-analysis.md#native-and-european-relations) to the nearest native nation, and changes none if no native nation exists. If De Soto is in Congress, either bad outcome becomes empty instead.
3. A resolved marker is gone even when the result is empty or the explorer is lost. Revisiting, inspection and Continue do not award or punish again. An invalid or stale entry does not consume the marker or draw a result.
4. Save and Continue retain both the removed marker and applied result; each visible event explains the actual gain, loss or empty result. The burial effect is not accepted until the native-state owner and its player path exist.

5. Agreed 2026-10-20 ([shared rule](../../gap-analysis.md#r-0129-refinement)): Find the nearest native settlement to the disturbed burial tile; if several settlements are equally near, choose one uniformly using the persisted game random state and apply the agreed anger to its nation. Select among settlements, not uniformly among nations. Record the one resolved choice so Continue or inspection cannot reroll it; with no native settlement apply no anger.
