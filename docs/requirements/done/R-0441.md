# R-0441 — Simplify Settings slider and developer labels

1. Status: done
2. Updated: 2026-11-10
3. Related: UC-119 (Regrese), SUPPORT-001; [UX rules](../../ux.md).
4. Dependencies: [Settings alignment](R-0438.md), existing localization and preference persistence.
5. Primary area: [A03](../areas.md#a03).
6. Related areas: A01 menu/game navigation; A04 existing preference persistence.
7. Origin: User's Settings screenshot and implementation request, 2026-11-10.

## 1. Summary

1. Reduce redundant text on Settings while retaining the existing controls and their behavior.
2. Remove the effects value beside its slider, the standalone Developer heading and the diagnostic-information description. Replace map-scrolling numeric labels with localized Slow/Fast endpoints.

## 2. Behavior

1. Open Settings from the menu or a running game: Effects has no separate percentage or silent-value readout; Music retains its existing readout.
2. Map scroll speed shows Slow at the minimum and Fast at the maximum, with no intermediate numbers. Czech uses the existing localized speed labels. The underlying nine positions, keyboard increments and saved values remain unchanged.
3. Developer mode retains its labeled checkbox and shortcut hint, without the separate heading or description. Toggling, localization, Back and Escape retain existing behavior.
4. Slider changes still apply immediately and persist on reopening; no new confirmation or cancellation step is introduced.

## 3. Implementation steps

1. Keep ownership in `gui.screen.setting`, reuse the existing speed-label translations and formatter pattern, and remove redundant displayed labels without changing preferences or model rules.
2. Update TC_84/F75 page verifications for removed effects text, developer layout and localized scroll endpoints while retaining value, keyboard and persistence assertions.
3. Apply the shared formatter; run all model/JUnit checks, full TC_84 with PageVerificationContractTest in Docker/Xvfb, fixed smoke/support, documentation consistency and strict MkDocs.
4. Implemented and locally accepted: 5,117 model/JUnit, 18 targeted UI/source-contract and 21 smoke/support checks passed without failures, errors or skips. Results belong in the [functional evidence](../../functional-tests.md#r-0441-settings-labels-2026-11-10).
