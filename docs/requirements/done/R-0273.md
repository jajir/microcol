## 1. Summary

1. Make the top toolbar feel like the same hand-drawn game as the map, while making every action understandable from its icon and permanent text label.
2. The supplied screenshot mixes icon-only controls, text-only Congress/Retire buttons and a platform-styled colony selector. It is a visual reference, not evidence of a newly verified game build.
3. On 2026-10-25 the user selected **07B — Přirozený rukopis** from the [three refinements](../../graphics-top-menu-proposals.md) and explicitly requested its implementation. Preserve its motifs and clean layout, with small irregularities in the artwork and the agreed font.

## 2. Behavior

1. Every available toolbar action has one recognizable hand-drawn symbol and a permanent localized name. Existing action availability and meaning remain authoritative; leaving the game and ending it with a score remain separate actions. The selected family is 07 — Čistý skicář: preserve its clean structure while introducing small natural asymmetries, gently imperfect curves and non-identical repeated details in the icons. Keep consistent pen thickness and flat fills; do not obtain the hand-drawn effect by changing the agreed font.
2. Hovering a button or focusing it with the keyboard shows its explanation in the existing bottom status bar. Leaving the control restores the appropriate status message. The icon and short label remain visible without hover. O/Escape provides keyboard entry into the toolbar; Tab/Shift+Tab traverse its controls and Space activates the focused control. Map-focused Tab/Space retain their existing unit orders.
3. All icons share dark ink and one replaceable accent: olive green for annual turns, spring, summer and autumn; cool blue for winter. Both seasons use identical geometry on the existing cream background. Loading a game and beginning a human turn refresh the accent from the existing calendar. Color does not change action availability or meaning.
4. The colony selector has an enclosed hand-drawn field, a colony symbol, the localized name Colonies and a separate chevron. Opening it shows the current player's valid colonies by name; keyboard focus visibly marks the offered item. This is navigation to a colony screen, not a persistent colony selection, so no fictitious selected colony is shown. Escape or clicking outside closes it without choosing a colony; an empty list clearly explains that no colony is available.
5. The existing Playpen Sans 14 regular typography and [visual brief](../../graphics.md#soucasne-zadani-vzhledu) apply to implementation. A proposal sheet's enlarged headings, raster text or detail illustrations do not introduce a typography exception.

## 3. Implementation steps

1. Implement selected 07B using 48 px transparent icon tiles displayed at 40 px, permanent localized 14 px labels, native keyboard behavior and a thin irregular frame. Keep visible hover, pressed, focused and disabled states. Wrap the existing FlowPane at narrow widths rather than truncating labels. Include the conditional independence bell and retirement flag.
2. Reuse the GUI owners `ButtonsGamePanel`, `ColoniesMenu`, shared button/status-message support and `gui.image`, following the [package map](../../architecture.md). Preserve existing model operations and localization. No model-to-GUI dependency or save-format change is needed.
3. Redraw the selected art as editable SVG with fixed ink and replaceable accent, then follow the existing raster export/runtime pipeline. Do not use a complete concept-sheet PNG as a runtime button asset.
4. TC188/F221 covers labels, hover/focus, EN/CZ layouts, empty colonies, keyboard selection/cancel and season changes through real turns and Continue. TC38/TC01, TC81/TC04 and TC164/TC01 retain the affected colony, independence and retirement journeys. Required model/JUnit and Docker/Xvfb smoke gates remain mandatory under the [functional contract](../../functional-tests.md#r-0273-toolbar-07b-2026-10-25).
5. Locally accepted on 2026-10-25 after targeted UI checks, visual review, the mandatory 4,745-check precommit gate, shared formatting and documentation checks. Production implementation follows the chosen 07B motifs in editable SVG and exported PNG, with existing action handlers and native controls. The [graphics catalogue](../../graphics.md#navrhy-horni-listy-r-0273) owns asset dimensions, colors and export commands.
