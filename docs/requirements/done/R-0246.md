# R-0246 — Dřevěná běžná tlačítka bez bočních zářezů

1. Status: done
2. Updated: 2026-10-19
3. Related: P27/P28, [UC-119](../../use-cases.md); regresní kategorie, zachování hráčských cest TC21/TC24 a celé funkční sady.
4. Dependencies: [grafický manuál](../../graphics.md#minimalisticky-graficky-manual), existující standardní JavaFX ovládání.
5. Primary area: [A03](../areas.md#a03).
6. Related areas: A01 menu, A02 nastavení a dialogy A05–A10 používající společná tlačítka.
7. Origin: uživatel 18. října vybral variantu „Bez bočních zářezů“, zadal implementaci přes Codex a publikaci do main; následně výslovně vyňal tlačítka s dosavadním vlastním vzhledem.

## 1. Summary

1. Běžná tlačítka ve hře mají vypadat jako ručně kreslené a vybarvené dřevěné tabulky: černý mírně nepravidelný obrys, hladké boky a několik vnitřních čárek.
2. Inspekce main `39ed716c` dne 2026-10-18 našla společné styly hlavního okna a samostatné styly dialogů. Ikonová tlačítka a přepínače lodí mají vlastní obrázkové pozadí; některé statistické přepínače mají odstraněný standardní styl.
3. Mění se pouze standardní tlačítka a standardní přepínací tlačítka. Zachovat individuálně upravené ikonové ovládání, výběr lodí, statistické odkazy a malé stavební ovládání. Nativní souborový dialog a jiné druhy ovládacích prvků nejsou součástí změny.

## 2. Behavior

1. Hráč najde stejné akce na stejných obrazovkách i v modálních oknech. Popisky, ikony, dostupnost a herní výsledky se nemění. Čistě rozměrová omezení zůstávají zachována.
2. Běžný stav má světlou dřevěnou výplň, najetí světlejší a stisk tmavší výplň s mírným vizuálním posunem. Stisk se projeví i při ovládání klávesnicí; fokus, výběr a nedostupnost zůstanou rozeznatelné.
3. Šířka respektuje text, překlad a dosavadní rozložení. Krátké OK a dlouhý český popisek mají stejnou jmenovitou tloušťku obrysu. Kresba neblokuje kliknutí ani nepřekrývá text.
4. Kliknutí, Space, výchozí Enter a zrušení/Escape nadále používají původní JavaFX chování. Nedostupná akce se neprovede. Vlastní dosavadní vzhled vyňatých tlačítek zůstává beze změny.

## 3. Implementation steps

1. Sdílený vzhled vlastní `gui.util`: specializované standardní ButtonSkin/ToggleButtonSkin s kresbou v logických souřadnicích skutečné velikosti. Neměnit pravidla modelu, handlery ani ukládání. Styl připojit v hlavním okně i dialogových základech a explicitně zachovat uvedené vlastní styly.
2. Přibalit Caveat s licencí pro offline popisky běžných tlačítek. Kreslit obrys 2 logické px, detail 1 px, spodní hranu 1,5 px; delší tlačítko nezvětšuje tah.
3. Přidat TC83 a pojmenované page verifikace pro vzhled, stavy, různé délky, klávesnici a výjimky; zachovat existující TC21/TC24 i úplnou regresi. Použít Docker/Xvfb/Openbox, sdílený Java formatter, kontrolu skutečných screenshotů a přísný MkDocs build.
4. Zachovat neprotínající se panely plavby v Evropě i s vyššími běžnými tlačítky; ověřit TC71 včetně skutečného návratu lodi.
5. Místní přejímka dokončena 19. října 2026; výsledky a opravy eviduje [funkční ověření](../../functional-tests.md#r-0246-drevena-tlacitka-2026-10-18). Publikaci do main, distribuci, kompatibilitu a Pages ověřit samostatně pro výsledný commit.
