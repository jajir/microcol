# R-0270 — Separate game-wide controls from unit commands

1. Status: done
2. Updated: 2026-10-25
3. Related: P28/P27 in the [implementation plan](../../implementation-plan.md), UC-011 and UC-114/119 in the [use-case catalogue](../../use-cases.md), [UX guidelines](../../ux.md).
4. Dependencies: existing unit orders, navigation, dialogs and model validation; the main-screen layout from [R-0262](R-0262.md).
5. Primary area: [A03](../areas.md#a03), discoverable and consistent game controls.
6. Related areas: A01 owns leaving the game; A04 ending a turn; A05 unit orders; A06 ship cargo; A07 colony founding; A10 Congress, independence and retirement. Their rules remain unchanged.
7. Origin: user screenshot and request on 2026-10-25 to classify every top-bar control into game-wide navigation or the selected unit's context. Implementation selected by the user on 2026-10-25 after reviewing the classification.

## 1. Summary

1. Keep the top bar focused on the game, reports and map navigation. Put orders for a particular unit in that unit's contextual action menu.
2. Source inspection on 2026-10-25 at `fb6ee004765c15253691fb26ba456dc447b2784e` identifies 20 controls in the supplied screenshot: nine belong to the unit context and eleven to the game-wide bar. Other controls appear conditionally. This inventory is not an interactive player test.
3. The requested separation is agreed; the classification and access design below were accepted for implementation on 2026-10-25. Cover existing controls, including conditional and cancellation variants. Do not change game rules, command shortcuts, save data or the startup menu, or add new artwork for this change.

## 2. Behavior

1. Accepted unit-context inventory: screenshot order first, then conditional controls.

    | No. | Existing control | Reason and agreed context |
    | --- | --- | --- |
    | 1 | Build new colony — colony icon | The selected colonist founds a colony on its square. |
    | 2 | Move unit — walking figure | Starts movement for the selected unit. |
    | 3 | Wait (Tab) | Selects another available unit without spending movement. Keep the Tab shortcut. |
    | 4 | Skip turn (Space) | Spends this unit's remaining movement; it does not end the player's turn. Prefer a label explicitly naming the unit. |

    | 7 | Go to / Cancel go-to | Assigns or cancels this unit's destination. |
    | 8 | Go to colony | Sends this unit to a reachable own colony; it does not open the colony overview. |
    | 9 | Disband | Permanently removes the unit; keep existing confirmation and consequences. |
    | 10 | Plow field / Cancel plowing — conditional | Work performed by the selected pioneer. |
    | 11 | Clear forest / Cancel forest clearing — conditional | Work performed by the selected pioneer. |
    | 12 | Build road / Cancel road building — conditional | Work performed by the selected pioneer. |
    | 13 | Jettison goods — conditional | Discards cargo from the selected ship; keep quantity selection and confirmation. |

    | No. | Existing control | Reason to keep it in the top bar |
    | --- | --- | --- |
    | 1 | Colonies | Navigates the player's colony list. |
    | 2 | Congress | Opens national politics and founder recruitment. |

    | 11 | Leave game — door | Returns to the game menu through the existing safe-exit flow. |
    | 12 | Declare independence — conditional | Changes the nation's state, although the current code groups it near unit controls and reuses the plowing icon. |

3. Provide one menu for the selected own unit, available from a visible **Actions** control in its right-side detail card, right-click on that card and the standard context-menu keyboard action. Identify the unit and separate movement, orders, work and destructive actions. Preserve direct movement and command shortcuts. Opening/dismissing the menu changes no game state; Escape cancels an unconfirmed destination/dialog as before. Preserve right-button map dragging.
4. Show actions relevant to the unit. Explain temporarily unavailable actions under the [shared UX rule](../../ux.md#kdy-akci-skryt-a-kdy-vysvetlit-jeji-nedostupnost). Foreign/no selection must not expose another unit's orders. Changing selection must close or refresh an open menu; recheck state on confirmation and retain rejection feedback.
5. Move the current go-to destination/status text beside the unit's details so an active/paused route remains visible with the menu closed. It is unit information, not a global button. Global controls retain their existing game/phase eligibility independently of unit selection. Check 1000×700 and 1280×850 layouts without clipping controls or obscuring the map. No new save fields are needed.
