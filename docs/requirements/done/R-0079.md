## 1. Summary

1. The player needs an industrial upgrade to change production as described while conserving the raw materials actually used.

2. Migration observation (2026-10-14): Admission and several costs/chains were corrected by R-0025. Existing production constants do not establish every upgrade’s intended input/output effect.

3. Scope: the outcome and examples below. Selected and refined on 2026-10-16; it does not reopen the delivered origin scope or close a whole UC.

## 2. Behavior

Agreed acceptance, refined on 2026-10-16.

1. Keep workers and available inputs equal before/after an upgrade → show the agreed improvement and use it in the next turn.

2. Apply the manual’s stated sawmill output/input doubling, magazine improvement and arsenal half-tools-per-equal-musket-output rules to their proper chains.

3. With insufficient input, limit actual output consistently; multiple workers and industries cannot consume the same stock twice.

4. Factory founder eligibility is owned by R-0084. This requirement owns production arithmetic, including tools/luxury chains, without inventing a universal factory ratio.

5. Accepted behavior (2026-10-15; [economy, production and education](../../gap-analysis.md#economy-production-and-education)): Use the explicit per-tier input/output budgets and shared shortage/rounding order for each affected industry.
