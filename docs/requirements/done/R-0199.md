## 1. Summary

1. The religion advisor explains actual cross production, accumulated crosses and distance to the next immigrant.
2. This requirement owns the coherent report, not cross generation or immigration settlement.

## 2. Behavior

1. Show current per-colony/national cross output as applicable, accumulated progress and the actual next-immigrant threshold/remainder from the shared model. A founder/building/worker change updates the displayed production; a successful immigration updates progress once.
2. Pending human immigrant selection, canceled report viewing and Save/Continue do not consume crosses or recruit again. Keep other players' private progress hidden and show labels/numbers independent of color.
3. UC-114 checks multiple colonies, unattended/staffed crosses, threshold before/at/after, pending choice, founder effect and reload against model values.

4. Consume the accepted 2026-10-20 rules from [R-0146](../../gap-analysis.md#r-0146-refinement); preserve this requirement’s own outcome and existing delivered behavior. These decisions do not establish this consumer’s implementation or acceptance.

## 3. Implementation steps

1. Reuse the shared colony production and recruitment owners to expose an immutable current-owner religion report: named per-colony current cross output, national output, accumulated immigration crosses, current target, remaining crosses and pending earned choices. Validate owner identity against the current model; never read a same-named player from another game. Do not duplicate founder, production or immigration formulas in the GUI or maintain another counter.
2. Add a localized EN/CS religion tab in the existing statistics navigation. Clearly distinguish current output from accumulated progress and pending choices. Rebuild on opening; building, worker or founder changes are reflected without advancing time. Display blocked/ineligible immigration according to the existing model instead of inventing a threshold. Closing or revisiting must not settle an offer, spend crosses or recruit.
3. Model tests cover multiple colonies, unattended and staffed production, shared founder effects, before/at/after threshold, pending choices, identity/viewpoint isolation and purity. TC167 exercises the real report, a production change, earned/pending immigration and Save/Continue with stable counts/resources. Reuse existing religious-production and immigration fixtures/page objects and preserve their gameplay assertions.
4. Main reviews architecture and UI, applies the shared formatter and runs all JUnit plus relevant Docker/Xvfb scenarios. Full local batch acceptance is required before marking done.
