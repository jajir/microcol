## 1. Summary

1. A player needs an explicit way to remove an owned unit permanently while keeping passengers, goods and saved selections safe.
2. The 2026-10-17 catalogue source assessment at `f902be8a` identifies a model deletion operation already used by combat, but no player disband command. This capture does not treat the deletion primitive as missing.
3. This requirement owns command eligibility, confirmation, removal and player-facing cleanup. It does not change combat destruction or replace cargo-transfer rules.

## 2. Behavior

1. The current player can select an owned eligible unit and choose Disband. The confirmation identifies the selected unit; accepting removes it from the world, active selection and saved game once. Cancel changes nothing. Disbanding the last resident is refused to avoid silently destroying the colony and its receiving warehouse; existing minimum-resident departure limits also apply.
2. A ship or wagon must be empty before disbanding. Passengers and goods must be unloaded first; a loaded carrier is refused with a usable reason and no change to carrier, passenger or goods state. Foreign or stale unit selection, invalid game phase and repeated confirmation reject without deleting another unit.
3. Any continuing order on the disbanded unit ceases with it, without performing its pending work or route step. Disband never advances the turn, settles a voyage or credits unfinished work. After Continue, the removed unit cannot reappear or remain selected.
4. This player command does not alter the separately delivered combat-destruction result or imply that every UC-016 cancellation variant has passed.

5. Agreed 2026-10-20 ([shared rule](../../gap-analysis.md#r-0131-refinement)): On confirmed disbanding in an owned colony, return all actual equipment, including tools, horses and muskets, to that colony; outside an owned colony all equipment is lost. Confirmation shows exact quantities retained and lost. If warehouse capacity is exceeded, discard only the excess after explicit overflow confirmation; cancel changes nothing. Carrier cargo/passengers must still be unloaded first. Do not invent equipment.
