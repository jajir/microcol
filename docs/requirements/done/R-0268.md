# R-0268 — Keep grid inside exploration and share Regular button text

1. Status: done
2. Updated: 2026-10-25

4. Related: [R-0261](R-0261.md), [R-0267](R-0267.md), [visual brief](../../graphics.md#soucasne-zadani-vzhledu); UC-006, UC-114 and UC-119 in [use cases](../../use-cases.md).

## 1. Summary

1. The dashed grid must not leave protruding lines in gray unexplored areas, including rounded edges inside explored squares.
2. Menu and other shared buttons must use the same agreed Regular font as the gameplay screen, without the heavier Medium override.

## 2. Behavior

1. Enabling the grid shows dashed lines only on revealed map artwork. Rounded gray exploration edges cover the grid and retain their existing shape; tile joins have no protruding ink marks.
2. Scrolling, resizing, exploring and Save/Continue preserve this behavior. Turning the grid off leaves no grid marks; hidden terrain and animations remain hidden.
3. Shared wooden buttons in menu, settings, dialogs and game screens use Playpen Sans Regular 14 without extra weight. Their labels, focus, hover, pressed and disabled states remain readable and functional.
4. This correction changes button weight and fog compositing; it does not redesign layouts, title sizes, terrain or game rules.
