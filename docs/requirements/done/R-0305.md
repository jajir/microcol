## 1. Summary

1. The player wants wave lines to fit the map's existing pen outlines. The first three proposals were too thick and retained an unwanted teal color; only the final black-line proposal was approved.
2. At `8d9af870`, ocean waves use dark teal, High Seas waves use cyan, and their main stroke is 0.6 logical pixels. This is source inspection, not runtime verification.
3. Change only wave color and line weight. Preserve the approved wave geometry, movement, placement, terrain colors and meaningful map symbols.

## 2. Behavior

1. On opening or continuing a game, ocean and High Seas waves use black lines with the same visual weight as the boundary between explored and hidden map areas, following the [approved preview](../../graphics-assets/wave-contours-2026-10-27/selected-black.png).
2. The existing six-second swell, crest, fall and fading wash continue with the same shapes and timing. The line fades with the existing animation; black does not mean permanently opaque water marks.
3. The High Seas direction marker, lake artwork, sparse ocean placement, overlay priority and hidden terrain retain their existing behavior. Static previews use the same corrected crest.
4. The change is automatic and has no confirmation or cancellation step. Panning and Continue preserve the existing map and animation phase behavior; saves and game rules do not change.

1. Keep ownership in `gui.image`: update the shared wave definitions and colors in `terrain-symbols.svg`, then export `terrain-symbols.png`. Use a 1.6-logical-pixel black stroke for the wave and wash, matching the existing map outline target.
