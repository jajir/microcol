## 1. Summary

1. Make the minimap presentation fit the game's pen-drawn style: remove the dashed outer frame, place the heading “Minimap” above the map in the existing handwritten text style, and remove the visible instruction below it.
2. Implement the selected [middle proposal](../../graphics.md#minimapa-nadpis-a-hladkost-pobrezi-30-rijna-2026): gently round the corners while preserving the coastline's recognizable steps and strong ink outline. The user's explicit choice of the middle alternative determines the smoothing level.

## 2. Behavior

1. The centered heading reads “Minimap” in English and “Minimapa” in Czech, in the same font and size as the bottom status bar. The dashed outer frame and visible bottom explanation disappear; map scale, terrain colors, gray unexplored area, solid map border and rectangular camera indicator remain.
2. Gently round land/sea and known/unknown corners. Straight boundaries, diagonal contacts and three-way intersections remain readable; the viewport stays rectangular.
3. Preserve click, drag and arrow-key navigation, keyboard access, viewport tracking and concealed terrain. Smoothing uses only already permitted colors; it does not inspect unknown terrain or change game rules.
4. Keyboard focus underlines the heading; Tab leaves the control and removes that underline. The localized instructions remain accessible help without a visible footer.

## 3. Implementation steps

1. Use the supplied screenshot as the edit reference; produce the baseline proposal, then derive both smoothing alternatives from it with built-in ImageGen. Preserve the three outputs, input and exact prompts in the [gallery](../../graphics.md#minimapa-nadpis-a-hladkost-pobrezi-30-rijna-2026).
2. Record design-only inspection and documentation checks in [publication evidence](../../publishing.md#r-0356-minimap-refinement-proposals-2026-10-30). Generated lettering and contours are visual approximations, not a pixel-exact runtime specification.
3. Update `WorldMinimap`, existing localization keys and scoped sidebar styling. Replace the bottom label with a heading using shared Playpen Sans 14, bind underline to focus and preserve accessible help and input handlers. No new package or model dependency is needed; the PNG proposals remain documentation references.
   Keep the multiline terrain description's preferred height in `RightPanelView` so the heading cannot squeeze out its movement-cost line in a small window.
4. Round isolated sea/land/fog corners with short quadratic curves at 30% of a projected tile, capped at 2.4 logical pixels. Trim adjacent ink segments and fill only the cut corner with a neighboring permitted color. Land terrain shades share one coastline category; straight edges, diagonal contacts, three-way junctions and the frame stay intact.
5. Four `WorldMinimapTest` checks cover geometry boundaries. Extend TC196/01–02 for heading, shared font, layout, missing footer and focus without a dashed frame, retaining all gameplay/navigation assertions and TC196/03 dragging. Run model/JUnit, targeted TC196/TC188/TC192 plus `PageVerificationContractTest`, then fixed smoke/support. Review EN/CZ and small-window captures and validate documentation; [implementation evidence](../../functional-tests.md#r-0356-minimap-heading-and-rounded-coasts-2026-10-30).
