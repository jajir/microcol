# R-0284 — Unit reference in Colonizopedia

1. Status: done
2. Updated: 2026-10-25
3. Primary area: [A03](../areas.md#a03), shared player information.
4. Related: [R-0269](R-0269.md), UC-114/119 in [use cases](../../use-cases.md).
5. Dependencies: A05 unit definitions, A06 transport and purchase prices, A07 expertise, A09 combat roles. Existing rules remain authoritative.
6. Origin: the user requested a Units help topic listing every unit and its properties on 2026-10-25; selected for implementation in this request.

## 1. Summary

1. Players need to recognize the units they can encounter and compare their abilities without leaving the game.
2. Extend the existing illustrated terrain reference with Units / Jednotky, retaining the same navigation and search.

## 2. Behavior

1. Open help with its map button or H, then select Units. List all supported unit types with localized names and existing game pictures, including all specialists, six ships, artillery, wagons, native braves and treasure trains.
2. Show land/water movement, base movement allowance, cargo holds, passenger space required, initial Europe purchase price or unavailable, production expertise and applicable pioneer abilities. Explain conditional equipment and role effects separately from base type properties; an unavailable purchase is never described as free.
3. Search finds localized unit names, ignoring case and accents. Long content wraps and scrolls through the last unit. Both English and Czech are supported.
4. OK or Escape returns to the same game. Reading, searching and closing help changes no turn, treasury, units, cargo or stored game.

## 3. Implementation steps

1. Reuse the existing two-column Colonizopedia table, localized unit names and ImageProvider; read current UnitType definitions without accessing the running game. No new assets, dependencies or save schema.
2. Extend localized topic/name search and EN/CZ resource keys; explain base values and role-dependent abilities in player language.
3. Extend TC_100_F91 with named EN/CZ unit scenarios, all-type/name/image coverage, representative values, search, scrolling, keyboard closing and unchanged-state checks. Preserve existing scenarios and PageVerificationContractTest.
4. Apply the shared formatter, review screenshots from Docker/Xvfb, run targeted scenarios, the fixed model/JUnit plus smoke gate, documentation checks and strict MkDocs. Completed locally: the 12-check targeted set, corrected Czech scenario, 4,748-check fixed gate, shared Java formatting, screenshot review, nine documentation checks and strict MkDocs passed. See [dated acceptance evidence](../../functional-tests.md#r-0284-unit-help-2026-10-25). Remote publication is independent and unverified.
