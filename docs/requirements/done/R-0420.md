# R-0420 — Příjemce práce v panelu jednotky místo mapy

1. Status: done
2. Updated: 2026-11-06
3. Related: UC-032/114/119; [UX](../../ux.md).
4. Dependencies: [R-0405](R-0405.md), [R-0414](R-0414.md).
5. Primary area: [A03](../areas.md#a03) — informace o vybrané jednotce.
6. Related areas: A07 — čtení existujícího pracovního přiřazení, A05 — zachování mapového výběru.
7. Origin: uživatel doložil žlutý nápis „Works for New Amsterdam“ překrývající mapu a výslovně žádá přesun do pravého panelu u obrázku pracovníka, s implementací přes Claude.

## 1. Summary

1. Informace o městě, pro které pracovník pracuje, patří k jeho popisu v pravém panelu a nesmí zakrývat mapu.

## 2. Behavior

1. U pracovníka s přiřazeným městem pravý panel zobrazí lokalizované „Pracuje pro <město>“ / „Works for <colony>“ v textu vedle jeho obrázku, pod stávajícími údaji. Dlouhý název se zalomí a zůstane čitelný.
2. Žlutý nápis příjemce práce se na mapě nevykresluje. Obrázek jednotky, pracovní značka a národní vlajka zůstávají zachované.
3. Po změně výběru nebo zrušení práce panel odpovídá aktuální jednotce a jejímu přiřazení; u jednotky bez pracoviště údaj není. Existující text stavového řádku není tímto požadavkem rušen.
4. Změna neovlivní práci, pohybové body, produkci, zrušení práce, rybáře ani uložený stav. Platí v češtině i angličtině; běžné klikání a dvojklik zůstávají zachované.

## 3. Implementation steps

1. Stávající GUI vykreslení PaintService.paintWorkerRecipient a jeho volající odstranit; informaci číst z Unit.getWorkingColony ve stávajícím UnitPanel bez modelových změn. Vlastnictví odpovědností podle [architektury](../../architecture.md).
2. Rozšířit stávající WorldWorkersPage/TC201 o zobrazení příjemce v panelu, zmizení po zrušení práce a oba jazyky; zachovat herní aserce. Doplnit potřebné ověření rybáře TC202 a výběru/práce TC204, screenshot mapy a pravého panelu. Přesný výběr se zaznamená ve funkční evidenci.
3. Claude provede implementaci a testy; Codex review, sdílený Java formatter, celý model/JUnit, cílené Docker/Xvfb scénáře, smoke a dokumentační přejímku. Archivovat jako done až po přejímce.

4. Implementace a lokální přejímka dokončeny 2026-11-06; [výsledky](../../functional-tests.md#r-0420-worker-recipient-in-right-panel-2026-11-06) potvrzují model/JUnit, cílené UI, kontrolu snímků EN/CS a smoke.
