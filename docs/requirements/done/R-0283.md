## 1. Summary

1. Keep the main map toolbar in one row so shrinking the window does not consume additional map height.
2. This supersedes R-0278's wrapping behavior only for the game toolbar. Other screens retain their layouts.

## 2. Behavior

1. Show icons with names whenever all available actions fit in one row. When they would not fit, hide every toolbar name together and retain the icons, frames and colony dropdown arrow.
2. Restore every name when the window is wide enough again. Compute the fit from actual localized labels and available actions, including conditional independence and retirement; do not use a fixed language-dependent breakpoint.
3. Keep hover/focus explanations, accessible names, keyboard shortcuts, focus cues, dropdown selection/cancellation and gameplay effects. Names are hidden visually rather than removed from the controls.
4. The minimum main-window width accommodates the complete icon row, including native window borders. Resizing cannot hide actions beyond the edge or produce a second row. Other existing minimum-width constraints are preserved.

## 3. Implementation steps

1. Reuse `ButtonsGamePanel`, its existing control maps and `FlowPane`. Measure full and icon-only preferred widths after CSS, switch `ContentDisplay` for all controls, and update after width, language/font, managed-state and child-list changes. Retain the existing spacing and assets; no package, model, dependency or save-format change.
2. Extend TC188/F221 and `GameToolbarPage` for EN/CZ wide–narrow–wide transitions, boundary widths, an extremely narrow resize, accessible names, hover/keyboard use and colony dropdown behavior. Cover an available independence action through TC81/F73 without weakening its gameplay assertions.
3. Apply the shared Java formatter, run targeted Docker/Xvfb tests and review screenshots, then run all model/JUnit tests plus the fixed smoke gate, documentation consistency checks and strict MkDocs. Record actual selection/results in [functional evidence](../../functional-tests.md#r-0283-one-row-toolbar-2026-10-25).
