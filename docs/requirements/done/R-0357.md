## 1. Summary

1. Show five further complete building sets that belong beside the current map's sparse hand-drawn symbols.
2. Preserve useful profession attributes and the pronounced architectural progression while removing elaborate textures, lighting and decorative detail.

## 2. Behavior

1. Each of five alternatives covers all 41 existing forms across 16 families: 205 illustrations in total. Do not invent missing levels.
2. Use simple, slightly irregular dark contours, a small muted palette, solid color areas and a few large shapes. The supplied map is the authoritative style reference for these proposals.
3. The first level is an open lean-to with essential equipment or a basic paddock; the second is a modest single-storey building; the third is a larger two-storey manufactory around 1800. Defensive, maritime, civic, educational and religious families use corresponding functional forms.
4. Preserve a small number of clearly recognizable profession attributes. Distinguish alternatives by contour, shape or viewpoint, not extra ornament.
5. Deliver comparison sheets only. Existing runtime artwork, gameplay, construction names, prices and production remain unchanged. Raster proposals are design references; eventual production graphics still require genuine editable SVG.

## 3. Implementation steps

1. Reuse the existing graphics gallery and family mapping, verify the mapping against `ConstructionType`, and number the new directions 6–10 to distinguish them from the earlier round.
2. Generate two sheets per alternative from the supplied map reference, retain exact prompts and originals, and inspect all rows for coverage, level differences and style agreement.
3. Record the user's rejection of the earlier style alongside the previous gallery without replacing historical assets. Link this requirement and design evidence from the authoritative graphics documentation and backlog.
4. Delivered and visually reviewed all ten final sheets, with 41 identities and 16 exact upgrade chains checked against the model.
