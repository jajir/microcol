# R-0429 — Papírové pole názvu obchodní trasy

1. Status: done
2. Updated: 2026-11-08
3. Related: [UC-029](../../use-cases.md), [vzhled hry](../../graphics.md).
4. Dependencies: existující editor obchodní trasy a geometrie společného rámečku tlačítek.
5. Primary area: [A03](../areas.md#a03).
6. Related areas: A06 — zachování tvorby obchodní trasy.
7. Origin: uživatel 2026-11-08 požádal o výchozí herní formátování a upřesnil papírové pozadí a černý ručně kreslený rámeček.

## 1. Summary

1. Hráč má při vytváření obchodní trasy zadávat název do pole ve stejném papírovém stylu jako okolní dialog.
2. Dosavadní pole má bílý výchozí vzhled JavaFX; změna se týká pouze pole názvu v tomto formuláři.

## 2. Behavior

1. Po otevření formuláře má pole ploché papírové pozadí, lehce nepravidelný černý rámeček přibližně 2 logické pixely a dosavadní herní písmo.
2. Při zadávání názvu je fokus rozeznatelný plochým zvýrazněním pozadí. Text zůstává čitelný, výběr a klávesnice fungují jako dosud.
3. Vytvoření, validace názvu a zrušení formuláře zachovají dosavadní výsledky; další ovládací prvky se nemění.

## 3. Implementation steps

1. V GUI použít styl omezený na pole názvu a černou variantu existující vektorové geometrie rámečku. SVG je zdroj, PNG opakovatelný dvojnásobný export podle manifestu; odpovědnosti balíčků se nemění.
2. Rozšířit TC116/01 a jeho page object o ověření vzhledu bez fokusu i při psaní; zachovat vytvoření, zrušení a obnovení trasy i snímek formuláře.
3. Provést sdílené formátování Java, model/JUnit, cílené Docker TC116 a PageVerificationContractTest, pevný smoke do 420 sekund, dokumentační kontroly a strict MkDocs. Ověřit zdroj SVG, opakovatelný export a snímek z UI.

4. Implementováno a lokálně přijato 2026-11-08; [výsledky a snímky](../../functional-tests.md#r-0429-trade-route-name-input-2026-11-08).
