## 1. Summary

1. Contributors need a compact shared reference for palette, typography, controls, lines and materials when choosing how MicroCol should look.
2. The existing brief defers detailed styling; the user now selects a minimal written manual, retaining the existing game's hand-drawn character.
3. This outcome records design decisions and scaling safeguards. It does not implement a redesign, replace assets, select final fonts or deliver the later visual specimen sheet.

## 2. Behavior

1. A contributor opens the graphics page and finds one authoritative manual covering the accepted ink-on-paper style, flat fills, controls and their states, typography, spacing, material meanings and initial palette.
2. A small and large instance of the same line role should have equal nominal thickness at the same UI scale. Intentional detail/outline/emphasis roles remain distinct; system accessibility scaling still applies to the whole interface.
3. The manual explains ordinary SVG scaling, non-scaling strokes, raster-export limitations and loss of detail at small sizes, with a numeric example and checks at final display size.
4. Agreed direction, provisional numeric choices and future runtime acceptance are distinguished. Existing game assets, behavior and saves remain unchanged.

## 3. Implementation steps

1. Refine this documentation-only scope from the accepted discussion, then update the existing graphics page; link shared UX and active R-0222/R-0224/R-0225 to the relevant rules without changing their readiness.
2. Verify SVG semantics against the W3C specification. Keep UI/image ownership under the existing architecture; no Java/package/build-output changes are needed.
3. Run the documented launcher and documentation unit checks, strict MkDocs, and inspect the rendered manual and requirement. Record acceptance in the publishing evidence; verify Pages deployment and intentional game-job skips after push.
4. Current result: manual recorded; 21 launcher tests, nine documentation tests and strict MkDocs passed. Browser inspection confirmed readable manual layout. See [dated acceptance and delivery evidence](../../publishing.md#minimal-graphics-manual-2026-10-18). Runtime implementation and its acceptance remain separate.
