# R-0426 — Otevření detailu obchodní trasy dvojklikem

Status: done

## 1. Summary
1. Zadání uživatele z 2026-11-08: v plánovači obchodních tras otevřít podrobnosti dvojklikem na trasu v seznamu „Your routes“. Hlavní oblast [A03](../areas.md#a03); závislost A06 na existující správě tras, UC-029/030 podle [use cases](../../use-cases.md).
2. Jde o další vstup do existující správy zastávek, zboží a dopravců. Pravidla tras ani uložená data se nemění.

## 2. Behavior
1. Hráč v plánovači dvojklikne levým tlačítkem na neprázdný řádek své trasy. Otevře se stejná správa jako tlačítkem „Stops, goods and carriers…“, s právě kliknutou trasou, i když předtím byla vybraná jiná.
2. Jednoduchý klik dál pouze vybírá náhled. Dvojklik na prázdnou část seznamu nebo jiným tlačítkem editor neotevře. Zakázané editační tlačítko nelze obejít dvojklikem.
3. Zpět a Escape používají dosavadní návrat do plánovače se zachovanou vybranou trasou. Samotné otevření a zavření nic nezmění na trase ani dopravcích; dosavadní potvrzení změn zůstává stejné.

## 3. Implementation steps
1. V `gui.screen.game.components.TradeRoutePlanningPanel` připojit dvojklik na neprázdné buňky k existujícímu tlačítku editace. Zachovat vlastníka pravidel podle [architektury](../../architecture.md); nejsou potřeba nové modelové operace, texty ani grafika.
2. Doplnit page object a `TC_119_F110_trade_route_edit_test.TC_09_planner_double_click_opens_the_clicked_route_details`: výběr bez otevření, dvojklik na jinou i již vybranou trasu, její zastávky a návrat přes Escape/Zpět. Stávající TC119/07 zachová ověření tlačítka a oprav zastávek.
3. Sdílený Java formatter, review, všechny model/JUnit testy, cílený Docker/Xvfb TC119 a PageVerificationContractTest, pevný smoke do 420 sekund, dokumentační kontroly a strict MkDocs. Výsledky zaznamenat do [funkční evidence](../../functional-tests.md#r-0426-planner-double-click-2026-11-08).
4. Implementováno a lokálně přijato 2026-11-08. Model/JUnit, cílené UI, smoke a dokumentační kontroly prošly; přesné výsledky vede [funkční evidence](../../functional-tests.md#r-0426-planner-double-click-2026-11-08). Vzdálená publikace není ověřena.
