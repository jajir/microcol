## 1. Summary

1. The player needs a new map choice that produces a valid, playable world and can be reproduced for verification.

2. Current situation: The current setup selects bundled maps, including R-0027’s RivalExpedition; it does not generate a New World from climate/landmass choices.

3. Scope: the outcome and examples below. This is captured work awaiting individual refinement; it does not reopen the delivered origin scope or close a whole UC.

## 2. Behavior

1. The [accepted resource-overlay boundary](../../gap-analysis.md#economy-production-and-education) permits all land bonuses on land and fishery on ocean/lake. Generator distribution must choose natural placement within that boundary; its frequencies remain provisional.

Acceptance refined by the 2026-10-20 user answers; inherited resolved decisions remain agreed.

1. Agreed first-version controls (2026-10-19): use the reference world dimensions, cold/temperate/warm climate, low/medium/high land share and an explicit seed. Preview these choices and start a valid generated world. See the [shared decision](../../gap-analysis.md#generated-world-first-version).

2. The generated world has legal sea access, arrival lanes and usable starting positions for its participants; it must support the existing outward-voyage rule. A generated reference world includes actual native nations, settlements and associated braves from R-0150/0151, not only model types that exist in isolated fixtures. A valid deliberately configured no-native scenario remains possible if that setup contract allows it.

3. Back or failed generation leaves the active game and Continue unchanged and explains the failure.

4. Identical agreed generation inputs and seed reproduce the same starting terrain. Saving/continuing preserves the actual generated world.

5. Agreed 2026-10-20 ([shared rule](../../gap-analysis.md#r-0065-refinement)): Use low/medium/high land shares of 25/40/55%, each with a tolerance of five percentage points, with most land in one to three large connected masses and remaining islands. Climate shifts cold/warm latitude bands; terrain forms coherent regions. Rivers run from uplands to water without loops; a main river has at least eight tiles, shorter rivers are small. Approximately 10% of suitable tiles receive a resource: minerals preferentially hills/mountains; timber/game/trapping forests; oasis desert; crops naturally productive terrain; fish coastal water or lakes. Exact terrain weights and generation algorithms are delegated implementation choices within these limits, checked with fixed seeds. Preserve already agreed dimensions, controls, seed reproducibility, legal arrival lanes and native-world dependencies.
