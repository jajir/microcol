## 1. Summary

1. Recruiting Jefferson, Paine or Hudson changes the matching ongoing production, including existing colonies, without granting free stock.
2. The 2026-10-17 catalogue's missing-effect observations are historical; membership and Penn's production effect are already delivered separately.
3. This requirement owns only these three remaining production modifiers and their combination with the accepted shared order.

## 2. Behavior

1. Jefferson adds +50% to staffed ordinary/expert statesman liberty-bell output only; unattended town-hall bells do not receive Jefferson. Paine adds a bell percentage equal to the **current** tax rate in every owned colony, including eligible unattended output; a later tax change changes the next output.
2. Hudson doubles fur-trapper output, ordinary or expert, after the additive-percentage stage. He does not independently double coat production or create fur from a zero-yield job. Each modifier reads the producer owner's membership and applies once.
3. Use the accepted order: base/flat yield, profession, political addition, additive percentages (Jefferson/Paine/print), Hudson's explicit doubling where eligible, floor once, then real-input cap. The documented 3 staffed bells, expert ×2, political +1, press +50%, Jefferson +50%, tax/Paine +20% example yields 15, or 18 with newspaper replacing press.
4. Save/Continue, reassignment, tax changes and colony ownership changes use current lawful membership without stacking duplicates. UC-093/094/107 check each effect before/after recruitment, ordinary/expert, unattended eligibility, press/newspaper combinations, fur versus coats and owner change.

## 3. Implementation steps

1. Use existing rule owners: `Construction.getProduction` for town-hall totals
   and `ColonyField.getPotentialProduction` for fur, shared by preview and actual
   colony credit. Reuse persisted founder membership and the live owner's tax;
   no new persistence, dependency, package or UI-specific production formula.
2. Separate unattended bells U from staffed bells S after existing profession
   and political changes. Add print and Paine percentages to both; Jefferson's
   50 percentage points apply only to S, including servants/criminals doing
   that job. Aggregate with wide arithmetic and floor once. With percentages
   pU and pS the hall yields floor((U*(100+pU)+S*(100+pS))/100).
   The accepted 15/18 example explicitly describes the staffed contribution;
   with one unattended bell the corresponding hall totals are 17/21. Newspaper
   replaces press; founders belong to the current owner, not a prior occupier.
3. Double positive fur output for Hudson after existing political/additive
   production; preserve zero yield and leave coats and Penn crosses unchanged.
   Preview and actual turn must agree, repeated reads must never grant goods.
4. Add model coverage for each father alone and combined, ordinary/expert and
   laborer workers, unattended bells, press/newspaper, current tax changes,
   zero fur, ownership/membership and save/load. Add TC_97_F88_founder_production_test
   for UC-093/094/107 using existing fixtures, actual production UI and Continue.
   Preserve the worker-contribution-before-colony-bonuses explanation in job UI.
5. Follow architecture, the full functional contract and shared Java formatter
   profile. Main performs targeted Docker tests, review and documentation checks.
   Targeted acceptance is complete in the isolated batch; native and other father effects
   are outside this requirement.

6. Accepted on 2026-10-19; see [verification evidence](../../functional-tests.md#r-0180-founder-production-2026-10-19). Publication is pending batch integration.
