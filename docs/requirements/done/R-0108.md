1. Use this ordinary movement/holds matrix for both existing and newly supported ships: caravel 4/2, merchantman 5/4, galleon 6/6, privateer 8/2, frigate 6/4 and man-of-war 6/6. Caravel, merchantman and privateer use the existing European purchase flow at base prices 1000, 2000 and 2000. Preserve existing positive galleon/frigate prices 5000/4000 and their construction sources. Man-of-war replaces the carrier in the existing Crown expedition event and cannot be bought or built by colonists. R-0105 separately owns the complete Crown roster and intervention lifecycle; R-0077 owns escalating prices.

2. Acquire, move, load to capacity, cross the Atlantic and unload → preserve owner, cargo and ship identity.

3. Full holds, incompatible passengers or invalid terrain reject without mutation. Noncombat vessels must not gain attack permission merely by sharing ship controls.

4. Save/load retains every new type and its state. Man-of-war and privateer special rules are explicit dependencies rather than generic-frigate behavior.
