## 1. Summary

1. Provide one command that checks the full model and UI suites and reports a complete, unambiguous result.
2. Existing containers already isolate source copies, JVMs, displays and exported results. The four-container experiment failed with memory pressure and incomplete reports; it is not accepted evidence of speedup.
3. Retain Maven modules, test assertions, serial JVM isolation and existing CI configuration. Prepare a portable foreground command and completion-runner entry for agents.

## 2. Behavior

1. With Git, Python 3, Docker and Compose available, the operator starts full verification with two UI groups by default, or one for serial execution.
2. Every group uses the same frozen source and image. Model tests execute once before the UI groups. Each invocation and group retains separate logs, reports and source identity.
3. Success requires all processes and exports to finish successfully, every expected suite and test method to appear, and zero failures, errors or skips. Missing, duplicate, malformed or incomplete reports fail verification.
4. Timeout or cancellation stops only this invocation's containers and processes, preserves available evidence and returns failure. Concurrent invocations cannot overwrite each other's output.
5. Report actual duration and counts without claiming speedup from an unmatched baseline. Provide a handoff command and local acceptance evidence; remote CI execution and publication verification are outside this request.

## 3. Implementation steps

1. Add orchestration under `scripts/ui-tests`, reuse the Compose resource settings and existing entrypoint, and retain outputs under `target/verification`.
2. Discover conventional JUnit source classes/methods including inherited tests, allocate complete UI classes, and reconcile fresh Surefire XML against the frozen inventory. Balance using prior report durations when supplied.
3. Add process, snapshot, allocation and report-validation unit tests, run existing runner checks and full local model/UI acceptance, and validate documentation strictly.
4. Implemented and locally accepted: 11 orchestration checks, five Docker entrypoint checks and a full run of 2,968 model plus 465 UI tests, without failures/errors/skips, in 47 minutes 28 seconds. Full model selection retains ConnectorTest despite the legacy default POM exclusion. See [dated evidence and handoff](../../functional-tests.md#r-0257-izolovane-uplne-overeni-2026-10-21); publication and remote CI were not verified.
