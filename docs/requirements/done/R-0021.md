## 2. Behavior

1. Entering a lane does not depart; moving outward from it starts one voyage and records the source square. Return uses that origin, preserving cargo and passengers. Blocked arrival waits at zero and retries next owner turn; the existing 3/4/3 durations remain provisional.

## 4. Open questions

The original decision/question numbering is retained below. For a superseded

1. Resolved on 2026-10-13 after consulting the [original manual](../../Sid_Meiers_Colonization_manual.pdf), printed page 60 (PDF page 66): return uses the sea-lane square of departure. The passage does not specify blocked arrivals. Explicit MicroCol policy: an enemy occupant blocks arrival; friendly stacking follows current model movement rules. Keep the ship, passengers and goods in transit with zero remaining turns and a visible waiting reason, then retry once on its next owner turn. Do not relocate to another square or decrement below zero.

2. Resolved implementation policy on 2026-10-13: a ship without prior departure uses the default eastern arrival for the selected reference map. Choose an eastern sea-lane square adjacent to ordinary ocean, nearest the vertical map centre; break ties by row and then column. Fix and persist this choice when beginning the first return voyage so a later load or occupant cannot select a different coast. An occupied destination follows 4.1. A map with no such legal terrain must reject departure before mutation and explain why. The consulted passage does not specify where newly purchased ships first arrive; this deterministic rule is MicroCol policy, not a historical claim. No new user setting is required.

3. Resolved trigger wording from printed pages 17 and 60 (PDF pages 23 and 66): entering a lane and then moving toward its corresponding map edge are separate actions. The source lane square, rather than the outward target square, is the recorded origin. Retain current provisional voyage timing; the manual describes variable one-to-four-turn crossings but does not supply an exact weather/navigation formula for Q-11.
