# R-0423 — Předvybrání všech pasažérů k vylodění

1. Status: done
2. Updated: 2026-11-06
3. Related: UC-025, Hra; [výběr vylodění](../../ux.md).
4. Dependencies: [R-0379](R-0379.md), existující modelová validace vylodění.
5. Primary area: [A06](../areas.md#a06).
6. Related areas: A03 — stávající dialog a ovládání checkboxů.
7. Origin: požadavek uživatele z 2026-11-06; zachyceno a zpřesněno pro přímou implementaci.

## 1. Summary

1. Hráč chce při otevření výběru vylodění rovnou potvrdit všechny nabízené jednotky bez jednotlivého zaškrtávání.
2. Zdroj `b71c83a3` zkontrolovaný 2026-11-06 vytváří checkboxy bez výběru. Tento požadavek mění pouze jejich počáteční stav.

## 2. Behavior

1. Při pokusu o vylodění více způsobilých pasažérů na sousední pole se otevře dialog se všemi nabízenými jednotkami zaškrtnutými a aktivním potvrzením.
2. Hráč může libovolné jednotky odškrtnout; potvrzení vylodí právě vybrané. Po odškrtnutí všech je potvrzení neaktivní. Myš i Tab/mezerník zůstávají použitelné.
3. Zrušit a Escape nevylodí nikoho. Každé nové otevření znovu předvybere všechny nabízené jednotky, bez ohledu na předchozí výběr.
4. Způsobilost, kontrola změněného cíle, přímé vylodění jediného způsobilého pasažéra a uložení potvrzeného výsledku zůstávají podle R-0379.

## 3. Implementation steps

1. `gui.dialog.ChoosePassengerDialog` nastaví počáteční výběr každého vytvořeného checkboxu. Vlastnictví modelových pravidel se nemění.
2. Upravit TC29/F21 pro výchozí výběr, odškrtnutí všech, zrušení, opětovné otevření, klávesnici, přímé potvrzení všech a odmítnutí změněného cíle. Testové volání pro jediného pasažéra přizpůsobit v TC01, TC24 a `ExpeditionLoopPage`; zachovat výsledky hry.
3. Použít sdílený Java formatter; model/JUnit, cílené Docker/Xvfb scénáře TC01, TC24/12, TC29, TC101, TC198 a kontrakt page objects; potom pevný smoke, dokumentační kontroly a strict MkDocs.
4. Implementováno a lokálně přijato 2026-11-06; modelové, cílené UI a smoke testy prošly. Výsledky vlastní [funkční evidence](../../functional-tests.md#r-0423-passenger-default-selection-2026-11-06).
