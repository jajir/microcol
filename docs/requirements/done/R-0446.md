# R-0446 — Shared Java 25 baseline

1. Status: done
2. Updated: 2026-11-10
3. Primary area: [A03](../areas.md#a03), shared technical environment.
4. Related areas: A01 application launch; P31 verification and P32 distribution.
5. Dependencies: installed JDK 25, Maven, Docker/Xvfb and existing packaging tools.
6. Origin: user selected Java 25 for local launch, builds, tests and packaged runtimes after analysis of a native macOS graphics crash.

## 1. Summary

1. Developers need one explicit Java major version across local launches, compilation, CI, Docker tests and distributions.
2. Inspection on 2026-11-10 found JDK 17 packaging/tests, Java 11 compiler output, local Maven using 25 and jenv using 21. The supplied crash report used 26.0.1.
3. Standardize on Java 25 while retaining JavaFX 17.0.20. This does not establish that the native CoreGraphics crash is fixed.

## 2. Behavior

1. The documented local launch selects installed Homebrew JDK 25 on macOS unless JAVA_HOME is explicit; other environments use the configured JDK. Maven and its game process use the same JDK.
2. Maven lifecycle builds reject a Java major version other than 25 with instructions to select JAVA_HOME. Compilation and the module descriptor target Java 25; Java 11/17 compatibility is retired.
3. Docker verification and CI use JDK 25. Distribution tools and linked runtimes use Maven's JDK 25. No global shell or jenv configuration is changed.
4. Player behavior, graphics, JavaFX dependencies and save schema remain unchanged. Local acceptance is distinct from native crash reproduction and published distribution verification.

## 3. Implementation steps

1. Update the parent compiler/enforcer configuration, JavaFX executable selection, module compiler, native package guards, regular-file license notices in the linked runtime, Docker image and CI JDK selection. Add a small local launch script and update authoritative build documentation.
2. Check launch environment selection and wrong-version rejection; run affected tooling checks, all model/JUnit checks, targeted Docker startup/movement/drag paths and fixed smoke/support. Verify module/runtime packaging on JDK 25 without launching the host GUI.
3. Record actual acceptance results in the existing [test evidence](../../functional-tests.md#r-0446-java-25-baseline-2026-11-10). No remote CI/publication verification is requested.
4. Current result: implemented and locally accepted on 2026-11-10. All 5,117 model/JUnit, 3 targeted UI and 21 smoke/support checks passed; macOS application/DMG/updater packaging and tooling checks passed. Full results and the preserved preparation/packaging failures are in the linked test evidence. The original macOS crash and publication remain unverified.
