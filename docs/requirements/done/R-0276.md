## 1. Summary

1. Menus should look drawn with a ballpoint pen, including their selected row, rather than like recolored system rectangles.
2. The selected proposal uses one visibly irregular ink contour, cream paper and a warm filled selection with a hand-drawn closed frame.
3. Apply the shared treatment to context menus and colony dropdown entries; retain the existing toolbar artwork and gameplay.

## 2. Behavior

1. Opening a context menu or the colony selector shows a readable paper menu with a single freehand outline and hand-drawn separators.
2. Mouse and keyboard selection use the same warm fill and irregular closed outline, including Jettison goods and a colony name. A disabled command remains visibly unavailable and keeps its explanation.
3. Existing unit shortcuts appear in separate drawn keycaps to the right of the action name, without parentheses in the visible caption; English and Czech remain readable.
4. Existing commands and colony navigation still activate once. Moving from the unit-choice submenu to an action closes the submenu; Escape and outside clicks cancel without changing the game. Narrow windows and long menus retain their existing navigation and scrolling.

## 3. Implementation steps

1. Refine shared ContextMenus.css shapes and reuse the same selection contour for custom unit buttons and ordinary menu items. Keep JavaFX menu input and layout.
2. Render the existing localized unit captions and shortcuts separately inside their current buttons; do not register new accelerators or change model operations.
