## 1. Summary

1. A player choosing Free Play Game → Original World should discover a varied, believable world containing all supported terrain types and natural features, including recognizable rivers when approaching land.
2. Source inspection on 2026-10-24 at `422c3b34` finds that Original World loads a bundled map. Its map data contains terrain and forest arrays but no explicit river or special-resource arrays. This is a source observation, not a completed runtime audit.
3. Author one richer fixed Original World. It is distinct from the geographic America map in [R-0221](../R-0221.md) and the generated random/custom world in [R-0065](R-0065.md). Selected for implementation by the user on 2026-10-24.

## 2. Behavior

1. Starting a new free-play game with Original World always uses the same authored geography and feature placement. Different sessions, nations or difficulties do not randomly rearrange its terrain. Existing nation/difficulty effects and expedition rules still apply; the generated-world choice remains separate.
2. The map has one large northern landmass with tundra in its northern region and a southern Antarctic ice region without tundra. Antarctica uses the existing ice terrain. The remaining landscape forms varied, geographically plausible regions, with coherent transitions and connected coastlines rather than scattered showcase squares.
3. All 14 supported base types occur: grassland, plains, prairie, savannah, desert, tundra, arctic, marsh, swamp, hills, mountains, ocean, lake and high-sea lane. Forested and open land, small and large rivers, and every current special-resource kind occur in legal, sensible locations. This requires each kind, not every possible combination. The illustrated catalogue in [R-0259](../R-0259.md) explains the same identities.
4. Rivers form readable, connected courses through the land, with at least one mouth discoverable during an ordinary approach from each supported starting expedition. A player approaching the main landmass can reveal a river without an exceptional detour to a remote map corner. Normal exploration and sight rules apply; hidden terrain and features are not revealed early to demonstrate map completeness.
5. Sea access, landing and legal colony founding remain possible for every supported nation. Variety must not block normal play or place features on forbidden terrain. Existing artwork and the [visual brief](../../graphics.md#soucasne-zadani-vzhledu) show the terrain and overlays consistently with the game; this request adds map content, not new terrain rules or a new art set.
6. Canceling setup does not create a new game. Save/Continue preserves the same map, its subsequent player changes and explored state without regenerating or restoring the initial landscape. Other bundled maps and reference expeditions retain their contracts.

## 3. Implementation steps

1. Refined on 2026-10-24: preserve the existing Dutch-only authored expedition, French colonies, seed and starts; isolate the resource as `original-world.microcol`. Connect the northern tundra shield to the main continent, keep the southern ice shelf free of tundra, group temperate lowlands and southern savannah/wetlands, and place an ten-square small-to-large river ending at (25,13), near the direct approach from (45,15). No new rumors or prebuilt improvements are included. Reuse the authored map format, `model.campaign` loading and shared model terrain/river/resource validation under the [package responsibility map](../../architecture.md). Do not add a randomization setting or a GUI-owned map generator for this fixed-world outcome.
2. Inventory the map against `TerrainType`, `RiverSize` and `ResourceOverlay`: include silver, ore, mixed minerals, trapping, game, oasis, prime cotton, tobacco, sugar, timber, food and fishery. Check forest legality, river sizes/connections, polar placement and traversable sea access. Choose the exact outline and distribution during refinement; use geographic clustering rather than changing production or movement rules.
3. Inspect all consumers before modifying `/maps/free-play.microcol`: `FreePlayMap.ORIGINAL` and `REFERENCE` currently share it. Isolate Original World content if needed to preserve reference fixtures, starting-expedition guarantees and other map modes. Update affected bundled data and tests directly using the current schema.
4. Extend `FreePlayNationBoundaryTest` and map-data checks for the complete terrain/feature inventory, fixed placement, northern tundra, no southern tundra, legal river courses, and valid starts. Extend `TC_24_F15_free_play_setup_test` and the appropriate journey in `TC_22_F15_free_play_capability_audit_test` for selecting Original World, approaching and revealing a river, landing/founding and Save/Continue. During refinement name any additional scenario needed and define a reproducible arrival route for each expedition. Keep [R-0209](../R-0209.md)'s full setup matrix and the [functional test contract](../../functional-tests.md).
5. Implementation and targeted verification completed: all feature inventories, fixed geography, reference isolation and the actual setup → sea approach → river discovery → landing → colony → Continue journey passed. See [execution evidence](../../functional-tests.md#r-0263-fixed-original-world-2026-10-24). The fixed precommit gate and documentation checks passed on 2026-10-24.
