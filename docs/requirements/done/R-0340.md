# R-0340 — Sedm barevných návrhů evropského přístavu

1. Status: done
2. Updated: 2026-10-29
3. Related: UC-018, UC-023–025 v [katalogu](../../use-cases.md); návrh nemění jejich chování.
4. Dependencies: [současný přístav R-0336](R-0336.md), [posuvníky R-0338](R-0338.md), [grafické zadání](../../graphics.md#soucasne-zadani-vzhledu).
5. Primary area: [A03](../areas.md#a03).
6. Related areas: A06 evropský přístav; A02 hlavní mapa pouze jako barevná reference.
7. Origin: uživatel 29. října 2026 přiložil aktuální přístav a hlavní mapu a požádal o sedm barevných návrhů, které je přiblíží. Barvy zboží, ovládacích prvků a dalších společných částí se nemají měnit.

## 1. Shrnutí

1. Dodat sedm srovnatelných návrhů barev přístavní ilustrace, vycházejících z tlumené zelenomodré vody, olivové krajiny a teplých šedých tónů hlavní mapy.
2. Rozsah končí vizuálními návrhy a jejich uchováním. Neobsahuje výběr varianty ani implementaci do hry.

## 2. Chování

1. Každý návrh zachovává rozložení přiloženého přístavu, tmavé ruční kontury a plochý 2D charakter. Varianty mění pouze paletu moře, nebe, kamenného mola a města.
2. Zboží, bedny nákladu, společné lišty, ikony a tlačítka si ponechávají dosavadní barevnou rodinu. Žádný celoplošný tónovací filtr přes celé rozhraní.
3. Sedm variant je jednoznačně pojmenováno a lze je porovnat se zdrojovým přístavem a mapou. Zobrazené návrhy jsou ilustrativní editace, nikoli důkaz implementace nebo totožnosti každého pixelu UI.

## 3. Kroky implementace

1. Použít vestavěný ImageGen se dvěma dodanými referencemi, jedním samostatným zadáním pro každou variantu a explicitně zachovanými společnými prvky.
2. Uložit sedm PNG a přesná zadání do dokumentačních podkladů; připravit přepínatelné srovnání v konverzaci. Autoritativní popis variant a hranic změny patří do [grafiky](../../graphics.md#barevne-varianty-pristavu-podle-hlavni-mapy-29-rijna-2026).
3. Ověřit úplnost, odlišnost a čitelnost návrhů, fungování přepínání a dokumentační odkazy. Pro dokumentační rozsah použít konzistenční kontroly a strict MkDocs podle [publikování](../../publishing.md#local-acceptance-policy); herní model ani runtime zdroje se nemění.

## 4. Otevřené otázky

1. None. Výběr a případná realizace jsou samostatný navazující požadavek.
