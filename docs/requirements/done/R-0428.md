# R-0428 — Escape z detailu obchodní trasy

1. Status: done
2. Updated: 2026-11-08
3. Related: [UC-029/030](../../use-cases.md), [R-0427](R-0427.md).
4. Dependencies: existující návrat z detailu a mapový plánovač obchodních tras.
5. Primary area: [A03](../areas.md#a03).
6. Related areas: A06 — zachování obchodní trasy a neuloženého návrhu.
7. Origin: uživatelský požadavek z 2026-11-08, Esc má zavřít detail a vrátit mapu obchodních tras.

## 1. Summary

1. Hráč chce opustit detail obchodní trasy klávesou Esc bez hledání tlačítka Zpět.
2. Kontrola zdrojů na `e43ab036` dne 2026-11-08 našla obsluhu Escape až při probublávání události; dosavadní page object před stiskem uměle přesouval fokus na Zpět.
3. Rozsah je spolehlivý návrat z detailu při běžném fokusu uvnitř stránky, bez změny obchodních pravidel.

## 2. Behavior

1. Hráč otevře detail obchodní trasy z mapového plánovače. Návrat je dostupný tlačítkem Zpět i klávesou Esc.
2. Bez neuložených změn Esc zavře detail, zobrazí mapu s obchodními trasami a zachová vybranou trasu. Platí při počátečním fokusu na nabídce trasy i po přepnutí karet Stanice, Přeprava a Zboží.
3. Při neuložených změnách zůstává stávající ochrana: první Esc upozorní, druhý odejde bez uložení. Uložená trasa se nezmění.
4. Návrat z detailu otevřeného v kolonii zůstává do kolonie. Změna nemění uložené hry ani příkazy dopravců.

## 3. Implementation steps

1. Vlastník je GUI `DialogTradeRouteCargo` podle [architektury](../../architecture.md). Zachytit Escape filtrem stránky před obsluhou vnořených ovládacích prvků a použít existující `close()`.
2. Page object stiskne Escape bez přesouvání fokusu. Rozšířit TC119/09 o počáteční fokus a karty; zachovat TC119/01 pro neuložené změny a ostatní scénáře.
3. Použít sdílený Java formatter, všechny model/JUnit testy, Docker TC119 a PageVerificationContractTest, potom pevný smoke do 420 s. Spustit dokumentační kontroly, naming audit a strict MkDocs.
4. Implementováno a lokálně přijato 2026-11-08: model/JUnit, cílené UI, smoke a dokumentační kontroly prošly. Výsledky jsou v [funkční evidenci](../../functional-tests.md#r-0428-trade-route-escape-2026-11-08).
