# R-0275 — Open map unit commands with Control-click

1. Status: done
2. Updated: 2026-10-25
3. Primary area: [A03](../areas.md#a03), shared map input.
4. Related areas: A05 unit orders and A07 colony entry; no gameplay or save changes.
5. Related: [R-0272](R-0272.md), [UX guidelines](../../ux.md), UC-011/114/119 in the [use-case catalogue](../../use-cases.md).
6. Origin: the user identified macOS Control + left click as the failing gesture and requested support and a regression check on 2026-10-25.

## 1. Summary

1. Control + left click on a unit must open the same map menu as the right mouse button, including a ship in port. The right panel remains informational.

## 2. Behavior

1. Control-click selects the own unit on the clicked square and opens its commands beside the pointer without moving it, spending movement or entering a colony. Several units retain the existing menu selector.
2. A pending movement preview is canceled before opening the menu. Releasing Control before the mouse button still completes the same context gesture.
3. Dragging a context gesture pans the map and does not open the menu. Ordinary left click, right click, keyboard access and turn restrictions retain their behavior. Empty and foreign-unit squares offer no own-unit orders.
4. Alt-click retains the existing smooth-focus modifier. Control-click consistently means unit context instead of its previous focus-and-primary-action path.

## 3. Implementation steps

1. Refine the existing GUI mouse listener only: recognize secondary, Control-primary and platform popup-trigger input before primary actions, and remember the gesture through release and dragging. Retain existing command handlers and model validation.
2. Extend the TC11 page object with real Control-primary input. Add named port and sea scenarios checking unchanged state, preview cancellation, modifier-release order, dismissal and normal colony entry. Re-run complete TC11 plus the page source contract and the mandatory model/JUnit and fixed Docker/Xvfb smoke gate.
3. Implementation and local acceptance completed on 2026-10-25. Apply the shared Java formatter, update the authoritative UX/use-case notes and record actual results in [functional evidence](../../functional-tests.md#r-0275-control-click-unit-context-2026-10-25). Run documentation consistency and strict MkDocs before completion. Distinguish Linux gesture tests from native macOS verification.
