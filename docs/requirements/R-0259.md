# R-0259 — Recognize terrain types and features through illustrated help

1. Status: new
2. Updated: 2026-10-24
3. Related: P27; [SUPPORT-004](../gap-analysis.md#supporting-persistence-and-information), [MAP-001–005](../gap-analysis.md#map-terrain-and-exploration); [UC-114](../use-cases.md#povinne-matice-a-obsah-prehledu) (Hra), with UC-007/008 terrain recognition.
4. Dependencies: existing encyclopedia [R-0206](done/R-0206.md); terrain identities [R-0123](done/R-0123.md), rivers [R-0126](done/R-0126.md), resources [R-0127](done/R-0127.md) and current map artwork.
5. Primary area: [A03](areas.md#a03), understandable in-game help.
6. Related areas: A05 supplies terrain, feature and exploration meanings; A07 supplies production effects. This requirement explains existing rules without changing them.
7. Origin: user request on 2026-10-24 for two help pages showing all 14 terrain types and all terrain features, using existing terrain images so players understand what they see.

## 1. Summary

1. Players need a visual reference that connects the map's appearance with terrain names and the meaning of features such as forest.
2. Source inspection on 2026-10-24 at `31abf834` finds 14 terrain types and nine text-based encyclopedia topics, but no dedicated illustrated terrain or feature catalogue. Some terrain types currently share artwork; a shared image does not make them the same terrain.
3. Add two connected pages inside the existing in-game help: terrain types and terrain features. Reuse current game images; new artwork, changed map rendering, game-rule changes and a separate external manual are outside this request.

## 2. Behavior

1. During play, the player opens the existing help and can find both pages by topic and search. Each page links to the other and remains usable with the existing mouse, keyboard and scrolling controls in Czech and English.
2. The terrain-types page contains all 14 named entries: grassland (Zelená země), plains, prairie, savannah, desert, tundra, arctic, marsh, swamp, hills, mountains, ocean, fresh-water lake and high sea/sea lane. Each entry has a representative existing in-game image, the localized name used elsewhere in the game and a brief explanation of what the player is looking at. Distinguish similarly named terrain and the role of lake, ocean and the sea lane to Europe. Captions remain clear where two terrain types share artwork.
3. The terrain-features page explains that a base terrain and its additional features are different things. Cover forest, plowed field, road, small and large rivers, and every current special resource: silver deposit, ore deposit, mixed mineral deposit, trapping area, game, oasis, prime cotton, prime tobacco, prime sugar, prime timber, prime food and fishery. Explain cleared versus forested land and finite deposit depletion where relevant, without inventing an additional terrain type. Also explain the lost-city-rumor map marker as an exploration feature rather than a base terrain or production resource.
4. Each feature has its in-game name, a brief explanation of its visible appearance and practical meaning, and an example using existing map graphics where available. Examples make the underlying terrain and overlay recognizable together, including forested tundra. Explain permitted combinations and relevant movement, production or defense effects from current rules; do not imply that every feature can occur on every terrain. Detailed numerical rule tables need not be duplicated here.
5. Images supplement readable text and labels; identification must not depend on color alone. Keep examples legible within the existing visual brief. The pages are a general reference: opening, searching, switching or closing them neither reveals hidden map locations nor changes units, goods, turns or saved state. OK/Escape returns to the game through the existing help behavior.
