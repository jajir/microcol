# R-0232 — Provide a first-release player quickstart and help path

1. Status: new
2. Updated: 2026-10-17
3. Related: P32/P27; [player-documentation estimate](../implementation-estimate.md#release-engineering-and-upkeep), rules help [R-0206](R-0206.md), existing tutorial [R-0207](R-0207.md).
4. Dependencies: final supported packages [R-0234](R-0234.md)/[R-0235](R-0235.md), confirmed controls/rules [R-0222](R-0222.md), local diagnostics [R-0231](done/R-0231.md).
5. Primary area: [A01](areas.md#a01).
6. Related areas: A03 in-game help, A02 setup, A10 ending; P32 package delivery.
7. Origin: external player-facing release documentation, separate from the in-game encyclopedia/tutorial and developer documentation.

## 1. Summary

1. A new player can install, start, save, continue and understand the core free-play loop using current release instructions.
2. The guide links to controls/rules, troubleshooting and support without copying an obsolete developer site as current product documentation.

## 2. Behavior

1. Provide a concise English quickstart, current controls and main actions, save location/backup guidance, supported platforms, install/launch/update/uninstall steps, common recovery steps, known limitations, versioned release notes and help/report route.
2. Follow the guide on a clean supported Mac and Linux install: paths, menu names, screenshots and error remedies match the actual package. The in-game help remains navigable from ordinary play; links work offline where the package promises offline use.
3. Date and version the guide; keep development-build instructions separate from stable-release instructions. Do not promise Steam-only behavior before R-0239–R-0241 acceptance.

4. The guide must describe the [accepted local diagnostic policy](../gap-analysis.md#local-diagnostic-logs): logs outside saves, three files of at most 5 MB each, macOS ~/Library/Logs/MicroCol, no save/player text and no automatic transmission.

## 3. Implementation steps

1. Draft from verified UI/package behavior, run a clean-install walkthrough on supported targets, and keep one authoritative player guide linked from the product/help and release notes.
2. Current result: captured first-release guide scope; no verified public installation guide is claimed.

## 4. Open questions

1. What player-support destination should the first release publish? It must be chosen before the guide can give a working contact path.
