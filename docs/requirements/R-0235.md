# R-0235 — Verify the supported Linux release runtime matrix

1. Status: new
2. Updated: 2026-10-17
3. Related: P32; [Linux distribution limits](../distribution.md#distribution-scope-and-remaining-release-work), [Linux platform estimate](../implementation-estimate.md#platform-requirements-and-project-findings).
4. Dependencies: release runtime [R-0233](canceled/R-0233.md), existing archive/DEB and launcher, player guide [R-0232](R-0232.md), long-game check [R-0229](canceled/R-0229.md).
5. Primary area: [A01](areas.md#a01).
6. Related areas: A03 toolkit/audio/display, A04 home-directory save, P31 performance.
7. Origin: Linux native runtime acceptance beyond producing development archive/DEB files; RPM is not required by this scope.

## 1. Summary

1. The Linux release starts and plays on an explicitly supported distribution/runtime matrix without an installed developer JDK.
2. This requirement owns native dependency and environment verification, not another build system.

## 2. Behavior

1. On each selected target, install/extract the published package, launch through its documented entrypoint, and exercise graphics, audio or mute, input, save/Continue, update and uninstall. Missing GTK, graphics, audio or C-library dependencies produce actionable failure evidence and a supported-package fix or documented minimum.
2. Record distribution/version, architecture, display server/session, bundled runtime, native dependencies and actual player-path result. Package construction alone is insufficient; test a clean environment and one representative game journey.
3. Steam Linux Runtime acceptance belongs to R-0239/0240 and may share evidence, but a development-host run does not prove it.

## 3. Implementation steps

1. Agree the support matrix, create clean test environments and run package/functional checks on each. Adjust native bundle or declared minimum only from measured results.
2. Current result: captured platform gate; the [distribution audit](../distribution.md) identifies risk but does not prove present target-platform failures.

## 4. Open questions

1. Which Linux distributions/versions, architecture and display environments are supported at first release? The docs require a matrix but do not choose its cells.
