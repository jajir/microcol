## 1. Summary

1. The player needs a reference game in which each included European nation starts with an agreed, legal expedition.

2. Migration observation (2026-10-14): R-0015 supplies fixed French colonies/units; R-0027 adds a French first-colony expedition on one map. These are accepted scenarios, not a complete four-nation reference start.

3. Scope: the outcome and examples below. This is captured work awaiting individual refinement; it does not reopen the delivered origin scope or close a whole UC.

## 2. Behavior

Proposed acceptance for refinement; inherited resolved decisions remain agreed.

1. Choose the reference profile → each included nation has its own valid people, carrier, supplies and arrival state; no participant borrows another’s identities.

2. Changing which nation is human does not duplicate or remove another participant’s starting equipment.

3. Starting locations respect map boundaries, legal cargo capacity and access to land; a profile that cannot place an expedition is rejected before replacing the active game.

4. Keep existing authored maps as explicit scenarios. New reference setup and save/load preserve all participants and their starting state.

5. Shared behavior accepted on 2026-10-15 ([Q-02](../gap-analysis.md#q-02-calendar-and-starting-expeditions)): Use all four European participants, peaceful initial pairs, two equipped free colonists per expedition, and the Dutch merchantman/other caravel distinction. These decisions unblock policy; individual design, dependencies and acceptance checks still require refinement.
