## 1. Summary

1. The player needs a reference game in which each included European nation starts with an agreed, legal expedition.

2. Migration observation (2026-10-14): R-0015 supplies fixed French colonies/units; R-0027 adds a French first-colony expedition on one map. These are accepted scenarios, not a complete four-nation reference start.

3. Scope: the outcome and examples below. Selected and refined on 2026-10-16 under the remaining-backlog authorization; it does not reopen the delivered origin scope or close a whole UC.

## 2. Behavior

Acceptance refined on 2026-10-16; inherited resolved decisions remain agreed.

1. Choose the reference profile → each included nation has its own valid people, carrier, supplies and arrival state; no participant borrows another’s identities.

2. Changing which nation is human does not duplicate or remove another participant’s starting equipment.

3. Starting locations respect map boundaries, legal cargo capacity and access to land; a profile that cannot place an expedition is rejected before replacing the active game.

4. Keep existing authored maps as explicit scenarios. New reference setup and save/load preserve all participants and their starting state.

5. The new reference profile uses the existing original terrain as a fixed world until R-0065 supplies generation. It does not inherit authored colonies, units, money, exploration or statistics. All four colonizing nations and their Crowns have unique identities; six initial European pairs are at peace. Each nation starts on a distinct eastern sea-lane tile with a water route to a walkable coast. Each ship carries exactly two free colonists: a soldier with muskets and a pioneer with 100 tools, neither mounted, with no extra goods. The Netherlands uses a merchantman; the other three use caravels.

6. All four colonial treasuries start at 1000/750/500/250/0 for Discoverer/Explorer/Conquistador/Governor/Viceroy respectively. The roster does not change with difficulty. The reference begins in 1490 with no colonies; later end-date and national-effect rules remain their own requirements. An unsuitable map (missing four legal starts or a reachable coast) is rejected before any current game is replaced.

7. The model setup accepts each of the four human nations without changing the other expeditions. R-0063 owns the actual four-nation menu selector; R-0066 adds the selectable reference map profile using the current Dutch human default. Starting and saving the reference game must use ordinary game/AI turns, not a special test-only path.

8. Accepted behavior (2026-10-15; [calendar and starting expeditions](../gap-analysis.md#calendar-and-starting-expeditions)): Use all four European participants, peaceful initial pairs, two equipped free colonists per expedition, and the Dutch merchantman/other caravel distinction.
