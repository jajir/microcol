## 1. Summary

1. The player needs battle odds to respond to the same strengths the game explains before an attack.

2. Migration observation (2026-10-14): The inspected combat path uses a fixed win probability; R-0028 deliberately left outcome arithmetic unchanged.

3. Scope: the outcome and examples below. Selected for linked refinement on 2026-10-16; it does not reopen the delivered origin scope or close a whole UC.

## 2. Behavior

Proposed acceptance for refinement; inherited resolved decisions remain agreed.

1. For the agreed ordinary attacker/defender pairs, compute the outcome chance from the displayed final strengths using one documented formula.

2. Use one combat draw only after successful confirmation/revalidation; canceled or stale commands draw nothing and cause no battle.

3. Controlled low/high draws exercise both outcomes with the agreed movement exhaustion and existing ownership/selection cleanup.

4. Save/continue preserves resolved results without replay. Veterans, artillery, naval outcomes and civilian capture use their own linked scope.

5. Accepted behavior (2026-10-15; [combat and naval outcomes](../gap-analysis.md#combat-and-naval-outcomes)): Resolve battles from the agreed strength ratio and persisted random state, including zero/equal-strength boundaries.

Draw one uniform value in [0,1) and compare strictly with A/(A+D); positive A against zero D succeeds, zero A cannot initiate and both-zero is rejected. Preserve exhaustion of both participants and existing cleanup; equipment degradation, promotions, civilian capture and naval damage remain their named requirements.

Add model-owned persisted combat RNG state with deterministic advancement; previews/cancel/rejected stale commands must not advance it. Initialize state explicitly when creating a new game and update bundled current-schema maps/test fixtures; reject missing or invalid required state on load without migrations. Keep weather and Congress random paths outside this bounded change.
