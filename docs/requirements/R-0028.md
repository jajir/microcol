## 1. Summary

1. Prevent an unarmed colonist or stale attack command from initiating a battle while making intentional treaty-breaking explicit.

2. COMBAT-001 already has adjacency/terrain checks. COMBAT-003 records that colonist type eligibility ignores muskets, allowing an unarmed foot colonist to attack.

3. Eligibility for currently supported roles and European hostility transition. Strength calculation belongs to R-0029; new unit types, capture and privateer exceptions remain separate.

## 2. Behavior

Implementation is authorized by the request to implement R-0019 onward. The following decisions distinguish manual rules from the current supported roles.

1. Show an attack only when current role/equipment, registered ownership,
    adjacent map positions, terrain, remaining movement and a live foreign target
    permit it. Move into adjacency through the normal movement action before
    choosing an attack; confirmation must not silently chase a moved defender.
    Unknown targets remain unavailable. Use this explicit supported-role table:

    | Current role | May initiate | Target domain |
    | --- | --- | --- |
    | Ordinary colonist or master blacksmith, no muskets | No, including tools-only or horses-only equipment | None |
    | Same colonist with muskets (soldier) | Yes | Land units |
    | Same colonist with muskets and horses (dragoon) | Yes | Land units |
    | Frigate | Yes | Ships on navigable water |
    | Galleon or wagon | No | None |

    Expertise stays attached to the same unit and does not prevent taking the
    soldier/dragoon role. The manual's Seasoned Scout exception is not an existing
    MicroCol specialty; this requirement does not invent that unit type.

2. For a peaceful European target, show that the proposed attack declares war;
   cancelling, Escape or closing the window changes neither relation nor movement
   nor units. This confirmation is mandatory even when the ordinary fight advisor
   has been hidden. Show the actual attacker and defender, and reset a reused
   dialog's choice before each opening.

3. On confirmation, revalidate the original game, registered participants,
   attacker/defender identities and positions, equipment, movement, target domain
   and expected peace/war state before changing the relation or consuming movement.
   A removed/replaced target, changed game, moved participant or removed weapon
   rejects without partial declaration or battle. Report rejection in English/Czech.
   A single accepted command both records any required declaration and initiates
   the existing battle; UI must not declare war in a separate earlier command.

4. A successful valid initiation invokes existing combat resolution and exhausts
   both participants' remaining movement for the current turn. The survivor cannot
   move or attack again until its next ordinary turn replenishment. Keep the
   existing outcome algorithm in this slice; strength calculation belongs to R-0029.

5. AI uses the same role and live attack checks. Its current policy attacks only
   already-hostile opponents; it does not implicitly declare war during wandering.
   Save/load preserves resulting relations and remaining movement, without
   repeating combat. Preserve existing Crown paths and foreign occupancy rules.
   Newly created royal expedition soldiers receive muskets: the Crown must meet
   the same equipment gate. Existing attack fixtures explicitly carry their
   required weapons; no special unarmed-Crown exception is introduced.

   unit's current equipment. Model queries remain read-only.

   objects, original owners/positions, originating model and expected relation.

   R-0026's relation transition only after complete attack preflight. Preserve the

## 4. Open questions

1. Resolved from the [original player aid card](../Sid_Meiers_Colonization_manual.pdf#page=132),
   PDF page 132, visually reviewed on 2026-10-14: `Any Unarmed Colonist`, wagon
   and galleon carry the cannot-attack asterisk; frigate is armed. `Seasoned Scout`
   has no such asterisk. Current MicroCol has no seasoned-scout specialty; horses
   alone on an ordinary colonist are not treated as that exception. Muskets confer
   the soldier role on ordinary colonists and supported specialists, and horses
   then confer dragoon equipment. No new unit type or privateer exception is added.

2. Resolved from the [combat description](../Sid_Meiers_Colonization_manual.pdf#page=36),
   printed page 30 (PDF page 36): battle consumes all remaining moves and a unit
   involved cannot continue moving that turn. Apply that to both participants
   immediately; the next normal turn of the survivor's owner replenishes movement
   as usual. Do not impose an additional lost future turn. Verify survival of each
   side and save/load of the exhausted state before claiming this rule complete.

3. The [European powers chapter](../Sid_Meiers_Colonization_manual.pdf#page=87),
   printed page 81 (PDF page 87), treats attacks as declarations of war. The
   mandatory confirmation and rejection of changed confirmation state are MicroCol
   interaction/atomicity policy. Reuse R-0026's registered bilateral state and
   existing Crown exception; general negotiations and unguarded capture remain
   separate accepted scopes.
