## 1. Summary

1. The fleet report tells the player where each owned ship is headed and what it carries, while showing only permitted occupancy for visible foreign ships.
2. This requirement owns the fleet report and consumes R-0205's shared model disclosure query for foreign holds.

## 2. Behavior

1. Show every own ship with current location (map, port, Atlantic or repair), destination/ETA where known, passengers, goods and occupied/free holds based on real saved state. Current damage/repair status is labeled when applicable.
2. A visible foreign ship reveals only occupied-hold count, not exact cargo/passenger identities or hidden route/destination. An unknown foreign ship is absent. Transfer, reversal, battle/repair and Continue refresh values without making a move or duplicating cargo.
3. UC-114 checks six ship families, full/partial holds, Atlantic/reversed/repair state, visible foreign occupancy, hidden contents and owner switch.

## 3. Implementation steps

1. Model supplies viewpoint-filtered ship summaries and bounded foreign occupancy from cargo/visibility owners; GUI renders through R-0016. Reuse R-0205's local disclosure semantics.
2. Proposed model/UI UC-114 checks cover source counts, all location modes, denial of hidden cargo and reload under the [functional contract](../functional-tests.md).
3. Current result: capture only; no fleet report implementation or runtime acceptance is claimed.
