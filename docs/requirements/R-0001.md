# R-0001 — Start free play without completing the campaign

- Status: Draft
- Updated: 2026-10-12
- Related: P02/P28/P26; SETUP-001–003, SUPPORT-001;
  [UC-115, Hra](../use-cases.md#souvisle-pruchody-beznou-hrou), entry and continuation only.
- Dependencies: existing free-play scenario and save/load path; no new map generator.

## 1. Summary

Let a new player start an ordinary game directly from the main menu. This is the
first small part of the [ordinary-game goal](../implementation-plan.md#cil-bezne-nove-hry),
not completion of the whole expedition or setup system.

Static source inspection on 2026-10-12 at
[`4b3a1b56`](https://github.com/jajir/microcol/commit/4b3a1b567bd9e8c8ad8af1587d9849ecee02bead);
no new gameplay test was run while preparing this draft.
[ButtonsPanelPresenter.refresh](../../microcol-game/src/main/java/org/microcol/gui/screen/menu/ButtonsPanelPresenter.java)
requires a completed campaign before enabling free play.
[ApplicationController.startNewFreeGame](../../microcol-game/src/main/java/org/microcol/gui/dialog/ApplicationController.java)
already starts the free-play campaign; its
[mission factory](../../microcol-game/src/main/java/org/microcol/model/campaign/FreePlay_0_missionFactory.java)
uses empty mission goals.

Scope is availability of the existing game and its continuation. Map generation,
nation/difficulty selection, scenario rebalancing and campaign redesign are outside it.

## 2. Behavior

From a fresh profile, the player can discover and activate the free-game entry.
It opens the ordinary free-play map without completing or selecting a campaign
mission. The campaign remains a separate option. Use the current direct launch;
a setup wizard or new confirmation dialog is not required by this slice.

Acceptance examples:

- Fresh profile with no campaign progress → start free play → playable map,
  free-play mode and no campaign goals; ending one turn remains possible.
- Profile with completed campaign → the same action → the same game mode.
- Open the menu and leave without starting → no new game or progress is created.
- Start, save and continue → the same world, player, date and stocks return;
  continuation does not require a campaign completion flag.

The default scenario is reused as it stands. Passing this entry check does not
accept all national profiles, the entire UC-115 journey or the unresolved calendar.

## 3. Implementation steps

1. Keep menu availability in `gui.screen.menu`; reuse the existing controller
   and `model.campaign` free-play path. Review all callers of the menu refresh
   and launch action before removing the campaign prerequisite.
2. Extend [TC_12_F11_start_free_game](../../microcol-test/src/test/java/org/microcol/test/TC_12_F11_start_free_game.java)
   with a fresh-profile path and explicit mode/state verifications. Its present
   setup uses `scenarios-finished`; preserve completed-profile regression coverage
   and the existing TC/F IDs.
3. Exercise launch and save/continue through page objects with dedicated
   `verify...` methods. Use isolated test homes; do not modify a player's profile.
4. Run TC12 and the page verification contract in the
   [documented JavaFX environment](../functional-tests.md#spousteni-a-ochrana-publikace).
   Run the full functional suite for the shared menu change; update UC-115 entry
   evidence and follow normal documentation/build publication.
