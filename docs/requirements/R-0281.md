1. Status: ready for development
2. Updated: 2026-10-25
3. Related: UC-114/115/119 in [use cases](../use-cases.md), [visual brief](../graphics.md#soucasne-zadani-vzhledu), [UX guidelines](../ux.md).

6. Related areas: none; no gameplay, persistence or build-output change.
7. Origin: on 2026-10-25 the user requested that the white macOS window title bar match the cream game background in their screenshot.

## 1. Summary

1. Remove the visible color mismatch between the native macOS title bar and the paper-colored game below it.
2. The requested surface is the title bar with the three window buttons, rather than the macOS menu bar at the top of the desktop.

## 2. Behavior

1. The main window uses the game paper color `#FFF9EC` behind its title on macOS, across the welcome menu, settings and game screens.
2. Keep the native title, close/minimize/zoom controls, dragging, resizing and existing close behavior. No player setting or extra action is required.
3. Other platforms retain native window decorations and the existing game layout. The change does not modify game data or screen navigation.

## 3. Implementation steps

1. Keep ownership in `gui.MainStageBuilder`, following the [package map](../architecture.md). Set the scene fill to the existing paper pigment and initialize the unified style only on platforms reporting `UNIFIED_WINDOW` support, preserving an already unified stage and the incoming style elsewhere. Do not add native bridges or custom window controls.
2. Extend TC188/F221 through a dedicated page verification method to check the persistent scene fill and native window configuration across menu, game, settings and Continue. Retain the existing toolbar and gameplay assertions.
3. Inspect the actual macOS title bar and native window actions; Docker cannot verify macOS chrome. Apply the shared Java formatter, run the targeted Docker scenarios, all model/JUnit tests and the fixed smoke gate, plus documentation checks and strict MkDocs.
4. Record actual results in [functional evidence](../functional-tests.md#r-0281-macos-title-bar-2026-10-25). The combined R-0283 targeted run passes 14 checks, including the repaired Linux paths. The complete model/JUnit and fixed smoke gate passes 4,748 checks with zero failures/errors/skips in 294.427 seconds. Native inspection is pending because the host remains inaccessible as locked; this requirement is not accepted yet.
