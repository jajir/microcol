# R-0122 — Apply road bonuses to the right resources

1. Status: new
2. Updated: 2026-10-17
3. Related: P07/P11; PION-005; UC-021 (Hra). See the [pioneer rules](../gap-analysis.md#equipment-and-pioneers), [accepted production rules](../gap-analysis.md#economy-production-and-education) and [use case](../use-cases.md#vybaveni-a-upravy-krajiny).
4. Dependencies: road state from [R-0121](done/R-0121.md); positive base outputs from [R-0124](done/R-0124.md) and explicit silver-deposit data from [R-0127](done/R-0127.md).
5. Primary area: [A05](areas.md#a05).
6. Related areas: A07 field yield, colony production and preview; A04 saved road/deposit state.
7. Origin: documented PION-005 gap in the [rule catalogue](../gap-analysis.md#equipment-and-pioneers).

## 1. Summary

1. A road should improve documented resource work on its tile without creating output on barren land or deposit-free mountains.
2. The 2026-10-17 catalogue at `f10e3f49` records terrain production modifiers for trees and plowed fields, but no road/resource branch. This is a documented source assessment, not a player test.
3. Scope: apply the accepted road addition to ore, furs, lumber and eligible mountain silver. Building/travel effects belong to [R-0121](done/R-0121.md); the broader baseline terrain and resource-reserve matrices retain their own ownership.

## 2. Behavior

1. A player inspecting a worked road tile sees the same road-influenced output that the colony receives on its next production update.
2. A road adds one to an already positive ore, fur or lumber tile output. Mountain silver gets that addition only when a silver deposit is present. Apply the [accepted calculation order](../gap-analysis.md#economy-production-and-education) before profession and percentage effects.
3. A zero-output resource, deposit-free mountain or tile without a road gets no road bonus; previews and production remain unchanged. Road eligibility on all non-sea terrain, including coastal colonies, comes from [R-0121](done/R-0121.md); eligibility alone cannot create a zero-base resource output. Removing or changing the worker does not add a second road bonus.
4. Save and Continue retain road/deposit identity and the same yield rule; loading does not produce goods by itself.

## 3. Implementation steps

1. Reuse the shared terrain-output calculation for both preview and actual production, reading persisted road state and [R-0127](done/R-0127.md) explicit silver-deposit identity. Do not infer a deposit from nonzero current production.
2. Not prepared for development; inspect the resource-state prerequisite and representative terrain fixtures after selection.
3. Proposed checks: model before/after road for all four resources, zero-base and deposit-free mountain cases, preview versus one real production update, and save/Continue; add a named UC-021 `TC_...` player path at refinement.
4. Current result: captured only; gameplay has not changed.
