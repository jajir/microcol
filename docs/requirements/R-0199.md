## 1. Summary

1. The religion advisor explains actual cross production, accumulated crosses and distance to the next immigrant.
2. This requirement owns the coherent report, not cross generation or immigration settlement.

## 2. Behavior

1. Show current per-colony/national cross output as applicable, accumulated progress and the actual next-immigrant threshold/remainder from the shared model. A founder/building/worker change updates the displayed production; a successful immigration updates progress once.
2. Pending human immigrant selection, canceled report viewing and Save/Continue do not consume crosses or recruit again. Keep other players' private progress hidden and show labels/numbers independent of color.
3. UC-114 checks multiple colonies, unattended/staffed crosses, threshold before/at/after, pending choice, founder effect and reload against model values.

4. Consume the accepted 2026-10-20 rules from [R-0146](../gap-analysis.md#r-0146-refinement); preserve this requirement’s own outcome and existing delivered behavior. These decisions do not establish this consumer’s implementation or acceptance.
