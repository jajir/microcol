## 2. Behavior

1. New free play game opens setup. Start starts the selected map once; Back returns to the main menu without creating a game.

2. Offer exactly two map choices in this slice: the existing map and a new similarly sized map split into two main islands, with a navigable sea route and a legal initial expedition position. No random generator is required.

3. Show a selectable nation mock, clearly identified as a preview without gameplay effect. Preserve the reference player’s actual nation until nation-aware creation is implemented; do not mislabel the resulting game as a functional national choice.

4. Player name has a maximum of 64 Unicode code points after trimming surrounding Unicode whitespace; internal spaces, accents and punctuation remain. The setup requires a nonempty name and explains invalid input before Start. Store the display name separately from the existing nation/ownership key, so entering a name never breaks unit ownership or king association. This is the default limit for future player-entered strings unless explicitly overridden, and needs no repeated question.

5. Other proposed setup options may be mock controls, visibly marked as not yet affecting play. Do not present an unimplemented difficulty effect as verified gameplay.

6. Save/load retains the actual selected map/world state. Test Start for both maps, Back for either selection, and name lengths 0/64/65 when the name field is implemented.
