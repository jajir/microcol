## 1. Summary

1. Choosing North America starts a playable free game on a recognizable, detailed geographic North American map.
2. This requirement owns the authored geographic world and its setup entry, not random generation or a new map editor/import flow.

## 2. Behavior

1. The New Game North America choice loads a stable geographic world with legal land, sea, coastline, voyage access and enough playable space for the documented nations. The geography is visibly distinct from the random/generated choice and the existing small fixture maps.
2. Assemble legal national starting expeditions and native participants using their owning rules. Every active participant has an eligible start; the player can land, found, explore, Save/Continue and progress a complete turn without invalid terrain or unreachable required access.
3. Repeating the North America choice yields the same authored geography and valid initial world; cancellation leaves no new game. This requirement verifies its selector journey; R-0209 is canceled.

4. Consume the accepted 2026-10-20 rules from [R-0065](../gap-analysis.md#r-0065-refinement), [R-0150](../gap-analysis.md#r-0150-refinement), [R-0157](../gap-analysis.md#r-0157-refinement); preserve this requirement’s own outcome and existing delivered behavior. These decisions do not establish this consumer’s implementation or acceptance.

## 3. Implementation steps
1. Selected next in the authorized ordered batch on 2026-11-01. User chose **North America only, more detailed**. The [shared geographic-map rule](../gap-analysis.md#north-america-reference-map) owns this decision. Use an authored 100 × 80 tile world, larger than the generated 50 × 30 map, with recognizable Alaska/Canada, contiguous mainland, Mexico/Central America and nearby Caribbean islands; retain Atlantic space for legal arrivals. This is an original stylized game map, not a surveyed geographic dataset.
2. Reuse `FreePlayMap`, `GameModelDao`, current resource schema, national expedition assembly and native population owners. Inspect all callers before extending selection. Keep authored geography separate from randomized terrain; deterministic resource/participant placement may reuse existing helpers without changing the authored coastline. Reuse valid terrain, river and lane contracts; validate the complete world before replacing the current game. Do not add a general map editor, external dataset dependency or parallel rule implementation.
3. Integrate a clearly named North America entry into existing English/Czech setup, including nation/difficulty options, cancellation and Save/Continue identity. Preserve all bundled and generated choices. Do not rely on canceled R-0209 for missing UI coverage: this requirement owns its complete playable setup journey.
4. Test recognizable geographic landmarks, dimensions, terrain/river/connectivity invariants, legal starts for all supported European nations, native settlement/brave consistency, deterministic repeat setup, and save/restore. Add named `TC_...` scenarios using existing fixture/page-object conventions for selection, landing/founding/exploring, complete turn, Save/Continue and cancellation. Assertions stay in page `verify...` methods; preserve stable scenario IDs and readable steps. Capture a full-map preview for geographic review and actual player screenshots for UI acceptance.
5. Apply shared Java formatting and documentation checks; use focused model/UI checks during implementation and consolidate full model/JUnit, affected Docker/Xvfb UI and smoke at the end under the expanded-batch amendment. Only the previously authorized unchanged FRIGATE artwork failure is exempt. No native macOS automation; final smoke runs once at the end of the ordered batch. Keep status ready for development until required acceptance completes; record actual execution in the evidence page, not as assumed success here.
6. Candidate design, 2026-11-01 (not yet accepted): the editable source `maps/north-america.txt` stores 80 run-length terrain rows (save codes; upper case marks forest), river courses as corner points and authored native settlements. `model.generation.NorthAmericaWorld` reads it, rejects invalid rows or non-inland rivers, and assembles the world with `ReferenceExpedition`, `GeneratedNatives.placeAt`, `GeneratedWorldResources`, `GeneratedRumors` (fixed seed 1492) and the existing legal-start check. Those helpers now take the map size from the map; the 50 × 30 generated path keeps its random order and output.
7. `FreePlayMap.NORTH_AMERICA` uses the free-play template only for mission data and allows every nation; `GameModelDao.createFreePlay` builds the whole world before the active game is replaced. The setup list appends **North America / Severní Amerika** after the generated choice, so earlier choice indices are unchanged. The map catalogue documents the landmarks, starts and native nations; [evidence](../functional-tests.md#r-0221-north-america-world-2026-11-01) records the test selection and results.
