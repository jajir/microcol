## 1. Summary

1. Choosing America starts a playable free game on a recognizable geographic American map.
2. This requirement owns the authored geographic world and its setup entry, not random generation or a new map editor/import flow.

## 2. Behavior

1. The New Game America choice loads a stable geographic world with legal land, sea, coastline, voyage access and enough playable space for the documented nations. The geography is visibly distinct from the random/generated choice and the existing small fixture maps.
2. Assemble legal national starting expeditions and native participants using their owning rules. Every active participant has an eligible start; the player can land, found, explore, Save/Continue and progress a complete turn without invalid terrain or unreachable required access.
3. Repeating the America choice yields the same authored geography and valid initial world; cancellation leaves no new game. R-0209 verifies the player-facing selector and map-mode matrix.

4. Consume the accepted 2026-10-20 rules from [R-0065](../gap-analysis.md#r-0065-refinement), [R-0150](../gap-analysis.md#r-0150-refinement), [R-0157](../gap-analysis.md#r-0157-refinement); preserve this requirement’s own outcome and existing delivered behavior. These decisions do not establish this consumer’s implementation or acceptance.

## 3. Implementation steps

1. Supply and validate an authored map/scenario through the existing map resource format and setup boundary; reuse shared terrain, expedition and native assembly owners. Check coast connectivity, starts and representative actions with named model/UI scenarios under the [functional contract](../functional-tests.md).
2. Current result: captured requirement only. Existing bundled free-play and rival-expedition maps do not constitute a geographic America acceptance result.
3. Align the existing checks and shared model/AI/UI integration with the linked 2026-10-20 decisions; retain unresolved questions only with their rule owners and run UI regression in CI under the current user instruction.
