# R-0078 — Breed horses in colonies and improve breeding with stables

1. Status: new
2. Updated: 2026-10-15
3. Related: P11/P12; PROD-010; UC-041 (Hra); Q-10. See the [rule catalogue](../gap-analysis.md) and [use cases](../use-cases.md).
4. Dependencies: existing horse/food stocks, warehouse capacity and [R-0025](done/R-0025.md) stable construction; coordinate food accounting with [R-0057](R-0057.md).
5. Primary area: [A07](areas.md#a07).
6. Related areas: A04 colony update phase; A03 production preview/report; A05 horses subsequently used as equipment.
7. Origin: [R-0025](done/R-0025.md). Specification follow-up for a building's real effect under the [migration](migration-2026-10-14.md).

## 1. Summary

1. The player needs stored horses to breed over time and a stable to improve that breeding, instead of remaining an inert building.
2. Migration observation (2026-10-14): horses can be stored, traded and used as equipment, but the existing colony update has no horse-breeding process. The manual building rows are already represented; adding fictional missing building types would not address this gap.
3. Scope: horse breeding and the stable's effect, including resources, capacity and continuity. Other industrial/religious building effects have separate owners.

## 2. Behavior

Proposed acceptance for refinement; unknown coefficients remain explicit.

1. With the agreed minimum horses and available food, complete a colony update → add the agreed new horses and charge exactly the agreed breeding resources.
2. Compare otherwise identical colonies with and without stables → stables improve the breeding rate according to the accepted formula.
3. Zero horses, stock below the breeding threshold, insufficient food and a full warehouse follow explicit boundary rules; no stock becomes negative and no horses exceed capacity silently.
4. Colony preview and actual result agree, including the interaction with resident consumption and famine. Opening a view does not breed horses.
5. Save immediately before/after the update and continue → preserve the stocks and produce no duplicate breeding or report.

6. Shared behavior accepted on 2026-10-15 ([Q-10](../gap-analysis.md#q-10-economy-production-and-education)): Use the agreed minimum stock, food/capacity limits and Stables multiplier; Large Stables provisionally has the same effect. These decisions unblock policy; individual design, dependencies and acceptance checks still require refinement.
