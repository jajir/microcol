# R-0239 — Upload runnable Steam depots and launch options

1. Status: new
2. Updated: 2026-10-17
3. Related: P32; [SteamPipe and launcher scope](../implementation-estimate.md#missing-publishing-and-delivery-work), [platform findings](../implementation-estimate.md#platform-requirements-and-project-findings).
4. Dependencies: candidate packages [R-0234](R-0234.md)/[R-0235](R-0235.md), release baseline [R-0233](R-0233.md), product/app permissions [R-0237](R-0237.md). Installed-build acceptance belongs to [R-0240](R-0240.md).
5. Primary area: [A01](areas.md#a01).
6. Related areas: A04 user-data location, A03 app launch; P32 release.
7. Origin: SteamPipe platform depots, protected upload and Steam launch configuration; native Steamworks gameplay API is not required.

## 1. Summary

1. A private Steam branch can install a correctly filtered Linux or Mac build and launch the bundled game.
2. Upload scripts and package access identify the exact release candidate without exposing publisher credentials.

## 2. Behavior

1. Define explicit shipped-file lists, OS-filtered depots, launch executable/working directory/permissions and a private test branch. Upload the selected candidate repeatably and verify client access, installed files and version; a DMG or archive alone is not the Steam installation.
2. Keep content and credentials separated, omit development files and reference manual, and record upload/build IDs and checksums against source commit. Support controlled promotion and prior-build selection for R-0240/0241.
3. Steam client launch on each chosen platform reaches the game with correct save path and no developer runtime assumption. No achievements, cloud saves, DRM or native bridge is implied.

## 3. Implementation steps

1. Use the current partner account/build tools after R-0237 permissions and R-0234/0235 platform choices, prepare depot/launch manifests and private upload automation, then inspect a client installation. Share platform diagnostics rather than duplicating package work.
2. Current result: captured technical distribution outcome; no SteamPipe configuration or upload is claimed.

## 4. Open questions

1. None; permissions and supported targets are supplied by R-0237/R-0234/R-0235 during refinement.
