## 1. Summary

1. Two colonies can exchange actual resources, train a worker, improve production and recover after an input shortage.
2. This requirement owns conservation over the connected journey, not a new route or factory.

## 2. Behavior

1. Supply a second colony from the first by legal wagon/ship, teach a worker, build/upgrade the relevant facility and run an automatic trade route. Withhold a required input to pause dependent production/construction, then restore delivery and see work resume without free output.
2. Trace stock, cargo, worker and building changes through two complete route cycles, including a Save/Continue checkpoint between cycles and one uninterrupted reference path. A blocked stop cannot spin or consume unrelated goods.
3. UC-116 passes only when independent expected balances match both cycles and its feature UC-029–055 owner paths are honored on the same build.

Consume the accepted 2026-10-20 rules from [R-0092](../gap-analysis.md#r-0092-refinement), [R-0128](../gap-analysis.md#r-0128-refinement), [R-0140](../gap-analysis.md#r-0140-refinement), [R-0146](../gap-analysis.md#r-0146-refinement), [R-0172](../gap-analysis.md#r-0172-refinement); preserve this requirement’s own outcome and existing delivered behavior.
