# R-0196 — Apply war, independence and difficulty score components

1. Status: new
2. Updated: 2026-10-17
3. Related: P25; [SCORE-005/006/007/008](../gap-analysis.md#end-conditions-and-scoring), SCORE-009 difficulty factor; [UC-112](../use-cases.md#konec-hry-ulozeni-a-informace) (Hra); [accepted score formula](../gap-analysis.md#end-dates-and-scoring).
4. Dependencies: base score [R-0195](R-0195.md), native conquest count [R-0174](R-0174.md), successful revolution/order [R-0191](R-0191.md), post-intervention bells [R-0189](R-0189.md)/[R-0190](R-0190.md), difficulty [R-0064](done/R-0064.md).
5. Primary area: [A10](areas.md#a10).
6. Related areas: A08 native-settlement destruction; A04 event order/history; A03 full score breakdown.
7. Origin: terminal bonus/penalty arithmetic not owned by existing campaign score or Hall-of-Fame ranking.

## 1. Summary

1. A result must account for destroyed native settlements, post-intervention bells, successful independence, early declaration and difficulty in a fixed order.
2. This requirement owns that calculation; R-0197 ranks and stores finished results.

## 2. Behavior

1. From R-0195 base, deduct `(d+1)` per destroyed native settlement and add one per bell produced **after** intervention; count actual saved histories once. Clamp this sum B at zero before independence bonus.
2. Successful independence receives order bonus +100%/+50%/+25%/+0% for first through fourth completion, ordered by completion event then stable national turn order in a same-round tie. Only a successful result receives early points `max(0,1780−declaration year)`; a declaration alone gives neither bonus. Apply difficulty factors 0.5/0.75/1/1.25/1.5 to `max(0,B)×(1+order bonus)+early points`, then floor once. B=100, second independence, declaration 1770, Conquistador gives 160.
3. An unsuccessful or nonrevolutionary result has zero order/early bonus. Save/Continue preserves event order, destruction and intervention histories; result preview/recording does not create new events. UC-112 checks all five factors, first–fourth, 1779/1780/1781 and controlled negative/clamp cases. Confirm the post-intervention bell start boundary before readiness when delivery is pending.

## 3. Implementation steps

1. Model result calculator consumes R-0195 snapshot, durable conquest/intervention histories and R-0191 successful completion sequence. Report components and one final integer; UI does not independently round or rank nations.
2. Proposed model/UC-112 checks cover formula, 160 example, exact boundaries, tie order, no victory bonus on loss and reload under the [functional contract](../functional-tests.md).
3. Current result: capture only; no scoring implementation or runtime acceptance is claimed.
