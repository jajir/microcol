# R-0019 — Clarify fog of war separately from movement range

1. Status: Refining
2. Updated: 2026-10-13
3. Related: P04; MAP-007/008, Q-11; UC-006 (Hra). See the [rule catalogue](../gap-analysis.md),
   [use cases](../use-cases.md) and [work packages](../implementation-plan.md#seznam-pracovnich-baliku).
4. Dependencies: [R-0014](R-0014.md) initial expedition; existing Visibility state.
5. Primary area: [A05](areas.md#a05).
6. Related areas: A03 map/report disclosure; A08 opponent knowledge.

## 1. Summary

1. Yes: this requirement concerns fog of war, not the highlighted movement range. Movement reachability is an existing separate feature and must remain unchanged.

2. GamePaintService gates terrain and unit drawing with player.isVisible; Visibility stores accumulated explored cells. The current draft must not assume a new per-unit live line-of-sight system is already required.

3. First clarify and verify fog over unexplored cells: it hides unknown terrain and enemy units. The user’s haze/cloud wording describes the presentation. Re-covering previously explored cells with live enemy visibility is a separate possible extension, not silently included.

## 2. Behavior

1. Unknown cells are covered by fog and do not reveal terrain, enemy units or colony details through rendering or tooltips.

2. Exploration reveals the appropriate cells. Previously explored terrain remains known under the current MAP-007 rule and survives saving/loading.

3. The movement-range overlay answers where the selected unit can move; it neither reveals hidden map cells nor substitutes for fog.

4. Use the existing fog rendering first. A haze/cloud restyling can be scoped later under the graphics brief without changing game knowledge.

## 3. Implementation steps

1. Inspect and test the existing visibility-to-rendering boundary, with separate explored and unexplored sample cells and an enemy in an unknown cell.

2. Document any leakage and save/load mismatch before proposing new visibility state. Keep map knowledge in the model and visual covering in the renderer.

3. Do not claim current live line-of-sight or a new fog style is verified by the navigation audit; record its own acceptance evidence when tested.

## 4. Open questions

1. Q-11 still owns unspecified initial sight radii, but that does not block identifying existing fog or separating it from movement range. Retain current radius pending a rule decision.

2. The earlier proposal for dated enemy markers/live visibility is deferred. This slice covers hiding unexplored terrain and units; a second fog layer over previously explored land needs an explicit later requirement.
