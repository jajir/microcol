## 1. Summary

1. Yes: this requirement concerns fog of war, not the highlighted movement range. Movement reachability is an existing separate feature and must remain unchanged.

2. GamePaintService gates terrain and unit drawing with player.isVisible; Visibility stores accumulated explored cells. The implementation also covers later overlays with fog; it does not introduce a new per-unit live line-of-sight system.

3. First clarify and verify fog over unexplored cells: it hides unknown terrain and enemy units. The user’s haze/cloud wording describes the presentation. Re-covering previously explored cells with live enemy visibility is a separate possible extension, not silently included.

## 2. Behavior

1. Unknown cells are covered by fog and do not reveal terrain, enemy units or colony details through rendering or tooltips.

2. Exploration reveals the appropriate cells. Previously explored terrain remains known under the current MAP-007 rule and survives saving/loading.

3. The movement-range overlay answers where the selected unit can move; it neither reveals hidden map cells nor substitutes for fog.

4. Use the existing fog rendering first. A haze/cloud restyling can be scoped later under the graphics brief without changing game knowledge.
