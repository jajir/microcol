2. Updated: 2026-10-20

## 1. Summary

1. Complete campaigns expose whether economy, opponents, conflict and independence create a playable progression across nation and difficulty profiles.
2. This requirement owns measured balance findings and follow-up selection, not silent changes to accepted formulas.

## 2. Behavior

1. Play or observe representative fresh starts plus prepared mid/late positions across all four nations and five difficulties, including at least the agreed complete-campaign sample. Track turns/date, growth, bottlenecks, opponent pressure, blocked paths, victory/loss and player understanding.
2. Compare actual outcomes with explicit design hypotheses and reference matrix results. Record reproducible outliers, severity and owning rule; propose any balance change in its authoritative rule and affected active R before implementing it.
3. Finish only when the agreed campaign sample and finding dispositions are recorded. A few automated winning paths do not establish enjoyable pacing or fair difficulty for all players.

4. Consume the accepted 2026-10-20 rules from [R-0092](../gap-analysis.md#r-0092-refinement), [R-0128](../gap-analysis.md#r-0128-refinement), [R-0146](../gap-analysis.md#r-0146-refinement), [R-0150](../gap-analysis.md#r-0150-refinement), [R-0169](../gap-analysis.md#r-0169-refinement), [R-0170](../gap-analysis.md#r-0170-refinement), [R-0171](../gap-analysis.md#r-0171-refinement), [R-0172](../gap-analysis.md#r-0172-refinement), [R-0175](../gap-analysis.md#r-0175-refinement), [R-0186](../gap-analysis.md#r-0186-refinement), [R-0196](../gap-analysis.md#r-0196-refinement); preserve this requirement’s own outcome and existing delivered behavior. These decisions do not establish this consumer’s implementation or acceptance.

## 3. Implementation steps

1. Set the campaign sample and observation ledger before testing, run repeatable builds/positions, and separate measured mechanics defects from subjective play findings. Recheck accepted fixes with the same scenarios.
2. Current result: captured evaluation scope; no campaign balance finding or new numeric target is claimed.
3. Align the existing checks and shared model/AI/UI integration with the linked 2026-10-20 decisions; retain unresolved questions only with their rule owners and run UI regression in CI under the current user instruction.

## 4. Open questions

1. How many fresh-start completed campaigns and which acceptable pacing/difficulty ranges define this release's balance evidence? The estimate offers scenarios, not an approved threshold.
