## 1. Summary

1. A free-play expedition can found a viable colony, produce, sell, recruit and return using only ordinary player actions.
2. This requirement owns integrated proof across delivered features, not another setup/production implementation.

## 2. Behavior

1. From a fresh player profile and seeded New Game entry, carry a legal expedition through exploration, landing, named colony, food/work, a manufactured product, loading/voyage, sale, recruitment and return. The chain uses actual stocks, funds, turns and reports; no test-time model editing or free resource injection after start.
2. Repeat one complete connected route for each of four nations; additional profiles may load prepared reference starts. Save and Continue at named checkpoints, compare inventory/ownership/date before and after, and include one uninterrupted path. The 4×5 profile matrix is R-0208; all New Game UI pairings/map modes remain R-0209.
3. UC-115 passes only when all four routes and their expected independent balances succeed on the same build; any failure goes to its smallest feature owner.

## 3. Implementation steps

1. Fix seed, legal starting resources and expected checkpoint ledger before execution; run named `TC_...` player scenarios and model conservation checks under the [functional contract](../functional-tests.md). Retain screenshots/logs only as evidence, not as expected-value source.
2. Current result: captured verification scope only; no complete expedition journey pass is claimed.
