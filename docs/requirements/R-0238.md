## 1. Summary

1. The store presents recognizable, accurate game visuals in every required media slot.
2. This requirement owns media production and current-template validation, not a wholesale in-game visual redesign.

## 2. Behavior

1. Adapt approved source art into required capsules, library images and icons; capture required genuine gameplay screenshots across core activities and an honest gameplay trailer with legible footage, sound/captions and rights-cleared assets. Do not imply unimplemented mechanics.
2. Verify sizes, formats, safe areas, localization claims and actual rendered appearance against the release-time Steam templates. Keep editable sources, exports, version/capture build and license/credit trace.
3. Publisher review can compare every image and trailer scene to the approved product. The dated estimate's media counts/sizes are planning inputs; the live checklist governs submission.

## 3. Implementation steps

1. Select representative approved scenes, capture from a release candidate, create source/export pairs and validate in the current store preview before submission.
2. Current result: captured media scope; no store artwork, screenshots or trailer is claimed complete.

## 4. Open questions

1. None; specific artistic choices follow the accepted visual brief and the live store templates.
