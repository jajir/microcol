# Deferred requirements

Requirements with `Status: deferred` live here. Each file retains the reason for
postponement and the condition for reconsideration. On resumption, move the same
file and ID back to the active directory using the shared
[status and file-location workflow](../README.md#file-locations).

Use the [current backlog](../backlog.md) to select work. This directory currently
contains no deferred requirements as of **2026-10-15**.
