# R-0121 — Build a persistent road with a travel benefit

1. Status: new
2. Updated: 2026-10-17
3. Related: P07/P06; PION-004/PION-006, MOVE-003; UC-021 and UC-012 (Hra), UC-016 cancellation variant. See the [pioneer rules](../gap-analysis.md#equipment-and-pioneers), [accepted movement and work rules](../gap-analysis.md#exploration-work-and-transport) and [use cases](../use-cases.md#vybaveni-a-upravy-krajiny).
4. Dependencies: [R-0118](R-0118.md) equipment boundary; shared MOVE-003 terrain-cost execution, path and range contract remains a prerequisite outside this road-building slice.
5. Primary area: [A05](areas.md#a05).
6. Related areas: A04 road/work persistence; A03 road display and action feedback; A07 road-output bonuses in [R-0122](R-0122.md).
7. Origin: documented PION-004 gap in the [rule catalogue](../gap-analysis.md#equipment-and-pioneers).

## 1. Summary

1. A player needs a road order that produces a saved, visible improvement and shortens valid travel.
2. The 2026-10-17 catalogue at `f10e3f49` records a road capability flag but no executable road order or persisted road state. This is a documented source assessment, not a runtime test.
3. Scope: build one road, persist it, charge once and apply its accepted one-third movement effect through shared MOVE-003 cost, path and range calculations. The shared terrain-cost contract must be implemented before this requirement can become ready or done. This requirement does not own the full terrain-cost overhaul or road production bonuses [R-0122](R-0122.md).

## 2. Behavior

1. Under the [2026-10-17 terrain decision](../gap-analysis.md#exploration-work-and-transport), the current player can order an eligible pioneer with at least 20 tools and positive movement to build a road on any terrain except sea, including a coastal colony tile, if no road exists. Sea tiles reject the order; UI explains invalid or stale choices.
2. Start spends current movement; ordinary work completes after two later owner updates, hardy work after one. Completion records one road and spends exactly 20 tools once. A connected road segment costs one-third movement in either direction under the [accepted movement rule](../gap-analysis.md#exploration-work-and-transport); execution, path and displayed range must agree for acceptance.
3. Missing tools, an existing road, an ineligible unit or a stale order rejects without mutation. Explicit cancel discards unfinished work without charge or road and does not refund movement. Repeating the order cannot create another road or tool charge.
4. Save and Continue preserve unfinished work and the completed road without repeating completion or moving a unit during loading.

## 3. Implementation steps

1. Model/map own road admission and state, using the existing `TerrainType.isSea` distinction for exclusion; unit action owns work progress, and model.store saves both. Reuse one MOVE-003 cost source for travel/path/range; UI only displays availability and results. Depend on a separately selected shared terrain-cost implementation if it remains absent at refinement.
2. Not prepared for development; identify the shared MOVE-003 owner and actual route/range callers before readiness.
3. Proposed checks: road admission on every non-sea terrain including a coastal colony, sea rejection, 19/20-tool, repeat/cancel/timing/persistence cases, connected-road movement in both directions and matching route/range preview; add named UC-021 and UC-012 `TC_...` paths at refinement.
4. Current result: captured only; gameplay has not changed.
