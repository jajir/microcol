# R-0124 — Match the baseline terrain production matrix

1. Status: new
2. Updated: 2026-10-18
3. Related: P04/P11; MAP-003; UC-007 and the terrain matrix (Hra). See the [terrain audit](../gap-analysis.md#terrain-reference-data-audit), [accepted production order](../gap-analysis.md#economy-production-and-education) and [use cases](../use-cases.md).
4. Dependencies: documented terrain/forest states from [R-0123](done/R-0123.md); existing colony field production and preview owners.
5. Primary area: [A05](areas.md#a05).
6. Related areas: A07 field work and production; A03 yield preview; A04 saved terrain/forest state.
7. Origin: MAP-003 discrepancies enumerated in the [rule catalogue](../gap-analysis.md#terrain-reference-data-audit).

## 1. Summary

1. A player choosing a field needs its basic commodity output to follow the same terrain chart in previews and in the next production update.
2. The 2026-10-17 source assessment at `f902be8a` finds a different forest formula and fixed lumber/fur amounts, as well as the missing terrain rows from R-0123. It does not establish a new player test.
3. This requirement owns only the free-colonist baseline for every legal bare/forested terrain and commodity cell. Roads, rivers, deposits, plowing, expertise, politics and buildings retain their own additive or later calculation owners; the finished colony economy is not claimed by this table alone.

## 2. Behavior

1. For each legal terrain/forest variant, an ordinary free colonist working a field receives the food, sugar, tobacco, cotton, fur, lumber, ore, silver and fish baselines printed on aid card 4. Compare all cells, including zero and exceptional values, to the [complete terrain audit](../gap-analysis.md#terrain-reference-data-audit); do not smooth barren cells or infer a positive output.
2. The field's displayed baseline and actual production agree before improvements or worker bonuses. For example, forested/bare plains has food 3/4, fur 3/0 and lumber 6/0; forested/bare marsh has food 2/3, tobacco 2/3 and ore 2/3. Forested tundra becomes usable with the printed baseline, while bare tundra has no fur or lumber.
3. Clearing a forest through [R-0120](done/R-0120.md) uses the bare row afterward without duplicating any yield. Selecting an unavailable commodity or invalid variant does not silently produce goods; a zero cell stays zero without an explicit resource overlay from [R-0127](R-0127.md).
4. Save and Continue preserve terrain and forest identity, and subsequent previews and production use the same baseline. Loading alone never adds stock. Whole UC-007 also needs movement/defense and remains separately assessed.

5. Accepted on 2026-10-18: a fresh-water lake uses the ordinary ocean baseline of three edible food (`CORN`) and the same dock/higher-tier prerequisite and production modifiers. This resolves the absent lake row by an explicit MicroCol rule; see the [shared lake rule](../gap-analysis.md#terrain-reference-data-audit).

## 3. Implementation steps

1. Retain the existing edible ocean output representation (`CORN`) while matching the printed Fish amount; this naming alone is not a behavior gap. Put the aid-card baseline in the model terrain-output source used by both colony production and the UI preview. Preserve the [accepted calculation order](../gap-analysis.md#economy-production-and-education): terrain baseline, then eligible flat additions, job and political changes, percentage changes, and input caps.
2. Not prepared for development. On selection, inspect the existing `Terrain`/`TerrainType` output path and field preview; reuse R-0123 terrain identity and preserve separately owned improvement and specialist effects.
3. Proposed checks: every legal terrain × forest × commodity cell, including zeros, the plains/marsh/tundra examples, one real colony update matching preview, forest removal, and save/Continue. Add a named UC-007 player scenario at refinement; use the [functional contract](../functional-tests.md).
4. Current result: captured only; no gameplay change or runtime test is claimed.
