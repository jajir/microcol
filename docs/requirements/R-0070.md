## 1. Summary

1. The player needs an explicit, consistent rule for what can be learned about foreign units after they leave observation. This is a proposed follow-up, not a retroactive defect in the accepted fog slice.

2. Migration observation (2026-10-14): The delivered fog is accumulated exploration. A separate current-visibility layer and policy for remembered foreign objects were not accepted in R-0019.

3. Scope: the outcome and examples below. This is captured work awaiting individual refinement; it does not reopen the delivered origin scope or close a whole UC.

## 2. Behavior

Proposed acceptance for refinement; inherited resolved decisions remain agreed.

1. Visit and then leave an area → keep explored terrain while foreign-unit information follows the agreed current/remembered-knowledge policy.

2. Unknown or stale foreign information must not become an actionable attack target or leak through tooltips, range overlays or reports.

3. Re-enter observation → update visible information consistently without erasing the explored map.

4. Continue a save → restore permitted knowledge without revealing hidden current positions.

5. Shared behavior accepted on 2026-10-15 ([Q-11](../gap-analysis.md#q-11-exploration-work-and-transport)): Retain discovered terrain but disclose current foreign units only inside present sight; this separate future behavior is now selected as policy, not implemented. These decisions unblock policy; individual design, dependencies and acceptance checks still require refinement.
