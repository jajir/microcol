## 1. Summary

Include the automatic one-cross contribution in colony production even without
a preacher. This is a small production correction, not completion of immigration.

Static source inspection on 2026-10-12 at
[`4b3a1b56`](https://github.com/jajir/microcol/commit/4b3a1b567bd9e8c8ad8af1587d9849ecee02bead);
no new gameplay test was run while preparing this draft.
[ConstructionType](../../microcol-game/src/main/java/org/microcol/model/ConstructionType.java)
defines base production of one for chapel, church and cathedral.
[Construction.getProduction](../../microcol-game/src/main/java/org/microcol/model/Construction.java)
only sums worker slots, so that base is unused.
[Construction_CHURCH_Test](../../microcol-game/src/test/java/org/microcol/model/Construction_CHURCH_Test.java)
currently expects zero with no workers.
[Player](../../microcol-game/src/main/java/org/microcol/model/Player.java)
still grants immigrants periodically rather than from a cross threshold.

Scope is the one-cross base in the shared colony calculation and existing
accounting/display. Church/cathedral bonus tuning, firebrand preacher multipliers,
national immigration thresholds and recruitment are separate changes.
This partial UC-040 slice does not establish national immigration integration.

## 2. Behavior

An ordinary free-play colony with a basic chapel and no preacher displays one
automatic cross per update. Actual production uses the same calculation.
Existing worker output is added to that base once, not substituted for it.

Acceptance examples:

1. Empty basic chapel → preview 1 cross; complete one colony update → exactly
   one base cross is produced through the existing accounting path.
2. Reopen the colony screen repeatedly → stocks/accumulated production unchanged.
3. Staff the building → base 1 plus the currently agreed worker contribution;
   remove the worker → base remains 1.
4. Two colonies → each contributes its own base once. The same colony cannot
   receive a second base merely because an upgrade replaced its religious building.
5. Save before/after the update and continue → no missing or replayed base
   contribution. No preacher or manufacturing input is required.

The base component remains one at each building level; this does not assert that
the full upgraded building's unstaffed total should be one. Further religious
bonuses remain governed by PROD-009 and Q-10.

   an unstaffed chapel, staffing/removal and next-turn displayed/accounted output.
   Preserve TC02 and TC07 production assertions.
