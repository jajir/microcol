## 1. Summary

1. A new player can use the existing tutorial to reach a viable first colony and then find the relevant rule again.
2. This requirement updates instruction accuracy and transitions; it does not require a new campaign or create production resources for the player.

## 2. Behavior

1. The tutorial explains how to select/land a reference expedition, found and name a legal colony, assign food/work, view shortages and reach a first trade opportunity using actual available controls. A blocked action names its prerequisite; cancel/back leaves the game intact. It points to R-0206 help for rules beyond the first path.
2. Instructions follow current model/UI after language switch and Save/Continue, without referring to removed controls or guaranteeing a resource absent from the start. Skipping/reopening help never advances a turn or changes orders.
3. UC-114/115 check the guided steps on a seeded reference start, blocked/cancel paths, keyboard/mouse and resume; a separate player observation can assess discoverability without claiming automated tests prove it.

## 3. Implementation steps

1. Update existing mission/help text and links in place, using R-0016 controls and R-0206 reference entries. Keep mission mechanics and first-colony model operations with their current owners.
2. Proposed guided UC-114/115 UI check and manual comprehension observation cover accurate steps, localization, return/focus and nonmutation under the [functional contract](../functional-tests.md).
3. Current result: capture only; no tutorial implementation or runtime acceptance is claimed.
