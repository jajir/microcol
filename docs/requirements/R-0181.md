# R-0181 — Clear existing boycotts and arrears when Fugger joins

1. Status: new
2. Updated: 2026-10-17
3. Related: P22/P23; [FATHER-012](../gap-analysis.md#founding-father-effects)/GOV-003; [UC-097](../use-cases.md#vsech-25-otcu-zakladatelu) (Hra).
4. Dependencies: founder join [R-0104](done/R-0104.md), boycott/debt [R-0102](R-0102.md), ordinary repayment [R-0103](R-0103.md).
5. Primary area: [A10](areas.md#a10).
6. Related areas: A06 Europe trading; A04 once-only joining; A03 effect notice.
7. Origin: one-time founder effect excluded by R-0103's paid-back-tax action.

## 1. Summary

1. Fugger's arrival forgives the nation's currently outstanding back taxes and boycotts without a payment.
2. R-0104 already provides membership; R-0102/0103 own ordinary protest/repayment. This requirement adds only the founder's joining effect.

## 2. Behavior

1. On confirmed recruitment, clear every then-existing commodity boycott and its arrears for that nation exactly once, without deducting gold, changing unrelated stock or removing another nation's boycott. Restored goods become eligible for ordinary Europe trade subject to its other rules.
2. A later protest can create a new boycott and arrears normally; merely retaining Fugger membership is not permanent boycott immunity. Canceling recruitment or loading a prior save does not apply an unearned clearing.
3. UC-097 checks two blocked goods, nonblocked goods, zero payment, post-join new protest, foreign nation and Save/Continue without a second clearing.

## 3. Implementation steps

1. Model founder-join transaction invokes R-0102's boycott ledger once after valid recruitment, preserving R-0103's ordinary payment command. Persist the applied join with membership; GUI reports cleared commodities.
2. Proposed model/UC-097 checks cover multiple debts, once-only mutation, resumed game and later protest under the [functional contract](../functional-tests.md).
3. Current result: capture only; no gameplay or runtime acceptance is claimed.
