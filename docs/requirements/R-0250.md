# R-0250 — Playpen Sans v celé hře

1. Status: ready for development
2. Updated: 2026-10-19
3. Related: [UC-119](../use-cases.md), TC83, TC84 a TC85; typografie v [grafickém manuálu](../graphics.md).
4. Dependencies: [dřevěná tlačítka](done/R-0246.md) a [Nastavení](done/R-0248.md).
5. Primary area: [A03](areas.md#a03).
6. Cross-area dependencies: A01 menu, A02 Nastavení, A04 mapové popisky, A06/A07 tabulky a dialogy; jejich pravidla se nemění.

## 1. Summary

1. Uživatel 19. října 2026 vybral `02-Playpen-Sans-tenci.png` a požádal o nasazení na main v celé codebase. Jedna čitelná rukopisná rodina sjednotí všechny živé texty hry.
2. Původní náhled ztenčoval Regular 400 barvou pozadí. Ve hře použít skutečný lehký řez 300, který zachová jemné tahy bez závislosti na podkladu. Nejde o pixelově totožný render prohlížeče.

## 2. Behavior

1. Menu, Nastavení, hra, tabulky, vstupní pole, popup menu, dialogy, tlačítka a text kreslený na plátno používají Playpen Sans Light, normální sklon. Barvy, obrysy a vlastní vzhled herních tlačítek zůstávají. Následnou dohodu o velikostech 36/18 px a odsazení vlastní [R-0251](R-0251.md).
2. Po změně českého/anglického jazyka zůstává stejné písmo, úplné popisky, ovládání a ukládání nastavení. Font obsahuje českou, anglickou, německou, francouzskou a nizozemskou diakritiku, číslice a euro.
3. Otevření a zavření dialogů, potvrzení/zrušení, myš a klávesnice mají dosavadní výsledky. Širší znaky nesmí nově skrýt akce či oříznout krátké popisky; nutné rozměry přizpůsobit obsahu. Pevně rozloženou kolonii ověřit i při 1280 × 900; dřívější ořez při 900 × 750 evidovat odděleně od regrese fontu.
4. Font je součástí distribuce a funguje offline bez instalace do systému. Herní data a uložené pozice se nemění. Doplnění uživatele zahrnuje také všechny SVG s textem, včetně historických referenčních diagramů (zůstávají na místě). Font je přibalený i pro práci s podklady; samostatné SVG nemá vyžadovat instalaci systémového fontu.

## 3. Implementation steps

1. Připravit statický Light 300 z již použitého Google Fonts zdroje, uchovat OFL, zdroj a reprodukční postup. FontService načítá tento řez pro CSS i Canvas; společné CSS sjednotí oba kořeny scén a odstraní staré typografické výjimky.
2. SVG texty sjednotit, vložit potřebnou část fontu pro prohlížeče a pro Fontconfig export použít izolovanou konfiguraci s přibaleným TTF. Nahradit zastaralý flowRoot ikony standardním SVG textem. Z loga přegenerovat skutečný splash-screen.png; ostatní bitmapy bez viditelného změněného textu ponechat.
3. Doplnit font k produkčním údajům na plátně kolonie. Zachovat vlastní skiny; následné rozměry ovládání určuje R-0251. Případné opravy rozložení omezit na skutečné kolize.
4. Upravit kontroly fontu TC83/TC84 a přidat TC85 pro typografii menu, nastavení, herní obrazovky, Evropy a modalit. Ověřit rodinu/řez, načtení fontu, nekrácené popisky a příslušné hráčské výsledky. Celá Docker/Xvfb regrese, formatter, kontrola zdroje testů, strict MkDocs a publikace jsou povinné.
5. Stav: implementováno, cílené kontroly a SVG export ověřeny; úplná regrese běží. Na výslovný pokyn uživatele se odesílá do main před jejím dokončením. Status zůstává ready for development do úplné přejímky. Výsledky a publikaci vede [evidence](../functional-tests.md#r-0250-playpen-sans-2026-10-19).
