## 1. Summary

1. Players should recognize the map's squares without a strong grid competing with the hand-drawn terrain, units and colonies. Unknown territory should read as a quiet, continuous gray area.
2. Source inspection on 2026-10-24 at `df0cd0a4` finds straight, continuous light-gray grid lines drawn across the viewport after fog, controlled by an existing preference. The game already distinguishes permanently explored terrain from current sight.
3. Change the main map's grid and unexplored fill only. The new image is a reference for the grid's visual character; the agreed palette, typography, existing controls and gameplay rules retain their owners. This is a capture for later implementation, not a request to copy the reference screen layout.

## 2. Behavior

1. When the existing grid option is enabled, explored land and water display a subtle dashed square grid aligned to the actual map squares. Lines have a restrained hand-drawn appearance, lower contrast than object outlines and no shading or texture effects. Terrain, units, colonies, selection and routes remain legible.
2. Never-explored squares have a solid muted warm-gray fill, with `#9B9486` chosen from the agreed palette family. They contain no internal grid lines, including during scrolling or at the edge of the explored region. The reference image itself shows grid lines over gray territory; those lines are explicitly excluded by the user's instruction.
3. Explored terrain retains the grid when it leaves current sight. Existing rules still hide unseen foreign units and mark remembered colony information appropriately; a rendering change must not reveal hidden terrain or live object information.
4. Discovering new squares reveals their terrain and, when enabled, their grid. Shared edges stay visually consistent and are not doubled; the grid stops at the explored boundary without extending into the gray fill. Panning, resizing and repainting keep the grid aligned and stable, without flicker or random changes in the drawn line.
5. Turning off the existing grid option removes the grid from explored squares as well; unknown territory stays gray in either state. Preserve the current preference behavior and save/Continue exploration state. Changing the display spends no turn, changes no movement, and leaves units and goods unchanged.
