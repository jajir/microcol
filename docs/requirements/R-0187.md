# R-0187 — Close home Europe and secure its assets on declaration

1. Status: new
2. Updated: 2026-10-17
3. Related: P09/P24; residual [GOV-011](../gap-analysis.md#government-taxation-and-independence); [UC-081](../use-cases.md#politika-a-valka-za-nezavislost) (Hra); [accepted closure](../gap-analysis.md#revolution-and-intervention).
4. Dependencies: declaration [R-0105](R-0105.md), delivered reverse-voyage mechanics [R-0072](done/R-0072.md), existing Europe trade/purchase guards [R-0020](done/R-0020.md), custom-house export [R-0085](R-0085.md), foreign trade [R-0167](R-0167.md).
5. Primary area: [A10](areas.md#a10).
6. Related areas: A06 Atlantic travel/Europe economy; A03 warning/access feedback; A04 seized/in-transit persistence.
7. Origin: R-0105 explicitly excludes complete home closure. Current `Player.canTradeInEurope` already guards ordinary buy/sell/purchase, and R-0072 already reverses a voyage; this requirement owns remaining access and asset-state integration.

## 1. Summary

1. Declaring independence should close the home port consistently, including ships already sailing there and stock still inside.
2. This capture credits the existing market guards and reverse-course operation; it does not reimplement those delivered behaviors.

## 2. Behavior

1. Before confirmation, show that home Europe will close. Cancel keeps port, assets and voyages unchanged. Confirmed declaration makes home-port UI/actions unavailable: travel there, hiring, training, purchases, loading/unloading and ordinary buy/sell through every model/player route.
2. Ships already sailing **to** home Europe reverse using R-0072's normal duration/cargo preservation. People, ships and goods still in the home port become inaccessible Crown-seized assets, neither rebel resources nor destroyed REF; do not silently move or sell them.
3. Other permitted channels remain: R-0085 half-income custom-house export and R-0167 de Witt peaceful foreign-colony trade. Save/Continue cannot reopen the port, lose reversed cargo or make seized units available. UC-081 checks each access route, reversal, seized stock and alternative trade.

## 3. Implementation steps

1. Model declaration transaction validates and records closure/seizure before UI exit. Reuse `canTradeInEurope` guards and R-0072 voyage reversal; add missing model admission checks and viewpoint state for all remaining home-port operations. GUI hides/denies closed actions using model eligibility.
2. Proposed model/UC-081 checks cover canceled declaration, every port command, in-transit reversal, seized assets, alternative trade and reload under the [functional contract](../functional-tests.md).
3. Current result: capture only; no closure implementation or runtime acceptance is claimed.
