# R-0123 — Represent every terrain and legal forest variant

1. Status: new
2. Updated: 2026-10-17
3. Related: P04; MAP-001 and the terrain/defense part of MAP-002; UC-007/073 (Hra). See the [terrain audit](../gap-analysis.md#terrain-reference-data-audit), [map rules](../gap-analysis.md#map-terrain-and-exploration) and [terrain and combat use cases](../use-cases.md).
4. Dependencies: existing map persistence and the ordinary combat defense owner [R-0093](done/R-0093.md); production is [R-0124](R-0124.md), movement [R-0125](R-0125.md).
5. Primary area: [A05](areas.md#a05).
6. Related areas: A09 combat reads terrain defense; A04 saves map identity; A03 displays terrain and forest state.
7. Origin: MAP-001/002 gaps and the complete aid-card-4 comparison in the [rule catalogue](../gap-analysis.md#terrain-reference-data-audit).

## 1. Summary

1. A player must be able to distinguish every documented land and water terrain and its legal forest state, so later production, travel and combat use the same tile identity.
2. The 2026-10-17 catalogue source assessment at `f902be8a` identifies missing plains, marsh and fresh-water lake identity, disallows a documented forested tundra, while R-0093 has already corrected defense values for supported variants. The earlier catalogue table predates that correction. This requirement adds the missing identities/variants and their defense cells; it does not repeat completed defense work.
3. This requirement owns terrain identity, legal forest variants and the terrain-defense reference values. [R-0124](R-0124.md) owns output cells, [R-0125](R-0125.md) movement cost, and [R-0093](done/R-0093.md) owns the existing combat strength/resolver path; no combat resolver is recreated here. River, road and resource overlays have separate owners.

## 2. Behavior

1. Maps can contain and identify plains, grasslands, prairie, savannah, marsh, swamp, desert, tundra, arctic, hills, mountains, a fresh-water lake, ocean and sea lane. A lake remains distinguishable from ocean-connected water after save and Continue. The aid-card land rows support the bare/forested variants shown in the [terrain audit](../gap-analysis.md#terrain-reference-data-audit), including forested tundra; arctic, hills, mountains and water do not gain an invented forest variant.
2. On each documented terrain/forest variant, the terrain defense value equals the aid-card-4 cell. New cells include forested/bare plains 50/0%, marsh 50/25% and forested tundra 50%. Preserve the already delivered swamp 75/25%, hills 100% and mountains 150%; the [complete terrain audit](../gap-analysis.md#terrain-reference-data-audit) supplies the remaining cells. A combat preview and actual ordinary battle that already use shared terrain defense must read the same value; this requirement does not add new combat roles or special bonuses.
3. Invalid terrain/forest combinations and unknown required terrain codes are rejected without silently becoming another terrain. Merely inspecting or loading a tile does not alter it. Terrain identity and legal forest state survive save/Continue.
4. Changing a forest through the separately owned [clearing order](done/R-0120.md) changes the variant once; the corrected type/defense then applies. Whole UC-007 production/movement and UC-073 combat-role matrices remain independently open until their owners are accepted.

## 3. Implementation steps

1. Keep terrain identity, forest legality and defense values in the model/map owner, and persist the codes in the existing map store. UI and AI consume the same values; the shared combat strength path from R-0093 reads them without a new combat rule.
2. Not prepared for development. On selection, inspect map construction, serialization, bundled scenarios, terrain help and the R-0093 defense caller; update current-schema fixtures directly. Keep lake travel/output policy with the relevant movement/production rules rather than guessing from ocean.
3. Proposed checks: a table covering every aid-card terrain and legal forest/defense cell, invalid variants, lake versus ocean identity, new terrain round trips, a changed forest, and one existing ordinary-combat preview/resolver path. Add named UC-007/073 player scenarios at refinement under the [functional contract](../functional-tests.md).
4. Current result: captured only; no gameplay change or runtime test is claimed.
