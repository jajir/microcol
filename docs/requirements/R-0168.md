## 1. Summary

1. The foreign-affairs advisor should show known relations and, after de Witt, more detailed comparisons of European powers.
2. The 2026-10-17 catalogue at `80b0e180` reports generic screens but no complete gated foreign comparison; this is source assessment only.
3. This requirement owns the foreign-affairs fields and founder disclosure gate, not foreign trade or every advisor family.

## 2. Behavior

1. Before de Witt, the player can inspect legitimately known European powers and war/peace/alliance status without seeing undiscovered private details. Recruiting de Witt reveals comparison of population, colony count and average size, military, naval and trade strength for eligible foreign powers.
2. The values come from actual game state at report opening, with displayed totals/averages consistent with their source values. De Witt changes disclosure, not the underlying ownership or economics; trading remains R-0167.
3. Switching player, changing relationships, losing a colony, Save/Continue or reopening the report updates permitted values without altering game state or exposing information the current player has not earned.
4. UC-071/100/114 check before/after founder, known/unknown rival, each required comparison field, war/peace and keyboard/mouse access.

## 3. Implementation steps

1. Model supplies viewpoint-filtered foreign report data and founder gate; GUI renders through existing R-0016 navigation. Reuse relation/colony/ship/market owners as source values rather than maintaining duplicate advisor counters.
2. On selection, reconcile each comparison field with the report matrix and known-information rules; native advisor and naval inventory are separate A03 slices. R-0104 membership is delivered and need not be reimplemented.
3. Proposed model/UI and UC-071/100/114 checks cover all fields, disclosure boundary, fresh values after ownership changes, other-player view and Continue. Follow the [functional contract](../functional-tests.md).
4. Current result: capture only; no gameplay change or runtime acceptance is claimed.
